# Plan 25-06: Archive Tab, Revert/Restore & Permanent Delete with Mandatory Employee Guard

**Phase**: 25 · Department Module — Complete UI Overhaul, Functional Audit, Analytics, RBAC/PBAC Compliance & Error Fixing  
**Plan ID**: 25-06  
**Goal**: Overhaul the Archive Console and modals, guaranteeing full lifecycle data integrity and strictly enforcing the mandatory business rule: **a department must NEVER be permanently deleted while even one employee remains assigned to it**.

---

## 1. Critical Business Rule — Employee Assignment Restriction

> [!CRITICAL]
> **A department must NEVER be permanently deleted as long as one or more employees are assigned to it.**
> 
> Required Message:
> *"This department cannot be permanently deleted because employees are still assigned to it. Please reassign all employees to another department before proceeding."*

Both frontend and backend independently enforce this restriction:
1. **Backend**: `permanentDeleteDepartment` checks `Employee.countDocuments({ departmentId: id, isDeleted: false }) > 0` and throws HTTP 400.
2. **Frontend**: `DepartmentPermanentDeleteModal.jsx` checks the department's assigned headcount. If `headcount > 0`:
   - Delete button is permanently disabled.
   - An authoritative warning banner displays the exact message above.
   - A direct link to the Employee Directory (`/employees`) is provided to reassign staff.

---

## 2. Scope of Work

1. **Archive Tab Refinement (`DepartmentsPage.jsx`)**:
   - High-density table for archived departments:
     - Department Name & Code.
     - Assigned Personnel (highlighting staff count with lock notice if $> 0$).
     - Archived Date (`archivedAt` formatted in `Asia/Karachi`).
     - Archived By (`archivedByName`).
     - Actions: Inspect Details (`Eye`), Restore (`RotateCcw`), Permanent Delete (`Trash2`).
   - Dedicated search, pagination, and sorting controls.

2. **Restore / Revert Modal Redesign (`DepartmentRestoreModal.jsx`)**:
   - Modernized confirmation modal matching Forest & Emerald design system.
   - Explains that the department will be restored to the active corporate hierarchy.
   - Handles duplicate department codes or name conflicts gracefully.
   - Reinstates active status, updates live statistics, and shows success toast feedback.

3. **Permanent Delete Modal Redesign (`DepartmentPermanentDeleteModal.jsx`)**:
   - Enforces Employee Assignment Restriction Guard.
   - If `headcount === 0`:
     - Displays destructive warning that permanent deletion cannot be undone.
     - Confirmation button executes `DELETE /api/v1/departments/:id/permanent`.
     - Automatically updates Archive tab and KPI statistics.

4. **Verification**:
   - Verify permanent deletion is impossible while employees are assigned.
   - Verify restoring an archived department reinstates it to active status.
