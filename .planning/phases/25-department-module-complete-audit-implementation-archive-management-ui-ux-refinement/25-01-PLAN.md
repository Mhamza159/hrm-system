# Plan 25-01: Critical Regression Fix — Department Listing Restoration & Schema Normalization

**Phase**: 25 · Department Module — Critical Regression Fix, Complete Audit, RBAC/PBAC Compliance & UI/UX Refinement  
**Plan ID**: 25-01  
**Goal**: Resolve the critical regression where departments stopped displaying in the Department listing. Fix query logic to use `{ isArchived: { $ne: true } }` for backwards compatibility with legacy database records, and run an automated schema normalization so all existing MongoDB departments have `isArchived: false` populated.

---

## 1. Root Cause Analysis of Listing Regression

- **Root Cause**:
  `getAllDepartments` and `getDepartmentStats` in `backend/src/modules/departments/department.service.js` used `query.isArchived = false`.
  In MongoDB Atlas, existing department documents created prior to Phase 25 do not have the `isArchived` field stored in BSON.
  In MongoDB, `{ isArchived: false }` matches **ONLY** documents where `isArchived` exists and is strictly `false`. Documents where `isArchived` is undefined or omitted evaluate to false in the match, causing MongoDB to return **0 records** (`[]`).
- **Live Verification**:
  - `Department.find({ isDeleted: false, isArchived: false })` -> **0 records** returned.
  - `Department.find({ isDeleted: false, isArchived: { $ne: true } })` -> **8 records** returned!

---

## 2. Scope of Work

1. **Query Logic Restoration (`backend/src/modules/departments/department.service.js`)**:
   - In `getAllDepartments`:
     ```javascript
     if (isArchived !== undefined) {
       const shouldBeArchived = isArchived === 'true' || isArchived === true;
       query.isArchived = shouldBeArchived ? true : { $ne: true };
     } else {
       query.isArchived = { $ne: true };
     }
     ```
   - In `getDepartmentStats`:
     - Update active count query: `Department.countDocuments({ isArchived: { $ne: true }, isDeleted: false })`.
     - Update active departments array query: `Department.find({ isArchived: { $ne: true }, isDeleted: false }).select('_id').lean()`.
   - In `detectCircularParent`, `updateDepartment`, `archiveDepartment`, and `restoreDepartment`:
     - Replace strict `isArchived: false` with `isArchived: { $ne: true }`.

2. **Automated Database Normalization (`backend/src/modules/departments/department.service.js` or `department.model.js`)**:
   - Ensure an idempotent startup / initialization check:
     ```javascript
     await Department.updateMany(
       { isArchived: { $exists: false } },
       { $set: { isArchived: false } }
     );
     ```
   - Guarantees all legacy records in MongoDB Atlas are updated with `isArchived: false` without losing or overwriting any existing department names, codes, or hierarchies.

3. **Verification**:
   - Run verification script against MongoDB to ensure `getAllDepartments` returns all 8 existing departments.
   - Verify that `activeDepartments` in the frontend receives the full department array.
