# Plan 25-02: Department Dashboard Analytics, 7 KPI Cards & Interactive Visualizations

**Phase**: 25 · Department Module — Complete UI Overhaul, Functional Audit, Analytics, RBAC/PBAC Compliance & Error Fixing  
**Plan ID**: 25-02  
**Goal**: Build a complete, modern analytics dashboard for the Department Module conforming to `DESIGN.md` and `docs/UI-REFERENCE.md`, featuring 7 dynamic KPI cards and native SVG/Tailwind interactive charts (workforce distribution bar chart and department share donut chart) with zero external chart dependencies.

---

## 1. Design System & Theming Specifications

- **Theme Compliance**:
  - Forest & Emerald Enterprise theme: Canvas `#F8FAFC` (Light) / `#0A110D` (Dark), Surface Cards `#FFFFFF` / `#111D17`, Hairline Borders `#EAECF0` / `#1A3125`.
  - Brand Emerald Accent: `#00C471`, Hover: `#049856`.
  - Charts built using responsive SVG paths, flex bars, and animated tooltips (zero external chart dependencies, guaranteed React 19 compatibility).

---

## 2. Scope of Work

1. **Expanded 7-Card KPI Summary Grid (`DepartmentStatsCards.jsx`)**:
   - Backed by live data from `useGetDepartmentAnalyticsQuery` / `useGetDepartmentStatsQuery`:
     1. **Total Departments**: Total active + archived count with `Building2` icon.
     2. **Active Departments**: Operating business units with emerald pulse indicator.
     3. **Archived Departments**: Units stored in cold archive with `Archive` icon.
     4. **Total Assigned Staff**: Total employee headcount across all units with `Users` icon.
     5. **Staffed Departments**: Units with $\ge 1$ assigned employee.
     6. **Empty Departments**: Units currently having 0 assigned employees (shortcut to unassigned filter).
     7. **Unassigned Heads**: Units currently missing a Department Head (shortcut to unassigned head filter).
   - Clickable card interaction: Clicking a card applies the matching filter to the table view.

2. **Interactive Analytics Section (`DepartmentAnalyticsSection.jsx`)**:
   - **Chart 1: Employee Distribution by Department (Horizontal Bar Chart)**:
     - Renders horizontal bars for all active departments.
     - Displays department name, monospace code badge, employee count pill, and percentage of company workforce.
     - Hover states with interactive tooltip displaying headcount, department head name, and status.
   - **Chart 2: Department Workforce Share (SVG Donut Chart)**:
     - Native SVG donut chart with color-coded slices for top departments.
     - Central readout showing total headcount and active units.
     - Interactive legend with percentage breakdowns.
   - **Insight Highlights Box**:
     - Highlights: Top staffed department (e.g., Engineering), smallest active unit, and leadership coverage ratio (% of departments with assigned heads).
     - Responsive grid (stacks on mobile, side-by-side on desktop).

3. **Verification**:
   - Verify chart updates when new departments or employees are created or reassigned.
   - Verify light and dark mode contrast and accessibility.
