# Plan 25-02: Department Stats Aggregation, Archive Query Endpoints & Employee Guard Integration

**Phase**: 25 · Department Module — Complete Audit, Implementation, Archive Management & UI/UX Refinement  
**Plan ID**: 25-02  
**Goal**: Implement backend stats aggregation, archived departments query endpoint, route controllers, and safeguard the employee service against assigning employees to archived departments.

---

## 1. Scope of Work

1. **Department Stats Aggregation (`department.service.js` & `department.controller.js`)**:
   - Implement `getDepartmentStats()`:
     - Run parallel MongoDB aggregation queries:
       - `total`: Count of non-deleted departments (`{ isDeleted: false }`).
       - `active`: Count of active non-archived departments (`{ isArchived: false, isDeleted: false }`).
       - `archived`: Count of archived departments (`{ isArchived: true, isDeleted: false }`).
       - `withEmployees`: Count of active departments having $\ge 1$ assigned employee in `Employee` collection.
       - `withoutEmployees`: Count of active departments having 0 assigned employees.
     - Return structured KPI payload.

2. **Archived Departments Query (`department.service.js` & `department.controller.js`)**:
   - Implement `getArchivedDepartments({ search, page, limit, sortBy, sortOrder })`:
     - Query `{ isArchived: true, isDeleted: false }`.
     - Support search by `name` and `code` with ReDoS-safe regex.
     - Populate `parentId` (`name code`), `headId` (`email employeeId`), and `archivedBy` (`email name`).
     - Attach real-time `headcount` of currently assigned employees for each archived department so administrators immediately see if employees are still linked.
     - Return paginated results (`docs`, `total`, `page`, `limit`, `totalPages`).

3. **Controller & Route Integration (`department.controller.js` & `department.routes.js`)**:
   - Add route handlers:
     - `GET /stats` $\rightarrow$ `checkPermission('org.view')` $\rightarrow$ `departmentController.getDepartmentStats`
     - `GET /archived` $\rightarrow$ `checkPermission('org.view')` $\rightarrow$ `departmentController.getArchivedDepartments`
     - `PATCH /:id/archive` $\rightarrow$ `checkPermission('org.manage')` $\rightarrow$ `departmentController.archiveDepartment`
     - `PATCH /:id/restore` $\rightarrow$ `checkPermission('org.manage')` $\rightarrow$ `departmentController.restoreDepartment`
     - `DELETE /:id/permanent` $\rightarrow$ `checkPermission('org.manage')` $\rightarrow$ `departmentController.permanentDeleteDepartment`
   - *Note on Route Precedence*: Ensure `/stats` and `/archived` are registered **before** `/:id` to avoid route collision with MongoDB ObjectIds.

4. **Employee Module Guard Integration (`backend/src/modules/employees/employee.service.js`)**:
   - Verify that employee onboarding (`createEmployee`) and employee profile updates (`updateEmployeeProfile` / `updateEmployee`) check if `departmentId` is provided.
   - If provided, query `Department.findById(departmentId)`. If department is `isArchived: true` or `isDeleted: true`, throw 400: *"Cannot assign employee to an archived or inactive department."*

5. **Frontend RTK Query Endpoint Expansion (`frontend/src/features/departments/departmentsApi.js`)**:
   - Add RTK Query endpoints:
     - `getDepartmentStats`: query `/departments/stats`, providesTag `['DepartmentStats']`
     - `getArchivedDepartments`: query `/departments/archived`, providesTags `['ArchivedDepartments']`
     - `archiveDepartment`: mutation `PATCH /departments/:id/archive`, invalidates `['Departments', 'ArchivedDepartments', 'DepartmentStats', 'OrgChart']`
     - `restoreDepartment`: mutation `PATCH /departments/:id/restore`, invalidates `['Departments', 'ArchivedDepartments', 'DepartmentStats', 'OrgChart']`
     - `permanentDeleteDepartment`: mutation `DELETE /departments/:id/permanent`, invalidates `['Departments', 'ArchivedDepartments', 'DepartmentStats', 'OrgChart']`

---

## 2. Verification Criteria
- [ ] `GET /api/v1/departments/stats` returns accurate live counts from MongoDB collections.
- [ ] `GET /api/v1/departments/archived` returns archived departments with real-time employee count and archive metadata.
- [ ] Assigning an employee to an archived department is rejected with a clear 400 error.
- [ ] RTK Query endpoints compile and provide appropriate cache invalidation tags.
