---

## 1. Test Suite Coverage (20 Regression Requirements)

The test suite must verify:
1. Previously existing departments are still present in the database.
2. Department listing API returns the correct active records (including legacy records where `isArchived` was unpopulated).
3. Active departments appear correctly in active queries and omitted from archived queries.
4. Archived departments appear only in the Archive tab query.
5. Search does not incorrectly hide valid departments.
6. Backend pagination works properly without empty false results.
7. Authorized roles (`org.view`) can see their permitted departments.
8. Unauthorized roles cannot perform administrative operations (`org.manage`).
9. Department creation and editing enforce code uniqueness and block circular reporting.
10. Department archiving sets `isArchived: true` and records metadata (`archivedAt`, `archivedBy`).
11. Employee onboarding blocks assignment to archived departments (`POST /api/v1/employees` fails with 400).
12. Permanent deletion is **strictly BLOCKED** when $\ge 1$ employee is assigned to the department (HTTP 400).
13. Permanent deletion succeeds once assigned employees are reassigned or removed.
14. No employee records are ever cascade-deleted or orphaned.
15. Restoring an archived department reinstates it to active status.
16. Dynamic KPI statistics (`GET /api/v1/departments/stats`) return accurate live database counts.
17. Audit logs are correctly recorded for archive, restore, and permanent delete actions.
18. Sub-department hierarchy guard blocks archiving/deleting parents with active child departments.
19. Frontend linting passes with 0 errors.
20. Frontend Vite production build completes cleanly.
