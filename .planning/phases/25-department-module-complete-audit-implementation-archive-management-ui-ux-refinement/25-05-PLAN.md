# Plan 25-05: Comprehensive Department Details Modal with Leadership Spotlight & Staff Roster

**Phase**: 25 · Department Module — Complete UI Overhaul, Functional Audit, Analytics, RBAC/PBAC Compliance & Error Fixing  
**Plan ID**: 25-05  
**Goal**: Overhaul `DepartmentDetailModal.jsx` into a comprehensive unit inspection console featuring a Department Overview, a Leadership Spotlight Card with full employee credentials, an Assigned Staff Roster sub-table, and department-level workforce analytics.

---

## 1. Scope of Work

1. **Section 1: Department Overview & Breadcrumbs**:
   - Header with unit emblem, name, monospace code badge, and semantic status badge.
   - Directorate breadcrumb showing parent division and corporate hierarchy tier.
   - Descriptive mandate copy.
   - Metadata badges: Created At date, Last Updated timestamp in `Asia/Karachi` format.

2. **Section 2: Leadership Spotlight Card**:
   - Prominent card showcasing the Department Head:
     - Profile avatar / photo.
     - Full employee name.
     - Monospace employee code badge (e.g. `EMP-000`).
     - Official designation title and grade.
     - Email address with copy-to-clipboard action.
   - If unassigned, displays an informative prompt to assign a department head via the Edit modal.

3. **Section 3: Assigned Staff Roster Table**:
   - Displays all employees assigned to the department (populated via enhanced `getDepartmentById`):
     - Employee Name & Avatar.
     - Employee Code (`font-mono`).
     - Designation Title.
     - Employment Status (`Active`, `Probation`, etc.).
     - Joining Date.
   - In-modal search bar to quickly filter assigned personnel.
   - Empty state when 0 employees are assigned with shortcut guidance.

4. **Section 4: Department Workforce Analytics Bar**:
   - Total Headcount count pill.
   - Percentage share of company workforce.
   - Ratio of permanent vs contract/probation staff in the unit.

5. **Verification**:
   - Verify modal opens smoothly on row/card click.
   - Verify assigned employees list matches real MongoDB records.
   - Verify keyboard navigation (`Escape` closes modal).
