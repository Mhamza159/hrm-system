# Plan 25-04: Archive Tab, Modals Redesign Suite & Mandatory Employee Deletion Guard

**Phase**: 25 · Department Module — Critical Regression Fix, Complete Audit, RBAC/PBAC Compliance & UI/UX Refinement  
**Plan ID**: 25-04  
**Goal**: Implement the complete Archive tab, Revert/Restore modal, and Permanent Delete modal enforcing the critical business rule: **a department must NEVER be permanently deleted while even one employee remains assigned to it**. Modernize all modals per `DESIGN.md` and `docs/UI-REFERENCE.md`.

---

## 1. Critical Business Rule — Employee Assignment Restriction

> [!CRITICAL]
> **A department must NEVER be permanently deleted as long as one or more employees are assigned to it.**
> 
> Required Message:
> *"This department cannot be permanently deleted because employees are still assigned to it. Please reassign all employees to another department before proceeding."*

Both frontend and backend must independently enforce this rule:
1. Backend checks `Employee.countDocuments({ departmentId: id, isDeleted: false }) > 0` before deletion.
2. Frontend inspects the department's assigned headcount; if `headcount > 0`, the permanent delete button is locked/disabled and a prominent amber/rose warning banner is displayed with the exact guidance message.

---

## 2. Scope of Work

1. **Archive Tab Implementation (`DepartmentsPage.jsx`)**:
   - Query archived departments from `GET /api/v1/departments/archived`.
   - Columns:
     - Department Name & Code.
     - Archived Date (`archivedAt`) formatted in `Asia/Karachi`.
     - Archived By (`archivedByName`).
     - Assigned Employee Headcount.
     - Actions: Inspect Details, Restore / Revert, Permanent Delete.
   - Separate pagination, search, and sorting.

2. **Restore / Revert Modal (`DepartmentRestoreModal.jsx`)**:
   - Modernized confirmation modal matching `DESIGN.md`.
   - Explains that the department will be restored to the active directory.
   - Checks for duplicate department codes or naming conflicts.
   - Reinstates active status, preserves existing employee assignments, and refreshes KPI stats.

3. **Permanent Delete Modal (`DepartmentPermanentDeleteModal.jsx`)**:
   - Displays department identity and live assigned employee count.
   - If `headcount > 0`:
     - Disables the deletion button.
     - Renders an authoritative warning: *"This department cannot be permanently deleted because employees are still assigned to it. Please reassign all employees to another department before proceeding."*
   - If `headcount === 0`:
     - Displays destructive warning that permanent deletion cannot be undone.
     - Calls `DELETE /api/v1/departments/:id/permanent`.
     - Handles loading state and shows toast alert on completion.

4. **Create / Edit Department Modal (`DepartmentModal.jsx`)**:
   - Form fields: Name, Code (uppercase alphanumeric), Description, Parent Division, Department Head.
   - Field validations, error handling, and toast feedback.

5. **Detailed Inspection Modal (`DepartmentDetailModal.jsx`)**:
   - Hierarchy breadcrumbs, parent division, department head card.
   - Full assigned staff roster table with employee code, name, designation, and email.
   - Audit trail metadata (created at, updated at).

6. **Verification**:
   - Verify modal opening/closing, animations, keyboard navigation (Escape), and theme styling.
   - Verify that permanent delete is locked when employees are assigned.
