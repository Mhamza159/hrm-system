# Plan 25-04: Redesigned Create & Edit Modals with Complete Searchable Employee Dropdown

**Phase**: 25 · Department Module — Complete UI Overhaul, Functional Audit, Analytics, RBAC/PBAC Compliance & Error Fixing  
**Plan ID**: 25-04  
**Goal**: Completely redesign the Create Department and Edit Department modals, creating a custom, reusable `EmployeeSelectDropdown` that provides complete, authentic employee data (photo/avatar, full name, employee code, designation, email, status) with zero generic or placeholder options.

---

## 1. Critical Requirement: Searchable Employee Dropdown

> [!CRITICAL]
> **Whenever an employee dropdown or selector is used in the Department Module, it must provide complete and accurate employee information.**
> Never show generic "Employee 1" items or incomplete partial names.

Requirements for `EmployeeSelectDropdown.jsx`:
- Fetches real candidates from `GET /api/v1/departments/heads/candidates`.
- Searchable input within dropdown to quickly filter by name, email, or employee code.
- Rich candidate item rendering:
  - Avatar image or styled initials capsule.
  - Complete employee name in bold.
  - Monospace employee code badge (e.g. `EMP-001`).
  - Current designation (e.g., `Senior Software Engineer`).
  - Current department tag.
  - Employment status indicator.
- Support selecting "Unassigned / None" to clear the department head.
- Keyboard accessible (up/down arrow keys, enter, escape).

---

## 2. Scope of Work

1. **Searchable Dropdown Component (`EmployeeSelectDropdown.jsx`)**:
   - Reusable controlled select component.
   - Handles loading states (`Loader2`), empty search results, and click-outside dismissal.
   - Clear value button (`X`).

2. **Create / Edit Department Modal Overhaul (`DepartmentModal.jsx`)**:
   - Field layout:
     - **Department Name**: Text input with real-time length counter.
     - **Department Code**: Monospace input auto-uppercased, validated for uniqueness.
     - **Parent Directorate**: Dropdown of active top-level departments (excluding self on edit).
     - **Department Head**: Powered by `EmployeeSelectDropdown`, displaying selected head's complete card.
     - **Description**: Textarea for primary responsibilities and operational mandate.
     - **Active Status**: Accessible toggle switch with explanatory caption.
   - Live form validation via Zod schema and inline error alerts.
   - Loading state on submit with disabled buttons preventing duplicate submissions.
   - Success toast feedback with automatic cache invalidation.

3. **Verification**:
   - Verify selecting an employee properly sets `headId`.
   - Verify clearing the selection properly detaches the head (`headId: null`).
   - Verify editing an existing department pre-populates the currently assigned head's complete card.
