# Plan 25-03: Active Department Listing, Data Table & Filter Modernization per DESIGN.md & UI-REFERENCE.md

**Phase**: 25 · Department Module — Critical Regression Fix, Complete Audit, RBAC/PBAC Compliance & UI/UX Refinement  
**Plan ID**: 25-03  
**Goal**: Modernize the Active Department Listing, KPI Stat Cards, Filter Toolbar, and Enterprise Data Table adhering strictly to `DESIGN.md` and `docs/UI-REFERENCE.md` in the Forest & Emerald Enterprise theme.

---

## 1. Design System Standards Compliance

- **Theme & Color Tokens**:
  - Light Canvas: `#F8FAFC`, Surface Cards: `#FFFFFF`, Borders: `#EAECF0`, Text: `#0F172A` (Heading) / `#334155` (Body).
  - Dark Canvas: `#0A110D`, Surface Cards: `#111D17`, Borders: `#1A3125`, Text: `#F8FAFC` (Heading) / `#CBD5E1` (Body).
  - Brand Primary Accent: `#00C471` (Emerald), Hover: `#049856`.
- **Typography & Formatting**:
  - Monospace font (`font-mono`, `text-xs`) for department codes (`code`).
  - Tabular numbers (`tabular-nums`) for employee headcounts and metrics.
  - Semantic status pills with light pastel backgrounds and dark bold text.

---

## 2. Scope of Work

1. **Dashboard KPI Stat Cards (`DepartmentStatsCards.jsx`)**:
   - 4-card responsive grid backed by `GET /api/v1/departments/stats`:
     - Total Departments: Total count of organizational units.
     - Active Departments: Units currently operating.
     - Archived Departments: Units archived in cold storage.
     - Staffed vs Empty: Count of departments with assigned employees vs empty units.
   - Micro-indicators, hairline borders (`border-slate-200 dark:border-[#1A3125]`), and dark surface background (`bg-white dark:bg-[#111D17]`).

2. **Unified Filter Toolbar (`DepartmentFilterBar.jsx`)**:
   - Search input with search icon, clear button, and debouncing.
   - Parent Division selector dropdown.
   - Status selector (All, Active, Inactive).
   - Reset filters button.

3. **Active Departments Data Table (`DepartmentsPage.jsx`)**:
   - Required columns:
     1. **Department Name**: Title, optional parent badge, and description preview.
     2. **Department Code**: Monospace emerald tag (e.g., `TECH`, `EXEC`).
     3. **Description**: Concise summary with fallback em-dash.
     4. **Employee Count**: Tabular badge with `Users` icon showing actual assigned headcount.
     5. **Status**: Semantic pill (`Active` in green, `Inactive` in slate).
     6. **Created Date**: Formatted date in `Asia/Karachi` timezone.
     7. **Last Updated**: Relative or formatted timestamp.
     8. **Actions**: Row actions (Inspect Details, Edit Department, Archive Department).
   - Empty state, loading skeleton (`ScreenSkeleton`), and error boundary.
   - Dual Tab Switcher: **Active Departments (N)** vs **Archived Departments (N)**.

4. **Verification**:
   - Verify table renders all active departments with correct headcounts and codes.
   - Verify light and dark mode appearance.
