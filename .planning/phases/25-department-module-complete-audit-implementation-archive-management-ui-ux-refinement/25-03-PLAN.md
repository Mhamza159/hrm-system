# Plan 25-03: Department Dashboard, Tabs (Active vs Archived), Filter Toolbar & Modernized Data Table

**Phase**: 25 · Department Module — Complete Audit, Implementation, Archive Management & UI/UX Refinement  
**Plan ID**: 25-03  
**Goal**: Overhaul the frontend Department Module interface with live KPI cards, dual view tabs (Active vs Archived), unified search and filtering toolbar, and high-density responsive data tables following the Forest & Emerald Enterprise theme.

---

## 1. Scope of Work

1. **KPI Summary Stat Cards (`frontend/src/features/departments/components/DepartmentStatsCards.jsx`)**:
   - Create reusable summary component receiving live stats from `useGetDepartmentStatsQuery`:
     - **Total Departments**: Overall count with building icon.
     - **Active Departments**: Operating business units with emerald pulse indicator.
     - **Archived Departments**: Units in cold storage with archive icon.
     - **With Staff**: Units with $\ge 1$ assigned personnel.
     - **Without Staff**: Empty units eligible for immediate restructuring or removal.
   - Polished styling with subtle borders (`border-slate-200 dark:border-[#1A3125]`) and theme-consistent typography.

2. **Filter Toolbar (`frontend/src/features/departments/components/DepartmentFilterBar.jsx`)**:
   - Instant search input with debouncing and clear button (`name` or `code`).
   - Parent Division filter dropdown (All, Top-Level, or specific parent unit).
   - Status filter pills (All, Active, Inactive) for active tab.
   - Quick Reset Filters and Live Refresh button with loading spinner.

3. **Dual View Tabs Navigation (`frontend/src/features/departments/pages/DepartmentsPage.jsx`)**:
   - Segmented button/pill tab switcher:
     - **Active Departments** (with dynamic badge count).
     - **Archived Departments** (with amber/slate count badge).
   - Switching tabs automatically updates table columns, actions, and pagination without reloading page.

4. **Active Departments Data Table**:
   - Modernized columns:
     - **Department**: Icon squircle, Department Name, Monospace Code Tag, Description.
     - **Parent Division**: Hierarchy pill with `Network` icon or "Top-Level Directorate".
     - **Department Head**: Avatar/initials badge and head name, or "Not Assigned".
     - **Staff Headcount**: Emerald badge showing count of assigned employees.
     - **Status**: Semantic `StatusBadge` (Active / Inactive).
     - **Actions**: Inspect (Eye), Edit (Edit2), Archive (Archive/FolderArchive).

5. **Archived Departments Data Table**:
   - Tailored columns:
     - **Department**: Squircle icon with muted tone, Department Name, Code tag, Description.
     - **Parent Division**: Previous parent division name.
     - **Assigned Staff**: Critical indicator — if headcount > 0, renders amber/rose badge (*"N staff assigned - must reassign before delete"*); if 0, renders neutral gray badge.
     - **Archived Metadata**: Date/time localized to `Asia/Karachi` and Archived By user name.
     - **Actions**:
       - **Inspect** (`Eye`): Opens detail drawer/modal.
       - **Restore** (`RotateCcw`): Opens confirmation modal to reinstate department.
       - **Permanent Delete** (`Trash2`): Opens destructive modal guarded by assigned staff count.

---

## 2. Verification Criteria
- [ ] Tabs switch seamlessly between Active and Archived lists with accurate badge counts.
- [ ] Summary cards reflect live backend numbers without mock data.
- [ ] Search and parent filters execute efficiently across both tabs.
- [ ] Archived table clearly flags whether staff are still assigned to an archived unit.
- [ ] Dark and light theme tokens strictly adhere to `DESIGN.md` and `docs/UI-REFERENCE.md`.
