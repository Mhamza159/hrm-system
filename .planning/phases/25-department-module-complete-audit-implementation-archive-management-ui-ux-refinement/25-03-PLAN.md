# Plan 25-03: Department Listing Redesign, Dual View Switcher (Table & Grid) & Advanced Multi-Filters

**Phase**: 25 · Department Module — Complete UI Overhaul, Functional Audit, Analytics, RBAC/PBAC Compliance & Error Fixing  
**Plan ID**: 25-03  
**Goal**: Overhaul the active department directory with a dual view switcher (high-density Enterprise Table View vs Department Cards Grid View), advanced multi-dimensional filtering, and full responsive behavior per `DESIGN.md` and `docs/UI-REFERENCE.md`.

---

## 1. Scope of Work

1. **Dual View Switcher (`DepartmentsPage.jsx`)**:
   - Header control to toggle between **Table View** (`List` icon) and **Card Grid View** (`LayoutGrid` icon).
   - Preserves active filters, sorting, and search state across view toggles.

2. **Enterprise Table View Refinement**:
   - High-density table columns:
     1. **Department Name & Hierarchy**: Unit name, monospace code badge (`font-mono text-[10px] bg-slate-100 dark:bg-[#1A3125] text-slate-700 dark:text-slate-300`), description snippet.
     2. **Parent Directorate**: Breadcrumb indicator showing parent hierarchy or "Top-Level Division".
     3. **Department Head**: Profile avatar with initial/photo, full name, and designation subtitle. Shows "Unassigned" badge if empty.
     4. **Staff Headcount**: Tabular numeric badge (`tabular-nums font-mono`) with `Users` icon.
     5. **Status**: Semantic pill (`Active` in green, `Inactive` in slate).
     6. **Created Date**: Formatted date in `Asia/Karachi` timezone (`DD MMM YYYY`).
     7. **Actions**: Fast action triggers for View/Inspect (`Eye`), Edit (`Edit2`), and Archive (`Archive`).

3. **Department Cards Grid View (`DepartmentCardView.jsx`)**:
   - Modern 3-column responsive card grid for visually oriented browsing.
   - Each card displays:
     - Header: Department icon, title, code tag, and status pill.
     - Body: Description, parent division badge.
     - Leadership section: Department head avatar, name, and designation.
     - Metrics footer: Headcount meter with member count.
     - Actions: Quick buttons to inspect details, edit, or archive.

4. **Advanced Multi-Filter Toolbar (`DepartmentFilterBar.jsx`)**:
   - Instant search input with keyboard shortcut tooltip (`⌘K` / `/`).
   - Parent Division filter dropdown.
   - Status filter: All, Active, Inactive.
   - Headcount filter: All, Staffed ($\ge 1$), Empty ($0$).
   - Leadership filter: All, Head Assigned, Unassigned Head.
   - Active filter tags with one-click clear all button.

5. **Verification**:
   - Verify table and card grid toggle seamlessly.
   - Verify responsive behavior on laptop, tablet, and mobile breakpoints.
