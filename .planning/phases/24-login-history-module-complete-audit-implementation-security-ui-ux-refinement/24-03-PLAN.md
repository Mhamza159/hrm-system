# Plan 24-03: Frontend RTK Query Expansion, Filter Toolbar, KPI Stat Cards & Data Table Modernization

## Goal
Expand the frontend authentication API slice (`authApi.js`) with login history queries, build responsive KPI summary metric cards, implement an intuitive multi-filter toolbar with date range pickers and status pills, and modernize the primary data table to match the Forest & Emerald Enterprise theme (`#061A14`, `#111D17`, `#1A3125`, `#00C471`).

## Proposed Changes

### 1. `frontend/src/features/auth/authApi.js`
- Enhance `getLoginHistory` query to support query parameters (`page`, `limit`, `startDate`, `endDate`, `status`, `deviceType`, `search`, `sortBy`).
- Add `getLoginHistoryStats` query endpoint:
  - Fetches `/auth/login-history/stats` with date range and filter parameters.
  - Provides `['LoginHistoryStats']` tag.
- Add `getLoginHistoryDetail` query endpoint:
  - Fetches `/auth/login-history/:id`.
  - Provides `['LoginHistoryDetail']` tag.

### 2. `frontend/src/features/auth/components/LoginHistoryStatsCards.jsx`
- Create a high-craft 4-to-5 metric card grid:
  - **Total Attempts**: Overall login volume in current filter window.
  - **Successful Logins**: Clean emerald metric with success percentage pill.
  - **Failed Attempts**: Rose metric with alert icon and failure percentage.
  - **Locked Out Accounts**: Amber shield icon tracking brute-force lockouts.
  - **Unique Accounts**: Indigo icon showing distinct user accounts authenticated.
- Cards feature skeleton loaders and clean responsive design.

### 3. `frontend/src/features/auth/components/LoginHistoryFilterBar.jsx`
- Design horizontal filter controls matching the application's craft design:
  - **Search input**: Debounced search by email, name, IP, or failure reason.
  - **Status filter pills**: All, Success (`#00C471`), Failed (`#EF4444`), Locked (`#F59E0B`), 2FA Pending (`#3B82F6`).
  - **Device Type selector**: All Devices, Desktop, Mobile, Tablet.
  - **Date Range inputs**: Fast presets (Today, Last 7 Days, Last 30 Days, Custom Range).
  - **Export button**: Dropdown or one-click CSV export with download status spinner.
  - **Reset filters button**: Instant filter reset.

### 4. `frontend/src/features/auth/pages/LoginHistoryPage.jsx`
- Redesign page following Forest & Emerald Enterprise theme:
  - `PageHeader` with title ("Authentication Audit Log" for HR/Admin, "My Login Activity & Security" for Employee), description, and live refresh button.
  - Adaptive Employee Mode: If regular employee, hide organizational search, adapt headers to personal security context, and show personal login metrics.
  - Responsive `DataTable` with columns:
    - **Timestamp (PKT)**: Dual line formatting (Date + Time in `Asia/Karachi` with relative time tag e.g. "2 hours ago").
    - **Account Identity**: Avatar initial, Employee Name, Email, and Employee Code badge.
    - **Role & Dept**: Role pill (Super Admin, HR, Employee) and department name.
    - **Status**: Tinted semantic status badges (`Success`, `Failed`, `Locked`, `2FA Challenged`, `Blocked`).
    - **IP Origin**: Formatted IP address with network type tag.
    - **Client Device**: Icon + Device type (Desktop, Mobile) + Browser (Chrome, Safari, Edge) + OS (Windows, macOS, Android).
    - **Notice / Failure Reason**: Clear failure description or "Authentication successful".
    - **Actions**: "Inspect Attempt" button opening detailed inspection modal.
  - Comprehensive states: loading skeleton, empty state, and attributed `ErrorState` with retry callback.

## Verification Criteria
- [ ] RTK Query endpoints successfully query login history with filters, stats, and export.
- [ ] KPI summary cards display real-time metrics computed from database records.
- [ ] Status pills and date presets filter the list dynamically without full page reloads.
- [ ] Table renders device, OS, browser, IP, and employee details cleanly in light and dark themes.
- [ ] Employee self-service view automatically adapts and hides administrative company-wide controls.
