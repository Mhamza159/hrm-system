# Plan 36-03: Employee ID Card Configuration & Live Interactive Preview Studio in Company Profile

## Objective
Upgrade the Employee ID Card preview inside `CompanyForm.jsx` from a static, hardcoded placeholder into a comprehensive, interactive **ID Card Configuration & Live Preview Studio**. Allow administrators to customize layouts (Vertical vs Horizontal), color themes (Elvara Forest, Emerald, Light, Midnight), field toggles (Blood Group, Emergency Contact, Barcode, QR Code type), validity periods, and back-side regulatory disclaimers, with real-time responsive CR80 physical badge rendering.

---

## Technical Context
- **Files Touched**:
  - `frontend/src/features/settings/components/IdCardConfigEditor.jsx` (New)
  - `frontend/src/features/settings/components/IdCardPreviewBadge.jsx` (New)
  - `frontend/src/features/settings/components/CompanyForm.jsx`
- **Dependencies**: Lucide icons, ISO/IEC 7810 ID-1 standard aspect ratio (~1.586 : 1).

---

## Detailed Implementation Steps

1. **Build `IdCardPreviewBadge.jsx`**:
   - Reusable component rendering high-fidelity front and back physical ID cards:
     - **Front View**: Company Logo, Company Name, Employee Photo/Avatar, Full Name, Designation, Department, Employee Code, Blood Group badge, Joining Date, QR Code, and Barcode.
     - **Back View**: Magnetic stripe / Chip simulation header, Emergency Contact details, Organization Address & Phone, QR verification badge, and Legal Return Disclaimer.
   - Strict CR80 geometry support:
     - Vertical Mode: `aspect-[54/86]` (Portrait badge).
     - Horizontal Mode: `aspect-[86/54]` (Landscape badge).
   - Theme styling:
     - `forest`: Elvara Forest `#061A14` with Emerald `#00C471` accent.
     - `emerald`: Emerald `#00C471` header with Clean White surface.
     - `light`: Clean Executive Slate-50 surface with Dark Typography.
     - `dark`: Carbon Black `#0D1117` with Neon Accent.

2. **Build `IdCardConfigEditor.jsx`**:
   - Configuration controls panel:
     - Layout Selector: Vertical (Portrait) vs Horizontal (Landscape).
     - Theme Selector: Forest, Emerald, Light, Dark.
     - Primary Color picker / Preset pills (`#00C471`, `#2563EB`, `#7C3AED`, `#EA580C`).
     - Display Toggles: Blood Group, Emergency Contact, Department, Designation, Joining Date, Barcode.
     - QR Code Type: `verification` (secure scan URL) vs `contact` (vCard) vs `profile`.
     - Validity Duration: 1 to 5 years (auto-calculates Valid Until from issue date).
     - Back-side Disclaimer text area.

3. **Integrate into `CompanyForm.jsx`**:
   - Add "Configure ID Card Design" accordion / modal / tab.
   - Live interactive front/back flip toggle in the preview pane.
   - Synchronize configuration state with `formData.idCardConfig`.
   - Persist configuration seamlessly on "Save Company Profile".

---

## Verification Criteria
- [ ] Changing layout, theme, or toggles in `IdCardConfigEditor` immediately updates `IdCardPreviewBadge`.
- [ ] Front/Back switcher toggles between employee identity front and regulatory back view.
- [ ] Saved `idCardConfig` persists to backend and reloads accurately on page refresh.
- [ ] Supports dark and light modes cleanly with zero visual artifacts.
