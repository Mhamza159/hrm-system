# Plan 36-02: Company Logo Removal Confirmation Modal & Text-Fields Redesign Studio

## Objective
Replace browser-native `window.confirm()` with a dedicated, enterprise-grade `CompanyLogoRemoveModal.jsx`. Build a categorized, multi-tab `CompanyProfileEditModal.jsx` for all corporate text fields with client-side Zod validation, clear error messages, and seamless light/dark mode support adhering strictly to Elvara Forest (`#061A14`) & Emerald (`#00C471`).

## Detailed Implementation Steps

1. **Build `CompanyLogoRemoveModal.jsx`**:
   - Displays the current company logo (or brandmark placeholder).
   - Clear warning explaining that removal will reset the entire system (Sidebar, Topbar, Payslips, ID Cards, Email headers) to the default brandmark.
   - Distinct "Cancel" and "Confirm Remove" buttons.
   - Loading spinner on action during `DELETE /api/v1/settings/company/logo` request.
   - Prevents duplicate clicks, closes cleanly on Cancel, triggers success toast on completion.

2. **Build `CompanyProfileEditModal.jsx`**:
   - Structured into 5 logical, navigable field categories:
     1. **General Corporate Identity**: Company Name, Legal Company Name, Industry, Business Type, Brief Description.
     2. **Contact & Online Presence**: Official Email, Primary Phone, Alternate/Support Phone, Official Website URL.
     3. **Statutory & Tax Coordinates**: National Tax Number (NTN), Sales Tax Registration (STRN), Corporate SECP / Registration Number.
     4. **Physical Headquarters**: Street Address, City, State / Province, Postal Code, Country.
     5. **Regional Localization**: Canonical Timezone (`Asia/Karachi`), Operating Currency (`PKR`).
   - Clean floating inputs, clear required indicators (`*`), field-level validation with real-time error messages.
   - Form state management: preserves user inputs on server errors; cancel button reverts uncommitted changes.

3. **Refactor `CompanyForm.jsx`**:
   - Clean up existing flat input controls; present high-level corporate overview cards with an "Edit Profile Details" button triggering `CompanyProfileEditModal`.
   - Wire the "Remove Logo" button to open `CompanyLogoRemoveModal`.
   - Update RTK query cache invalidation so updates refresh the UI immediately without manual browser reload.

---

## Verification Criteria
- [ ] Clicking "Remove Logo" opens `CompanyLogoRemoveModal` without calling `window.confirm()`.
- [ ] Confirming removal executes `DELETE /api/v1/settings/company/logo`, resets the preview, and displays success toast.
- [ ] `CompanyProfileEditModal` allows editing all 5 corporate categories with full validation.
- [ ] Saved changes persist to MongoDB Atlas and refresh across the settings panel immediately.
