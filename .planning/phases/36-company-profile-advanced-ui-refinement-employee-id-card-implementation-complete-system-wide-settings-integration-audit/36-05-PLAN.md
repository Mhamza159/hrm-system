# Plan 36-05: Employee Module ID Card Management Workflow (View, Preview, Download, Print)

## Objective
Implement a complete Employee ID Card management workflow inside the Employee Module. Build `EmployeeIdCardModal.jsx` with front/back inspection, dedicated physical badge print formatting (`@media print` for standard CR80 cards), PNG/PDF badge download, and integrate it seamlessly across `EmployeeProfilePage.jsx`, `EmployeeListPage.jsx`, and `MyProfilePage.jsx`.

---

- **Files Touched**:

  - `frontend/src/features/employees/pages/EmployeeListPage.jsx`

## Detailed Implementation Steps

1. **Extend `employeesApi.js`**:
   - Define `getEmployeeIdCard: builder.query({ query: (id) => `/employees/${id}/id-card`, providesTags: ['Employees'] })`
   - Define `getMyIdCard: builder.query({ query: () => `/employees/me/id-card`, providesTags: ['Employees'] })`

2. **Build `EmployeeIdCardModal.jsx`**:
   - Multi-tab front/back view of the official employee card rendered using `IdCardPreviewBadge`.
   - Real-time employee coordinates:
     - High-res photo with fallback to clean monogram avatar.
     - Full Name, Designation, Department, Employee Code.
     - Blood Group badge, Joining Date, Issue Date, Expiration Date.
     - Dynamic QR Code (rendered with SVG QR code library or canvas) and Barcode.
     - Back side with Emergency Contact name/phone and return disclaimer.
   - **Print Card Action**:
     - Uses CSS `@media print` rules specifically isolating the ID card container:
       - Hides modal backdrop, buttons, and app shell during print.
       - Centers front and back cards on the printed page with physical dimensions 85.6mm × 53.98mm.
   - **Download Card Action**:
     - Captures badge via `html2canvas` or generates printable image/PDF payload.
   - **Regenerate / Sync Action**:
     - Re-fetches the latest employee and company settings from server.

3. **Integrate into Employee Views**:
   - **`EmployeeProfilePage.jsx`**:
     - Add "ID Card" button with `CreditCard` icon in the profile header actions menu (accessible to authorized HR/Admin and the employee themselves).
   - **`EmployeeListPage.jsx`**:
     - Add "View ID Card" option in the row dropdown menu.
   - **`MyProfilePage.jsx`**:
     - Add "My ID Card" quick-action button on the personal employee profile.
