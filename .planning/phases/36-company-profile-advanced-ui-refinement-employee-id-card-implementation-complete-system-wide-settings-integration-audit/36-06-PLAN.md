# Plan 36-06: Complete System-Wide Settings Integration Audit & Implementation (Sidebar, Login, Careers, PDFs, Reports)

## Objective
Audit and refactor every hardcoded company branding and coordinate reference across the entire HRMS. Connect the application layout, public login and careers portals, PDF document generators (Payslips, Offer Letters, Experience Certificates), and report export engines directly to the central `SettingService` and public settings API. Ensure immediate cache invalidation and UI synchronization across the system upon company profile updates.

## Detailed Implementation Steps

1. **Frontend App Layout & Sidebar (`Sidebar.jsx`)**:
   - Query company profile settings using `useGetPublicPoliciesQuery()` or `useGetSettingsQuery()`.
   - Replace hardcoded `"ELVARA"` with dynamic `company?.name || 'ELVARA'`.
   - If `company?.logoUrl` exists, render company logo with clean fallback to the Elvara brandmark icon if no custom logo is uploaded.

2. **Public Portals (`LoginPage.jsx`, `CareersPublicPage.jsx`, `ApplyPage.jsx`)**:
   - In `LoginPage.jsx`: Fetch public policies and display dynamic company name and logo in hero badge and brand pill.
   - In `CareersPublicPage.jsx`: Render dynamic company name in header, hero, and copyright footer (`© {year} {company.name}`).
   - In `ApplyPage.jsx`: Render `{company.name} TALENT ACQUISITION`.

3. **Backend Document PDF Generators**:
   - **`payslipPdf.service.js`**:
     - Fetch `company = await SettingService.getSetting('company')`.
     - Replace hardcoded `'HRM ENTERPRISE SUITE'` with `company.name`.
     - Print dynamic `company.address`, `company.ntn`, and `company.phone` in the salary slip header banner.
   - **`offerPdf.service.js`**:
     - Replace default `'HRM Enterprise Suite'` with dynamic company name from `SettingService.getSetting('company')`.
     - In `recruitment.controller.js` line 235 (`downloadOfferLetterPdf`), fetch company profile and pass `companyName: company.name`.
   - **`onboarding.service.js`**:
     - In `generateServiceLetterPdf`, fetch `company = await SettingService.getSetting('company')`.
     - Replace hardcoded `'HRM ENTERPRISE SUITE'` with `company.name`.
     - Replace generic address with `company.address`.
   - **`reportExport.service.js`**:
     - In `generatePdfReport`, replace hardcoded `'HRM Enterprise Suite'` in the subtitle with dynamic company name.

4. **Cache Invalidation & Instant Live Update**:
   - Ensure `SettingService.updateSetting('company', ...)` invalidates in-memory cache.
   - Ensure frontend RTK Query invalidates `['Settings']` tags so Topbar, Sidebar, and open views refresh immediately with zero stale state.
