# Plan 36-01: Backend Core Schema Extension, Zod Validators, ID Card Config & SettingService Cache Bus

## Objective
Extend the `company` settings schema in `backend/src/modules/settings/` to support the full enterprise corporate profile (Legal Name, SECP/Registration No., Industry, Description, Alternate Phone, City, State, Country, Postal Code, Timezone, Currency) and the newly formalized `idCardConfig` specification. Ensure fast O(1) in-memory cache bus invalidation and comprehensive audit log tracking.

---

## Technical Context
- **Files Touched**:
  - `backend/src/modules/settings/setting.validation.js`
  - `backend/src/modules/settings/setting.service.js`
  - `backend/src/modules/settings/setting.controller.js`
- **Dependencies**: Zod, Setting Model, In-memory cache bus (`SettingService.settingsCache`), AuditLogService.

---

## Detailed Implementation Steps

1. **Extend `setting.validation.js`**:
   - Define `idCardConfigSchema`:
     ```javascript
     export const idCardConfigSchema = z.object({
       layout: z.enum(['vertical', 'horizontal']).default('vertical'),
       primaryColor: z.string().default('#00C471'),
       theme: z.enum(['forest', 'emerald', 'light', 'dark']).default('forest'),
       showBloodGroup: z.boolean().default(true),
       showEmergencyContact: z.boolean().default(true),
       showDepartment: z.boolean().default(true),
       showDesignation: z.boolean().default(true),
       showJoiningDate: z.boolean().default(true),
       showBarcode: z.boolean().default(true),
       qrCodeType: z.enum(['verification', 'contact', 'profile']).default('verification'),
       cardValidityYears: z.number().int().min(1).max(10).default(2),
       backDisclaimer: z.string().max(300).default('This credential card remains the property of the organization. If found, please return to Human Resources.')
     });
     ```
   - Extend `companyProfileSchema`:
     - Add `legalName` (string max 120, optional).
     - Add `registrationNumber` (string max 50, optional).
     - Add `industry` (string max 80, optional).
     - Add `businessType` (string max 60, optional).
     - Add `description` (string max 500, optional).
     - Add `alternatePhone` (string max 25, optional).
     - Add `city` (string max 60, optional).
     - Add `state` (string max 60, optional).
     - Add `postalCode` (string max 20, optional).
     - Add `country` (string max 60, default 'Pakistan').
     - Add `timezone` (string default 'Asia/Karachi').
     - Add `currency` (string default 'PKR').
     - Add `idCardConfig` (optional `idCardConfigSchema`).

2. **Update `DEFAULT_SETTINGS.company` in `setting.service.js`**:
   - Provide complete fallback blueprint containing all corporate coordinates and default `idCardConfig`.
   - Update `getPublicPolicies()` in `setting.service.js` to expose sanitized public corporate attributes (`name`, `legalName`, `address`, `city`, `country`, `phone`, `email`, `website`, `logoUrl`, `timezone`, `currency`) without exposing confidential tax registration identifiers.

3. **Cache Bus & Audit Logging Verification**:
   - Confirm `updateSetting('company', ...)` invalidates `settingsCache.delete('company')` and broadcasts the update.
   - Confirm before/after diffs are captured in `AuditLog` under category `settings`.
