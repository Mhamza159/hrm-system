# Plan 07-01: Backend Lifecycle & Deletion Guard Hardening

## Objective
Extend Asset Management backend services and API endpoints to support full Active/Archive lifecycle management (`restoreAsset`, `permanentDeleteAsset`, and archived query support) and harden the business invariant preventing any currently assigned asset from being deleted.

---

## Tasks

### Task 1: Extend Asset Service with Restore & Permanent Delete
- In [`backend/src/modules/assets/asset.service.js`](file:///c:/Users/hamih/OneDrive/Desktop/AtoZ%20Coder/Advanced%20MERN/HRM/backend/src/modules/assets/asset.service.js):
  - In `getAssets({ query, user, ... })`:
    - Check if `query.archived === 'true' || query.archived === true`.
    - If `true`, set `filter.isDeleted = true` and compute archived stats.
    - Otherwise, default `filter.isDeleted = false`.
  - In `deleteAsset({ id, user, ... })`:
    - Strict invariant check: If `asset.status === 'assigned' || asset.assignedTo`, throw `ApiError(400, 'Cannot delete an asset that is currently assigned to a custodian. Please return it to inventory first.')`.
  - Implement `restoreAsset({ id, user, ipAddress, userAgent })`:
    - Look up `Asset.findOne({ _id: id, isDeleted: true })`.
    - If not found, throw `ApiError(404, 'Archived asset not found')`.
    - Set `asset.isDeleted = false`, `asset.status = 'available'`.
    - Append to `asset.history`: action `'restored'`, `performedBy: user._id`, `notes: 'Restored from archive'`.
    - Record audit log with `action: 'asset.restore'`.
    - Return restored asset.
  - Implement `permanentDeleteAsset({ id, user, ipAddress, userAgent })`:
    - Look up `Asset.findOne({ _id: id })`.
    - If not found, throw `ApiError(404, 'Asset not found')`.
    - Invariant check: If `asset.status === 'assigned' || asset.assignedTo`, throw `ApiError(400, 'Cannot permanently delete an asset that is currently assigned to a custodian. Please return it to inventory first.')`.
    - Invariant check: Must be archived first (`if (!asset.isDeleted) throw new ApiError(400, 'Only archived assets can be permanently deleted. Please archive it first.')`).
    - Call `Asset.findByIdAndDelete(id)`.
    - Record audit log with `action: 'asset.permanent_delete'`.
    - Return success message.
