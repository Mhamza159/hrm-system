# Plan 07-02: Modern Custodian Dropdown & My Assets Page Overhaul

## Objective
Build a reusable, searchable employee custodian dropdown component (`CustodianSelect`) and completely redesign `MyAssetsPage.jsx` with dedicated filter pills, high-density enterprise tables, and an interactive row-click Asset Detail Modal.

---

## Tasks

### Task 1: Create Modern CustodianSelect Component
- In [`frontend/src/features/assets/components/CustodianSelect.jsx`](file:///c:/Users/hamih/OneDrive/Desktop/AtoZ%20Coder/Advanced%20MERN/HRM/frontend/src/features/assets/components/CustodianSelect.jsx):
  - Searchable dropdown supporting fast client-side filtering by employee name, `EMP-XXXX` code, or department.
  - Option card rendering:
    - Employee avatar / circular initials badge with emerald border.
    - Full Name in font-semibold text.
    - Monospace `EMP-XXXX` badge.
    - Department & Designation sub-text.
  - Keyboard navigation (Arrow keys, Enter, Escape) and click-outside dismissal.
  - Clear selection button and accessible ARIA attributes.
  - Integrated with `AssetAssignModal.jsx` and asset requisition allocation modals to eliminate raw `<select>` elements.

### Task 2: Build Interactive Asset Detail Modal
- In [`frontend/src/features/assets/components/AssetDetailModal.jsx`](file:///c:/Users/hamih/OneDrive/Desktop/AtoZ%20Coder/Advanced%20MERN/HRM/frontend/src/features/assets/components/AssetDetailModal.jsx):
  - Accessible modal dialog presenting comprehensive asset intelligence:
    - Header: Asset Tag (`tabular-nums font-mono`), Asset Name, Category badge, Status pill (`available`, `assigned`, `under_repair`, `retired`).
    - Identity & Hardware Specs Grid: Model Number, Serial Number, Processor, RAM, Storage, OS, Vendor.
    - Custody & Assignment Details: Current Custodian with `PersonRow` (avatar, name, email, department), Issue Date, Condition at assignment.
    - Warranty & Lifecycle Metrics: Purchase Date, Purchase Cost (in PKR), Warranty Expiration status chip (Active / Expiring Soon / Expired).
    - Maintenance / Issue History: Tabular listing of past repairs or reported defects with severity badges and resolution notes.
    - Action Controls:
      - For Employees (own asset): "Report Defect / Issue" trigger button.
      - For HR / Admin: "Assign Custodian", "Return to Inventory", "Send for Repair", "Edit Specifications".
      - Conditional action rendering via PBAC/RBAC.
