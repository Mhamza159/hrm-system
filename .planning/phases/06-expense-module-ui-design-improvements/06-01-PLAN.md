# Plan 06-01: Buttons, Pills, Semantic Badges & Category Detail Modal

## Objective
Elevate the shared UI primitives of the Expense Module. Implement the new `ExpenseCategoryDetailModal.jsx` to render complete category metadata (code, limits, receipt rules, descriptions, linked claims, timestamps, and contextual actions), update `expenseUi.jsx` with unified status badge & pill styles, and polish existing modal components (`ExpenseCategoryModal.jsx`, `ExpenseDecisionModal.jsx`, `ExpenseReimburseModal.jsx`).

## Tasks

### Task 1: Update `expenseUi.jsx` with Unified Semantic Pills and Status Badges
- Ensure `Pill` and `ExpenseStatusBadge` strictly use the codified color tokens from `DESIGN.md` §4:
  - Active / Required: `bg-emerald-50 text-emerald-700 border-emerald-200 dark:bg-emerald-950/40 dark:text-emerald-400 dark:border-emerald-800/60`
  - Optional / Inactive / Default: `bg-slate-100 text-slate-700 border-slate-200 dark:bg-[#15231C] dark:text-slate-300 dark:border-[#1A3125]`
  - In Review / Pending: `bg-violet-50 text-violet-700 border-violet-200 dark:bg-violet-950/40 dark:text-violet-400 dark:border-violet-800/60`
  - Approved / Authorised: `bg-teal-50 text-teal-700 border-teal-200 dark:bg-teal-950/40 dark:text-teal-400 dark:border-teal-800/60`
  - Reimbursed / Paid: `bg-cyan-50 text-cyan-700 border-cyan-200 dark:bg-cyan-950/40 dark:text-cyan-400 dark:border-cyan-800/60`
  - Rejected / Disabled: `bg-rose-50 text-rose-700 border-rose-200 dark:bg-rose-950/40 dark:text-rose-400 dark:border-rose-800/60`
- Export a reusable `CategoryPill` component with support for tone variants (`emerald`, `slate`, `rose`, `teal`, `violet`, `cyan`).

### Task 2: Build `ExpenseCategoryDetailModal.jsx`
- Create a dedicated detail modal for row-click inspection:
  - Header: Category name, code pill (`cat.code`), status pill (`Active` / `Inactive` / `Disabled`), and receipt requirement pill (`Receipt Required` / `Receipt Optional`).
  - Core Metric Cards:
    - Policy Max Limit per claim (`pkr(cat.maxLimitPaisa)` in tabular numbers or "No Limit").
    - Total Linked Claims (`cat.claimCount || 0`).
  - Guidance & Description Block:
    - Detailed policy rules or descriptive text explaining valid business expenses for this category.
  - Audit Trail & Lifecycle Metadata:
    - Created At / Updated At timestamps.
    - If archived: Archived date, time, and "Archived by" attribution.
    - Deletion Safety Notice: Clear explanation if linked claims exist, noting that records are safely retained for financial audits.
  - Contextual Actions Footer:
    - For Active categories: "Edit Category" button (launches edit modal) and "Archive" button (launches archive confirmation).
    - For Archived categories: "Revert / Restore" button (restores to active) and "Delete Forever" button (enabled only when claimCount === 0).

### Task 3: Polish Existing Modals
- Update `ExpenseCategoryModal.jsx`:
  - Enhance layout, alignment, input focus rings (`focus:ring-[#00C471]/30 focus:border-[#00C471]`), and submit button (`bg-[#00C471] hover:bg-[#049856]`).
- Update `ExpenseDecisionModal.jsx` and `ExpenseReimburseModal.jsx`:
  - Ensure balanced two-column summary grids, receipt zoom lightbox with clear close action, and aligned decision actions.
