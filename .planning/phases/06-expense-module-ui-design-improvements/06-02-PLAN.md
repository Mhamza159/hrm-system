# Plan 06-02: Categorize & Limit Tab and Archive Tab Overhaul

## Objective
Overhaul `ExpenseCategoriesPage.jsx` (`/expenses/categories`). Replace the fragile div-grid layout with high-craft, semantic HTML data tables with sticky headers, tabular figures, and full row-click support for opening `ExpenseCategoryDetailModal`. Streamline both the Active and Archive tabs with consistent button styling and clear lifecycle actions.

## Tasks

### Task 1: Refactor Active Categories View to Semantic Enterprise Table
- Replace `<ul><li>` div grids with a clean `<table>` structure:
  - `<thead className="bg-slate-50/75 dark:bg-[#0E1A14] text-[11px] uppercase tracking-wider text-slate-500 font-semibold border-b border-slate-200/80 dark:border-[#1A3125]">`
  - Columns:
    1. **Category Name & Description** (with icon badge)
    2. **Code** (monospace chip `font-mono px-2 py-0.5 rounded-md`)
    3. **Spending Limit per Claim** (right-aligned, monospace tabular-nums `font-mono font-medium`)
    4. **Receipt Policy** (semantic `CategoryPill`: `Required` emerald, `Optional` slate)
    5. **Status** (semantic `CategoryPill`: `Active` emerald, `Inactive` slate)
    6. **Actions** (right-aligned Pencil and Trash icon buttons with tooltip and stopPropagation)
- Add interactive row click:
  - Clicking any row triggers `setDetailCategory(cat)`, opening the `ExpenseCategoryDetailModal`.
  - Add `cursor-pointer hover:bg-slate-50/70 dark:hover:bg-[#15231C]/60 transition-colors` to each row.

### Task 2: Refactor Archive Tab View with Enhanced Information & Actions
- Implement the same semantic table structure for the Archive tab:
  - Columns:
    1. **Category Name** (with strikethrough styling and `Disabled` badge)
    2. **Code** (monospace chip)
    3. **Original Limit** (right-aligned, tabular-nums)
    4. **Archived Date & Actor** (tabular date and "by {actor}" label)
    5. **Linked Claims** (tabular count with warning indicator if claims > 0)
    6. **Actions** (Revert button and Delete Forever button with stopPropagation)
- Row click on archived categories also opens `ExpenseCategoryDetailModal` with the archived context and audit trail.

### Task 3: Polish Toolbar, Stats Cards, and Tab Switcher
- Modernize the top totals card grid (`Active categories`, `Receipt required`, `Archived`).
- Enhance the tab switcher with active emerald underlines (`border-[#00C471]`), count pill badges, and smooth transitions.
- Standardize the search box with `Search` icon and clear placeholder.

## Verification
- Verify build passes: `npm --prefix frontend run build`.
- Playwright verification: Click category rows in both active and archive tabs to confirm the detail modal opens seamlessly with all fields and actions intact.
