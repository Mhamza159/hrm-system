# Plan 06-03: Active Claims & Approvals Views Polish & Verification

## Objective
Harmonize the user experience across `MyExpensesPage.jsx` and `ExpenseApprovalsPage.jsx`. Update filter tabs to modern pill-style segmented controls with count badges, elevate table headers, ensure smooth row click modal/drawer transitions, and verify the entire Expense Module end-to-end.

## Tasks

### Task 1: Polish `MyExpensesPage.jsx`
- Modernize the KPI stats cards (Total claimed, In review, Approved unpaid, Reimbursed).
- Update the status filter tabs (`All`, `In review`, `Approved`, `Reimbursed`, `Rejected`) into elegant pill buttons with count indicators.
- Ensure the claims data table features crisp hairline dividers, monospace claim numbers, and currency values in tabular figures.
- Verify row click smoothly opens `ExpenseDetailDrawer.jsx` with full claim metadata, receipt image/document, and approval history trail.

### Task 2: Polish `ExpenseApprovalsPage.jsx`
- Refine executive tabs (`Awaiting manager`, `Escalated`, `Approved, to pay`, `Reimbursed`) with active emerald highlights and count indicators.
- Elevate table rows with `PersonRow` applicant avatar, designation, and department details.
- Ensure primary action buttons ("Review", "Reimburse") have clear visual hierarchy, emerald `#00C471` accents, and stopPropagation so row click opens detail modal while clicking the action button directly triggers the review/reimbursement modal.

### Task 3: Comprehensive Verification
- Run production build: `npm --prefix frontend run build`.
- Run backend automated test suite: `npm --prefix backend test -- tests/expenses.api.test.js`.
- Use Playwright to capture screenshots of:
  1. `/expenses/categories` (Active Tab with new table and opened Category Detail Modal).
  2. `/expenses/categories?tab=archive` (Archive Tab).
  3. `/expenses/approvals` (Approvals Queue).
  4. `/expenses` (My Claims).
