# Plan 28-05: Enterprise Role Directory Overhaul, Dual View Switcher (Table vs Cards) & Multi-Dimensional Filter Toolbar

## Goal
Overhaul the role listing experience in `RolesListPage.jsx` into a high-density, enterprise-grade command center. Implement a dual view switcher offering seamless toggling between a High-Density Enterprise Table View and a rich visual Role Cards Grid View (`RoleCardView.jsx`). Add a multi-dimensional filter toolbar with active search, role type selector, permission coverage threshold, and dismissible filter chips, with shared pagination controls across both views.

## Target Files
- `frontend/src/features/roles/pages/RolesListPage.jsx`
- `frontend/src/features/roles/components/RoleCardView.jsx`
- `frontend/src/features/roles/components/RoleFilterBar.jsx`
- `frontend/src/features/roles/components/RoleRowActions.jsx`

## Dual View Modes Specification
1. **High-Density Enterprise Table View**:
   - Columns:
     - `Role Name & Slug`: Bold role name, monospace slug, and protected system crown badge (`Crown`).
     - `Type`: Emerald badge for `System Role`, Slate/Indigo badge for `Custom Role`.
     - `Assigned Staff`: Avatar stack with +N overflow count, total headcount pill, and link to view assigned users.
     - `Permissions Count`: Progress bar displaying granted permissions count out of total catalogue.
     - `Module Scope Summary`: Micro-pills showing top accessible modules (e.g. `Attendance`, `Leaves`, `Payroll`).
     - `Status`: Green badge for `Active`, Amber for `Inactive`.
     - `Actions`: Context menu button (`MoreVertical`) with View Details, Edit, Clone, Assign Users, and Delete/Archive.
2. **Visual Role Cards Grid View (`RoleCardView.jsx`)**:
   - Responsive grid (1 col mobile, 2 col tablet, 3 col desktop).
   - Forest & Emerald card container (`#0F111A` / `#111D17`) with emerald hover halo.
   - Header: Shield icon, role title, system badge, and action trigger.
   - Body: Description snippet, assigned user avatars with headcount, and permission density mini-gauge.
   - Module tags: Top 3 module badges with "+X more" counter.
   - Footer: Quick action buttons ("Edit Permissions", "View Details", "Clone").

## Multi-Dimensional Filter Toolbar Specification (`RoleFilterBar.jsx`)
- Full-text search with debounce (`name`, `slug`, `description`).
- Role Type Filter: `All`, `System Roles Only`, `Custom Roles Only`.
- Headcount Status: `All`, `Staffed Roles (≥1)`, `Empty Roles (0)`.
- Active Status: `All`, `Active`, `Inactive`.
- View Mode Toggle: High-density Table vs. Card Grid with persisted preference in localStorage.
- Dismissible active filter chips showing count and single-click "Clear All Filters" button.
- Automatic page reset (`setPage(1)`) whenever search or filters are altered.

## Verification & Acceptance Criteria
- Seamless switching between Table and Card Grid views without losing scroll position or filter state.
- Applying any filter while on Page 2+ resets pagination to Page 1 cleanly.
- System roles are visibly distinguished from custom roles and protected from accidental deletion.
- Shared pagination controls work identically in both Table and Card Grid modes.
