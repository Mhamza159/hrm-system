# Plan 28-07: Role Create/Edit, Detailed Inspection, Cloning & User Multi-Role Assignment Modals

## Goal
Redesign and implement the complete suite of lifecycle modals for Role Management: Role Details Inspection Modal (`RoleDetailModal.jsx`), Role Cloning Modal (`RoleCloneModal.jsx`), Guarded Role Deletion/Deactivation Modal (`RoleDeleteModal.jsx`), and User Multi-Role Assignment Modal (`UserRoleAssignModal.jsx`). Ensure that system roles are locked from mutation, duplicate role names are caught with friendly validation, and active user assignment guards prevent corrupt state.

- `frontend/src/features/roles/components/RoleCloneModal.jsx`

## Modals Suite Specification
1. **Role Detail Inspection Modal (`RoleDetailModal.jsx`)**:
   - Header: Role title, slug, type pill (`System` vs `Custom`), and status badge.
   - Tab 1: **Assigned Permissions Overview**: Grouped by module with scope tags and limits.
   - Tab 2: **Assigned Staff Roster**: Paginated and searchable table of employees holding this role (avatar, name, employee code, department, email).
   - Tab 3: **Audit History**: Creation timestamp, last modified by, and recent audit log events.
2. **Role Cloning Modal (`RoleCloneModal.jsx`)**:
   - Source role summary with current permission count.
   - Form fields: `New Role Name` (auto-suggests "Copy of {Original}"), `Slug`, `Description`.
   - Real-time client validation preventing collision with existing role names.
   - Clones all permissions and scopes with `isSystem: false`.
3. **Guarded Role Deletion / Deactivation Modal (`RoleDeleteModal.jsx`)**:
   - **System Role Guard**: If `isSystem: true`, completely blocks deletion with explanatory banner: *"Core system roles are essential for system integrity and cannot be deleted."*
   - **Assigned User Guard**: If `userCount > 0`, warns administrator that $\ge 1$ staff member holds this role, displaying the list of affected users and blocking deletion until reassigned.
   - Soft-delete confirmation with double verification for empty custom roles.
4. **User Multi-Role Assignment Modal (`UserRoleAssignModal.jsx`)**:
   - Allows HR Managers and Super Admins to assign or revoke roles for an employee.
   - Multi-select checkbox list with search, system badges, and role descriptions.
   - **Privilege Escalation Guard**: Prevents non-Super Admin actors from selecting or assigning `Super Admin` or any role with privileges exceeding their own.
   - Effective permissions preview showing additive result of combined roles.

## Verification & Acceptance Criteria
- Modals follow Forest & Emerald styling with accessible focus traps and Escape key dismissal.
- System roles cannot be deleted or renamed under any circumstance.
- Custom roles with active users cannot be purged without reassigning users first.
- Role cloning creates an exact duplicate of permissions under a new unique name in < 1 second.
