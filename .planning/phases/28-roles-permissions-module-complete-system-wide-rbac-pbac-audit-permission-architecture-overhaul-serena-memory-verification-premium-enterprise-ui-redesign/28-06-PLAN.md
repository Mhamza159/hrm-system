# Plan 28-06: High-Performance Visual Permission Matrix Studio & Bulk Control Overhaul

## Goal
Completely overhaul the visual permission assignment studio in `PermissionMatrix.jsx` and `RoleFormPage.jsx`. Address performance bottlenecks when rendering and mutating 100+ permissions across 26+ modules. Implement sticky category navigation, hierarchical module groupings (Module $\rightarrow$ Resource $\rightarrow$ Action), bulk controls (Select All, Deselect All, Module-level toggles), fine-grained data scope selectors (`all`, `department`, `team`, `own`), numerical approval limit controls, dependency validation, and an unsaved changes bottom bar with diff review.

## Target Files
- `frontend/src/features/roles/components/PermissionMatrix.jsx`
- `frontend/src/features/roles/pages/RoleFormPage.jsx`
- `frontend/src/features/roles/components/PermissionDiffModal.jsx`
- `frontend/src/features/roles/components/PermissionScopePopover.jsx`

## Architecture & Interaction Design
1. **Hierarchical Categorization & Quick Jump Navigator**:
   - Sidebar/sticky top module category tabs:
     - `Core HR`
     - `Time & Attendance`
     - `Payroll & Finance`
     - `Talent & Operations`
     - `Governance & Communication`
   - Smooth scroll jump navigation to target module section on click.
2. **Tri-State Checkbox & Bulk Actions**:
   - Primary emerald check styling (`#00C471`).
   - Module Header controls:
     - "Select All" / "Deselect All" for the entire module.
     - Tri-state checkbox (checked, indeterminate, unchecked) reflecting module's selection ratio.
     - Bulk scope dropdown applying default scope across all actions in that module.
3. **Fine-Grained Permission Row**:
   - Checkbox with action name and human-readable explanation.
   - Resource tag (e.g. `Attendance`, `Employee`, `Payroll`).
   - Data Scope Dropdown: `All Company`, `Department Only`, `Direct Team`, `Self Only` (restricted to action's `allowedScopes`).
   - Approval Limit input: for actions supporting limits (e.g., leave approval max days, expense approval max PKR amount).
4. **Dependency Validation & Safety Guards**:
   - If an action requires a prerequisite (e.g. `employee.edit` requires `employee.view`), automatically prompt or auto-grant the dependency.
   - Warning banner if attempting to grant mutation privileges without read access.
5. **Sticky Unsaved Changes Bar & Pre-Save Diff Modal**:
   - Sticky bar pinned to the bottom of the viewport when dirty state is detected.
   - Displays number of added permissions, modified scopes, and removed permissions.
   - "Review Diff & Save" button opening `PermissionDiffModal.jsx` showing side-by-side before/after changes before committing to backend.

## Detailed Implementation Tasks
- [ ] **Task 1: Performance Optimization & Virtualization**:
  - Memoize `PermissionRow` with strict custom equality check on `[isChecked, currentScope, currentLimit, readOnly]`.
  - Use React `useCallback` and state updater functions to avoid re-rendering unrelated module rows on single toggle.
- [ ] **Task 2: Module-Level Bulk Operations & Scope Setting**:
  - Implement `toggleModulePermissions(moduleName, boolean)` batching updates into a single state mutation.
  - Implement `setModuleBulkScope(moduleName, scope)` updating all active rules in that module.
- [ ] **Task 3: Permission Scope Selector & Info Popover**:
  - Accessible dropdown with visual scope indicators and clear explanatory tooltips (`all`, `department`, `team`, `own`).
  - Restrict options to the specific `allowedScopes` defined in `permissions.js`.
- [ ] **Task 4: Pre-Save Diff Summary Modal (`PermissionDiffModal.jsx`)**:
  - Compares `permissions` against `originalSnapshot.permissions`.
  - Renders added actions in green (`+`), modified scopes in amber (`~`), and revoked actions in red (`-`).
  - Single-click confirmation invoking `updateRole` or `createRole` mutation.

## Verification & Acceptance Criteria
- Matrix renders instantly without lag or UI stutter across all 26 modules and 100+ permissions.
- Toggling a single permission updates in < 16ms without re-rendering the whole page.
- "Select All" correctly selects all actions in the module with their default scopes.
- Diff modal accurately itemizes all changes before persisting to MongoDB.
