## Automated E2E Test Suite Scope (`roles.overhaul.e2e.test.js`)
1. **Core System Roles Integrity**:
   - `Super Admin` bypasses all checks (`can('manage', 'all')`).
   - `Super Admin` role cannot be deleted via `DELETE /api/v1/roles/:id` (returns 400).
   - `Super Admin` role cannot be renamed or demoted via `PATCH /api/v1/roles/:id` (returns 400).
   - Core system roles (`HR Manager`, `Department Manager`, `Employee`) cannot be deleted (returns 400).
2. **Custom Role Full Lifecycle**:
   - Create custom role with specific permissions and data scopes (`POST /api/v1/roles`).
   - Verify newly created role appears in `GET /api/v1/roles`.
   - Update custom role permissions matrix (`PATCH /api/v1/roles/:id`).
   - Clone custom role under new name (`POST /api/v1/roles/:id/clone`).
   - Assign custom role to user (`PATCH /api/v1/users/:id/roles`).
   - Verify deletion of role with active users is blocked (returns 409).
   - Soft delete custom role when no users are assigned (`DELETE /api/v1/roles/:id`).
3. **Privilege Escalation Defenses**:
   - Non-Super Admin cannot assign the Super Admin role to any user (returns 403).
   - HR Manager cannot grant permissions they do not possess (returns 403).
   - Regular employee cannot call any mutation endpoint in `/api/v1/roles` (returns 403).
4. **Approval Delegation Workflows**:
   - Create temporary delegation from Manager A to Manager B (`POST /api/v1/delegations`).
   - Verify self-delegation is rejected with 400.
   - Verify end date before start date is rejected with 400.
   - Verify Manager B receives Manager A's approval powers during active window.
   - Cancel delegation (`PATCH /api/v1/delegations/:id/cancel`).
5. **Cross-Module API 403 Verification**:
   - Employee token calling `POST /api/v1/employees` receives 403 Forbidden.
   - Employee token calling `POST /api/v1/departments` receives 403 Forbidden.
   - Employee token calling `POST /api/v1/shifts` receives 403 Forbidden.
   - Employee token calling `POST /api/v1/payroll/runs` receives 403 Forbidden.
   - Department Manager token calling `GET /api/v1/payroll` receives 403 Forbidden.
6. **Live Analytics & Metrics Aggregation**:
   - `GET /api/v1/roles/stats` returns accurate counts for total, active, system, and custom roles.
   - `GET /api/v1/roles/analytics` returns verified workforce distribution and module permission coverage.
