# Plan 28-04: Roles & Permissions Dashboard Analytics, 8-KPI Summary Cards & SVG Visualizations

## Goal
Design and implement an enterprise-grade analytics header and visual dashboard for the Roles & Permissions Module (`RolesListPage.jsx`) following the Forest & Emerald Enterprise theme (`#061A14`, `#111D17`, `#1A3125`, `#00C471`). Replace static or placeholder cards with 8 live database-backed KPI summary cards and two interactive zero-dependency SVG visualizations: a Role Workforce Distribution Bar Chart and a Module Permission Coverage Donut Chart.

## Target Files
- `frontend/src/features/roles/components/RoleStatsCards.jsx`
- `frontend/src/features/roles/components/RoleAnalyticsSection.jsx`
- `frontend/src/features/roles/pages/RolesListPage.jsx`
- `frontend/src/features/roles/rolesApi.js`

## 8 KPI Summary Cards Specification
1. **Total Roles**: Total count of active and system roles in company directory.
2. **Active Roles**: Count of non-archived, fully enabled roles. Clicking filters list to `active`.
3. **System Roles**: Count of protected core roles (`Super Admin`, `HR Manager`, `Dept Manager`, `Employee`). Clicking filters list to `system`.
4. **Custom Roles**: Count of tenant-created specialized roles. Clicking filters list to `custom`.
5. **Staff Assigned**: Total number of unique active employees with at least one assigned role.
6. **Total Permissions**: Count of distinct registered actions across all 26+ modules in catalogue.
7. **Permission Coverage**: Percentage of registered permissions assigned to at least one non-admin role.
8. **Active Delegations**: Count of currently active managerial approval delegations.

## Native SVG Visualizations Specification
1. **Role Workforce Distribution Bar Chart (`RoleDistributionChart.jsx`)**:
   - Visualizes the headcount of staff assigned to each role using horizontal flex-bars styled in forest and emerald gradients.
   - Shows role name, pill badge (System vs Custom), headcount, and percentage of workforce.
   - Interactive hover state displaying exact user list count and preview tooltip.
2. **Module Permission Coverage Donut Chart (`ModulePermissionDonut.jsx`)**:
   - Native SVG Donut chart displaying permission density grouped by module categories:
     - `Core HR` (Auth, Roles, Employees, Org) — Emerald `#00C471`
     - `Time & Attendance` (Shifts, Clock-in, WFH, Geo) — Forest `#10B981`
     - `Payroll & Finance` (Payroll, Loans, Expenses) — Teal `#14B8A6`
     - `Talent & Operations` (Recruitment, Performance, Assets) — Cyan `#06B6D4`
     - `Governance & Communication` (Policies, Chat, Announcements) — Indigo `#6366F1`
   - Center summary showing Total Permissions and active category count.
   - Interactive legend with toggleable segment highlighting.
