# Plan 14-01: Directory Overhaul, Dual View (Data Table & Card Grid) & Advanced Filters

## Goal
Completely redesign `frontend/src/features/employees/pages/EmployeeListPage.jsx` to feature a seamless dual-view switcher (`Table View` vs `Card Grid View`), high-density data tables, responsive modern employee cards, triple status buckets (`Active Workforce`, `Inactive / Suspended`, `Archive Bucket`), advanced faceted filters, and strict PBAC action gating.

## Scope & Implementation Details

1. **Dual-View Switcher (`Table View` vs `Card Grid View`)**:
   - Modern toggle controls in the toolbar (`LayoutList` for table view, `LayoutGrid` for card grid view).
   - User's view preference stored in component state (or `localStorage`) so switching persists across filters and pagination.

2. **Card Grid View Implementation**:
   - Modern, pixel-perfect employee cards adhering strictly to Forest & Emerald Enterprise Craft:
     - Surface: `bg-white dark:bg-[#111D17]` with 1px border `border-slate-200 dark:border-[#1A3125]` and subtle hover elevation.
     - Top row: Avatar with initials fallback, full name, employee code badge, status pill.
     - Details grid: Designation, Department with building icon, Shift with clock icon, Reporting Manager with user check icon.
     - Quick contact strip: Email and Phone with clean icon tags.
     - Quick action buttons: View Details (opens modal), Edit (if permitted), More action menu.
   - Consistent card dimensions, hover effects, and responsive grid (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`).

3. **Data Table View Redesign**:
   - High-density semantic table with clean alignment:
     - `Code`: Monospaced badge with dark mode styling.
     - `Employee`: Avatar + Full Name + Email in a clean stacked row.
     - `Department`: Icon + department title.
     - `Designation & Role`: Designation badge + Role badge + Grade indicator.
     - `Shift`: Working hours badge.
     - `Status`: High-contrast semantic status pill (`Active`, `Probation`, `Notice`, `Terminated`, `Suspended`, `Resigned`).
     - `Actions`: View, Edit, Reset Password, Archive / Revert / Delete.
   - Clicking on any row opens the new `EmployeeDetailModal.jsx` directly.

4. **Bucket & Filter Governance**:
   - Status buckets:
     - `Active Workforce`: Active, Confirmed, and Probation employees.
     - `Inactive / Suspended`: Inactive, Suspended, or Terminated employees.
     - `Archive Bucket`: Soft-deleted employee records (`isDeleted: true`).
   - Advanced faceted filter bar:
     - Search input with clear button.
     - Department filter dropdown.
     - Designation filter dropdown.
     - Quick status pills and reset button.
   - Strict PBAC gating:
     - `Onboard Employee` (`UserPlus` button) hidden if user lacks `employee.create`.
     - `Bulk Ingest` (`UploadCloud` button) hidden if user lacks `employee.create`.
     - `Export to Excel` (`FileSpreadsheet` button) hidden if user lacks `report.export`.
     - Row edit and archive actions hidden if user lacks `employee.edit` or `employee.delete`.
