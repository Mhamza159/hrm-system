# Plan 09-01: Document Text Extraction Engine (PDF & Word DOCX)

## Objective
Implement native document text extraction in the backend for uploaded candidate resumes. Install `pdf-parse` and `mammoth` to extract true body text from digital PDFs and Word `.docx` documents, sanitize the output, and pass real candidate work experience and skills into the AI parsing pipeline.

---

## Tasks

### 1. Dependencies Installation
- Add `pdf-parse` and `mammoth` to `backend/package.json`.
- Run `npm --prefix backend install` to ensure clean installation.

### 2. Document Parser Service (`backend/src/services/documentParser.service.js`)
- Implement `extractTextFromBuffer(buffer, mimeType, filename)`:
  - For PDF (`application/pdf` or `.pdf` extension): Use `pdf-parse` to extract text from buffer.
  - For DOCX (`application/vnd.openxmlformats-officedocument.wordprocessingml.document` or `.docx`): Use `mammoth.extractRawText({ buffer })`.
  - For plain text (`text/plain` or `.txt`): Decode as UTF-8 string.
  - For legacy DOC / other: Extract UTF-8 printable string chunks gracefully.
- Normalization & Defense:
  - Strip null bytes, unprintable control characters, and redundant whitespace.
  - Cap extracted text length at 15,000 characters to prevent prompt bloat and memory exhaustion.
  - If document is scanned or text extraction yields fewer than 50 characters, fall back to applicant form metadata with an advisory warning.

### 3. Recruitment Service Ingestion Wiring (`backend/src/modules/recruitment/recruitment.service.js`)
- Update `applyForJob` and `screenCandidate` to call `extractTextFromBuffer(file.buffer, file.mimetype, file.originalname)`.
- Replace the previous synthetic metadata shortcut for `%PDF` with the extracted real document text.
- Store the sanitized extracted text in `candidate.cvText`.

### 4. Unit Testing (`backend/tests/m15.documentParser.test.js`)
- Test PDF buffer text extraction.
- Test DOCX buffer text extraction.
- Test plain text buffer extraction.
- Test handling of corrupt buffers and graceful fallback.

---

## Verification
