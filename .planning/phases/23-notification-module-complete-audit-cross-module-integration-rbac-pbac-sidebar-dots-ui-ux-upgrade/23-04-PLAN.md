# Plan 23-04: Notification Center & Drawer Complete UI/UX Redesign

## Goal
Redesign the Notification Center page (`/notifications`) and slide-out Header Drawer (`NotificationDrawer.jsx`) following the Forest & Emerald Enterprise theme, introducing segmented category filters, priority indicators, bulk actions, and a dedicated Archive lifecycle tab.

## Proposed Changes

### 1. `frontend/src/features/notifications/components/NotificationCard.jsx`
- Reusable notification presentation component:
  - Module icon with category-tinted badge (e.g. Leaves: Calendar, Payroll: Banknote, Policies: BookOpen, Grievances: ShieldAlert, System: Shield).
  - Priority badge (`Urgent`: Rose pill with pulsing indicator, `High`: Amber, `Normal`: Emerald, `Low`: Slate).
  - Timestamp with relative time formatting (`5m ago`, `2h ago`, `Yesterday`).
  - Read/Unread visual differentiation (unread items feature emerald highlight bar & subtle glow).
  - Quick action toolbar:
    - Mark as Read / Unread toggle button.
    - Archive button.
    - Deep-link button: "View Request" or "Take Action" navigating straight to the target route.

### 2. `frontend/src/features/notifications/components/NotificationDrawer.jsx`
- Slide-out quick inspection drawer triggered from topbar bell:
  - Header with unread count pill, "Mark All as Read" button, and close icon.
  - Quick module filters: `All`, `Urgent`, `Approvals`, `System`.
  - Virtualized or clean scrollable list of recent notifications.
  - Empty state with friendly illustration and tip.
  - Footer link: "Open Full Notification Center" navigating to `/notifications`.

### 3. `frontend/src/features/notifications/pages/NotificationsPage.jsx`
- Full command center view:
  - **Header & Metric Cards**:
    - Total Notifications, Unread Alerts, Urgent Action Required, Archived Alerts.
  - **Tab Navigation**:
    - Tab 1: **Active Notifications** (with unread filter pill).
    - Tab 2: **Archived Notifications** (with unarchive / restore actions).
  - **Category / Module Filter Bar**:
    - Horizontal scrollable filter pills: `All`, `Leaves`, `Attendance`, `Payroll`, `ATS`, `Assets`, `Policies`, `Announcements`, `Feedback`, `Chat`, `Security`.
    - Priority filter dropdown (`All Priorities`, `Urgent`, `High`, `Normal`, `Low`).
    - Search input searching within notification titles and bodies.
  - **Bulk Action Toolbar**:
    - Checkbox selection for batch operations: "Mark Selected Read", "Archive Selected".
    - "Archive All Read" button.
  - **Pagination Controls**:
    - Smooth server-side pagination with page size selector.

### 4. Design & Theme Adherence
- Strictly implement Forest & Emerald tokens:
  - Background: `#061A14`, surface: `#111D17`, card border: `#1A3125`.
  - Accent / Primary: Emerald `#00C471`.
  - Text: High contrast off-white and muted emerald-slate.
  - Focus rings and accessible keyboard navigation for all interactive controls.

## Verification Criteria
- [ ] Notification Drawer opens smoothly from Header and displays recent items.
- [ ] Dedicated Notification Center page allows switching between Active and Archived tabs.
- [ ] Filtering by module and priority correctly scopes the notification feed.
- [ ] Mark All as Read and Archive actions execute cleanly and update UI instantly.
- [ ] Deep action links successfully navigate user to destination records.
