# Plan 23-03: Dynamic Sidebar Indicators & Real-Time Synchronization

## Goal
Integrate dynamic notification indicators (unread count badges and pulsing dots) into `Sidebar.jsx` and `Header.jsx`. Real-time updates via Socket.io ensure immediate count increments upon new notifications and instant decrements upon marking read or visiting the target module.

## Proposed Changes

### 1. `frontend/src/features/notifications/notificationsApi.js`
- Add query endpoint `getModuleNotificationCounts`:
  - Query: `GET /notifications/module-counts`.
  - Provides tags: `['Notification', 'NotificationCounts']`.
- Add mutation endpoints:
  - `archiveNotification`: `PATCH /notifications/:id/archive` (invalidates `Notification`, `NotificationCounts`).
  - `unarchiveNotification`: `PATCH /notifications/:id/unarchive` (invalidates `Notification`, `NotificationCounts`).
  - `archiveAllNotifications`: `PATCH /notifications/archive-all` (invalidates `Notification`, `NotificationCounts`).
  - `markAllAsRead`: `PATCH /notifications/read-all` (invalidates `Notification`, `NotificationCounts`).

### 2. `frontend/src/features/notifications/hooks/useModuleNotificationCounts.js`
- Consume `useGetModuleNotificationCountsQuery(undefined, { pollingInterval: 30000 })`.
- Listen for Socket.io events:
  - `notification:new`: Trigger RTK Query cache update or tag invalidation.
  - `notification:read`: Decrement relevant module/route counts.
- Map counts to:
  - Standalone top-level links:
    - `Employees`: `byModule.employees`
    - `Company Policies`: `byModule.policies`
    - `Announcements`: `byModule.announcements`
    - `Notifications`: `totalUnread`
    - `Internal Chat`: `byModule.chat`
    - `Attrition Prediction`: `byModule.attrition`
  - Collapsible Tree Groups (rollup counts of children):
    - `Attendance`: `byModule.attendance`
    - `Leaves & Holidays`: `byModule.leaves`
    - `Payroll`: `byModule.payroll`
    - `Loans & Advances`: `byModule.loans`
    - `Expenses`: `byModule.expenses`
    - `Assets`: `byModule.assets`
    - `Recruitment & ATS`: `byModule.recruitment`
    - `Projects & Timesheets`: `byModule.projects`
    - `Performance`: `byModule.performance`
    - `Lifecycle`: `byModule.lifecycle`
    - `Rewards & Engagement`: `byModule.rewards`
    - `Feedback & Grievance`: `byModule.feedback`
- Provide helper `getRouteBadge(path)`:
  - Returns specific count for exact sub-route (e.g. `/leaves/approvals`).

### 3. `frontend/src/components/layout/Sidebar.jsx`
- Render dynamic indicators:
  - For accordion group items:
    - If group is collapsed and has unread count > 0: Display emerald badge counter or pulsing emerald indicator on the group header row.
    - If group is expanded: Child items display their specific route unread badges.
  - For standalone links:
    - Display numerical pill or indicator next to the item label.
- Theme & Styling:
  - Enterprise Forest & Emerald tokens (`bg-emerald-500/20 text-emerald-400 border border-emerald-500/30 text-[11px] font-bold px-1.5 py-0.5 rounded-full`).
  - High accessibility contrast ratio.

### 4. `frontend/src/components/layout/Header.jsx`
- Bell Icon indicator:
  - Displays `totalUnread` badge counter.
  - Clicking bell toggles the newly redesigned `NotificationDrawer.jsx`.

## Verification Criteria
- [ ] Sidebar accordion groups show aggregated unread counts when collapsed.
- [ ] Sub-items display route-specific unread badges when accordion is expanded.
- [ ] Receiving a new notification via Socket.io updates sidebar indicators immediately.
- [ ] Navigating to a module or marking notifications read decrements the count in real-time.
