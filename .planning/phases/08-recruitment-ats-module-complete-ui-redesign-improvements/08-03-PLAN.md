# Plan 08-03: Public Career Portal & Candidate Application Experience Overhaul

## Objective
Completely redesign the Public Career Portal (`CareersPublicPage.jsx`) and Public Application Page (`ApplyPage.jsx`) into a modern, attractive, responsive, and world-class careers portal with high visual craft, clear typography, refined job cards, interactive filters, and an intuitive candidate application flow.

---

## Proposed Changes

### 1. `frontend/src/features/recruitment/pages/CareersPublicPage.jsx`
- Redesign Public Header:
  - Clean brand mark with HRM Enterprise logo and subtle status badge.
  - Quick link to Employee Portal login.
- Modern Hero Section:
  - Radial gradient background (`from-emerald-950/40 via-slate-900 to-slate-950`).
  - Editorial headline and concise subheadline.
  - Floating search input with department selector and employment type pills.
  - Total openings counter.
- Job Listings Grid / Cards:
  - High-craft cards with hover lift effect, emerald borders on active selection.
  - Tags for Department, Location, Employment Type, and Salary range (when disclosed).
  - Clean preview of responsibilities and requirements.
  - Direct "Apply Now" button with arrow animation.
  - Quick drawer or modal for viewing full job description without navigating away.
- Empty states with search reset button.
- Footer with company branding and careers privacy pledge.

### 2. `frontend/src/features/recruitment/pages/ApplyPage.jsx`
- Redesign layout:
  - Back button with breadcrumb navigation.
  - Two-column split layout on desktop:
    - Left column: Job overview summary card (Title, Department, Location, Type, Key Requirements).
    - Right column: Clean, multi-step or streamlined single-page application form.
- Form Inputs:
  - Full Name, Email, Phone Number, LinkedIn URL, Portfolio/GitHub URL.
  - Modern drag-and-drop file upload zone for CV/Resume:
    - Supports `.pdf`, `.doc`, `.docx` up to 5MB.
    - Shows selected file name, size, and remove button.
    - Visual drag-over highlight.
- Success confirmation screen:
  - Animated checkmark, application reference number, next steps timeline (Screening -> Review -> Interview), and return to careers button.

---

- Submit test application on public careers portal.
- Verify file upload validation (<5MB, valid extensions).
