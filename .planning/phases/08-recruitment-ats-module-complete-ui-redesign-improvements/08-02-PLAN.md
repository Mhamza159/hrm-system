# Plan 08-02: Job Openings Page Overhaul & Archive Lifecycle Modal

## Objective
Completely redesign the Job Openings page (`JobsPage.jsx`) into a modern, pixel-perfect recruitment dashboard with dedicated **Active Openings** and **Archived Openings** tabs, status pills, refined filters, and a dedicated `JobArchiveDetailModal.jsx` enabling **Revert** and **Permanent Delete** workflows with safety confirmations.

---

## Proposed Changes

### 1. `frontend/src/features/recruitment/components/JobArchiveDetailModal.jsx`
- Create modal component adhering to Forest & Emerald design system:
  - Header: Archive badge, Job Title, Department, Designation, and closing date.
  - Body: Compensation details (min/max salary, currency, disclosure flag), employment type, experience requirements, responsibilities preview, and candidate count.
  - Warning alert: Explains the status of the archived job and restrictions (e.g. permanent deletion rules).
  - Actions:
    - **Revert to Active:** Calls `restoreJob(job._id)` with loading state.
    - **Permanent Delete:** Shows confirmation prompt ("Are you sure you want to permanently delete this job? This action cannot be undone.") then calls `permanentDeleteJob(job._id)`.
    - Close button.

### 2. `frontend/src/features/recruitment/pages/JobsPage.jsx`
- Redesign page layout:
  - Header with metrics summary cards: Total Jobs, Published, Draft, Archived, and Pending Requisitions.
  - Dual-mode tab switcher:
    - **Active Openings:** Lists published and draft jobs with filters for search, department, and employment type. Row click opens job preview / edit. Action buttons: Publish, Close, View Candidates, Edit, Archive (Delete).
    - **Archived Openings:** High-density table of decommissioned jobs. Row click or action button opens `JobArchiveDetailModal.jsx`.
    - **Requisitions (Headcount requests):** Polished cards/table for department requisitions with Super Admin decision buttons (Approve/Reject).
  - Styled buttons with emerald accents (`#00C471`, hover `#049856`).
  - Status pills with semantic color mapping:
    - `Published`: Emerald pill (`bg-emerald-50 text-emerald-700 dark:bg-emerald-950/60 dark:text-emerald-300`).
    - `Draft`: Amber pill (`bg-amber-50 text-amber-700 dark:bg-amber-950/60 dark:text-amber-300`).
    - `Closed` / `Archived`: Slate pill (`bg-slate-100 text-slate-700 dark:bg-slate-800 dark:text-slate-300`).
  - Enforce PBAC permissions: Hide action buttons if user lacks `recruitment.job.manage` or `recruitment.requisition.decide`.

### 3. `frontend/src/features/recruitment/components/RequisitionModal.jsx`
- Align modal styles with Forest & Emerald design system: hairline borders `#EAECF0` / `#1A3125`, dark background `#111D17`, clean input typography.
