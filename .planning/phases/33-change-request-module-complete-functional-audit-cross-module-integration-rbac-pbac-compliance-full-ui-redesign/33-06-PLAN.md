# Plan 33-06: Employee Self-Service Hub, Dynamic Multi-Category Submission Modal & End-to-End Testing

## Objective
Implement the employee self-service submission and tracking experience. Overhaul `ChangeRequestModal.jsx` to dynamically adapt across all 8 change categories with pre-filled current values, field validation, and supporting document uploads. Build a dedicated "My Requests" tab in `MyProfilePage.jsx` allowing employees to inspect their request status, read reviewer feedback, and cancel pending requests. Author an automated Vitest test suite (`backend/tests/changeRequest.module.overhaul.test.js`) verifying lifecycle transitions, cross-module synchronization, PBAC scoping, and zero UI leakage.

## Tasks
1. **Dynamic Multi-Category Request Submission Modal (`ChangeRequestSubmitModal.jsx`)**:
   - Category selector tabs/dropdown: Personal Info, Contact Details, Residential Address, Emergency Contact, Bank Coordinates, Department, Designation, Reporting Manager.
   - Dynamic form rendering with pre-populated current values from `currentEmployee`.
   - Category-specific validations (e.g. valid Pakistani phone `+92...`, valid IBAN, non-empty fields).
   - Supporting document uploader with drag-and-drop file picker, size check (<5MB), and progress indicator.
   - Justification reason textarea with character counter.
   - Pre-submission preview card contrasting current values with proposed inputs.

2. **Employee Self-Service Tracking Hub (`MyChangeRequestsTab.jsx` in `MyProfilePage.jsx`)**:
   - Embed a "Change Requests" tab into the employee's personal profile view.
   - Display a responsive list of the employee's submitted requests with status pills (`pending`, `under_review`, `approved`, `rejected`, `returned`).
   - Allow employees to open the Inspect Details modal to view reviewer notes/reasons.
   - Provide a "Withdraw Request" action for requests still in `pending` status.
   - Provide an "Edit & Resubmit" trigger for requests in `returned` status.

3. **Automated Vitest Test Suite (`backend/tests/changeRequest.module.overhaul.test.js`)**:
   - Test 1: Full lifecycle submission $\rightarrow$ review $\rightarrow$ approve $\rightarrow$ master employee record updated.
   - Test 2: Department and Designation change approval updates `Employee` and writes to `EmployeeHistory`.
   - Test 3: Rejection lifecycle: request marked `rejected`, reason stored, employee record untouched.
   - Test 4: Return for correction lifecycle: request marked `returned`, employee edits and resubmits.
   - Test 5: PBAC scoping enforcement: Department Manager cannot view requests outside their department.
   - Test 6: Super Admin escalation: HR employee change request cannot be approved by HR Manager.
   - Test 7: Sensitive data protection: IBAN encrypted at rest with AES-256-GCM.
   - Test 8: Audit log and notification dispatch verification.

4. **Quality & Build Verification**:
   - Execute Oxlint across all backend and frontend files touched in Phase 33 to guarantee 0 errors.
   - Execute `npm run build` in `frontend` to guarantee a clean Vite production build.

## Verification Criteria
- Employees can submit requests across any supported category with attached verification files.
- Employees can track all their submitted requests and view reviewer notes directly in `My Profile`.
- 100% of Vitest integration tests pass with zero flakiness.
- 0 Oxlint errors across all modified files and clean production build.
