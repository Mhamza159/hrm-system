# Plan 33-05: Request Details Forensic Modal, Before/After Diff Inspector & Reviewer Decision Studio

## Objective
Design and implement a comprehensive Request Details (Forensic Diff) Modal and Reviewer Decision Studio. Provide an enterprise inspection experience featuring complete employee credentials, side-by-side Before/After mutation comparison with highlighted changes, secure supporting attachment viewer, chronological audit timeline, and a guarded decision panel for Approve, Reject, and Return actions with mandatory rationale capture.

## Tasks
1. **Request Details Modal Architecture (`ChangeRequestInspectModal.jsx`)**:
   - Header with Request ID, submission timestamp, priority badge, and current status pill.
   - **Employee Identity Card**: Complete profile presentation including avatar, full name, employee code, official email, department, designation, employment status, and reporting manager.
   - **Request Context & Justification**: Employee's submitted statement explaining the necessity of the modification.
   - **Supporting Attachments Gallery**: Interactive file preview cards (PDF viewer trigger or thumbnail download) displaying filename, size, and upload timestamp.

2. **Side-by-Side Before/After Mutation Diff Inspector**:
   - Dedicated comparative grid:
     - **Current Baseline (`oldValue`)**: Grayed/neutral container displaying existing records prior to request.
     - **Requested Values (`requestedValue`)**: Tinted container with green/emerald accents highlighting the delta.
   - Category-tailored formatters:
     - *Bank Details*: Old vs New Bank, Title, Account #, and masked IBAN (`PK** **** **** **** 4821`).
     - *Address*: Old vs New Street, City, State, Postal Code.
     - *Emergency Contact*: Old vs New Name, Relationship, Phone.
     - *Department / Designation*: Old Department/Designation badge vs Proposed Target badge with grade tier.
     - *Personal / Contact*: Old vs New Full Name, Phone, Email, Marital Status.

3. **Chronological Status Timeline (`ChangeRequestTimeline.jsx`)**:
   - Visual vertical timeline tracking each lifecycle stage (`submitted`, `under_review`, `returned`, `approved`, `rejected`, `resubmitted`, `cancelled`).
   - Displays actor avatar, full name, role badge, timestamp, and decision notes/rationale.

4. **Reviewer Decision Studio & Confirmation Dialogs (`ChangeRequestDecisionModal.jsx`)**:
   - Guarded decision actions:
     - **Approve**: Green confirmation modal detailing the exact fields that will be permanently mutated on the employee's master record.
     - **Reject**: Red modal with mandatory rejection justification textarea.
     - **Return for Correction**: Violet modal prompting reviewer for specific revision notes guiding the employee.
   - Guard check: If applicant is HR, display warning that Super Admin authorization is required and lock action for non-Super Admins.

## Verification Criteria
- Diff inspector clearly contrasts current baseline against proposed values across all 8 categories.
- Timeline dynamically renders historical transitions with actor attribution and comments.
- Rejection and Return actions require non-empty notes before allowing submission.
- Unsaved state warning prevents accidental closing during review.
