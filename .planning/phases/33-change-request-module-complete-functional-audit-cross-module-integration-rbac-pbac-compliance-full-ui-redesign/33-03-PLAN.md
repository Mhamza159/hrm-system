# Plan 33-03: Change Request Dashboard, Actionable KPI Metrics & Category Analytics UI

## Objective
Design and implement an executive dashboard for the Change Request Module adhering strictly to `docs/UI-REFERENCE.md`. Surface real-time actionable metrics through a responsive 6-card KPI grid and pure SVG/Tailwind visual analytics (Request Status Distribution, Category Breakdown, and 6-Month Velocity Curves) reflecting live backend data scoped to user permissions.

## Tasks
1. **Redux API Slice Extensions (`frontend/src/features/employees/employeesApi.js`)**:
   - Add `useGetChangeRequestStatsQuery` with automatic invalidation on change request mutations.
   - Add `useGetMyChangeRequestsQuery` for self-service lookups.
   - Add `useReturnChangeRequestMutation` and `useCancelChangeRequestMutation`.
   - Add `useUploadChangeRequestAttachmentMutation`.

2. **Actionable 6-Card KPI Deck (`ChangeRequestDashboard.jsx`)**:
   - **Total Requests**: Cumulative volume with month-over-month indicator.
   - **Pending Review**: Requests awaiting action, highlighted in amber tint (`bg-amber-50/50 dark:bg-amber-950/20 text-amber-700`).
   - **Pending My Action**: Scoped count of requests specifically awaiting the logged-in reviewer's decision.
   - **Approved**: Successfully applied changes in emerald styling (`bg-emerald-50/50 dark:bg-emerald-950/20 text-emerald-700`).
   - **Rejected**: Declined requests in rose styling (`bg-rose-50/50 dark:bg-rose-950/20 text-rose-700`).
   - **Returned for Correction**: Requests sent back to employees in violet styling (`bg-purple-50/50 dark:bg-purple-950/20 text-purple-700`).
   - Skeletons for seamless loading states and error recovery fallback.

3. **Pure SVG Visual Analytics**:
   - **Category Breakdown Bar / Donut Chart**: Proportional distribution of requests across Personal, Contact, Address, Emergency Contact, Banking, Department, Designation, and Manager.
   - **Request Status Distribution Bar**: Visual progress breakdown (Pending vs Approved vs Rejected vs Returned).
   - **Monthly Request Velocity Curve**: Pure SVG line chart displaying historical 6-month request inflow and turnaround trends.
   - Fully reactive to dark/light theme switching with zero external charting library dependencies.

## Verification Criteria
- KPI cards display accurate counts synchronized with database records.
- "Pending My Action" accurately calculates requests requiring the current user's attention.
- All SVG charts render smoothly with zero layout shift in both light and dark themes.
- No external chart libraries (e.g. recharts, chart.js) are introduced.
