## 2. Step-by-Step Implementation

### Step 1: Update `shift.model.js`
- Add archival tracking, department link, capacity, color, and description fields:
  ```javascript
  isArchived: {
    type: Boolean,
    default: false,
    index: true
  },
  archivedAt: {
    type: Date,
    default: null
  },
  archivedBy: {
    type: mongoose.Schema.Types.ObjectId,
    ref: 'User',
    default: null
  },
  departmentId: {
    type: mongoose.Schema.Types.ObjectId,
    ref: 'Department',
    default: null
  },
  capacity: {
    type: Number,
    default: 0, // 0 = unlimited capacity
    min: 0
  },
  description: {
    type: String,
    trim: true,
    maxlength: [500, 'Description cannot exceed 500 characters'],
    default: ''
  },
  color: {
    type: String,
    trim: true,
    default: '#00C471'
  }
  ```
- Add compound indexes:
  ```javascript
  shiftSchema.index({ isArchived: 1, isDeleted: 1 });
  shiftSchema.index({ type: 1, isArchived: 1 });
  shiftSchema.index({ departmentId: 1, isArchived: 1 });
  shiftSchema.index({ code: 1, isArchived: 1, isDeleted: 1 });
  ```

### Step 2: Implement Archival Lifecycle in `department.service.js`
- **`getAllShifts`**:
  - Update query to `{ isDeleted: false, isArchived: { $ne: true } }` by default to ensure 100% backwards-compatibility with unmigrated Atlas documents.
  - Idempotent background normalization: `Shift.updateMany({ isArchived: { $exists: false } }, { $set: { isArchived: false } }).catch(() => {});`
  - Populate `departmentId` (`name code`) and compute assigned staff headcount via `Employee.aggregate`.
- **`getArchivedShifts({ search, type, departmentId, page, limit, sortBy, sortOrder })`**:
  - Query `{ isArchived: true, isDeleted: false }`.
  - Populate `departmentId` (`name code`), `archivedBy` (`name email`), and `createdBy` (`name email`).
  - Attach active headcount via `Employee.aggregate`.
  - Return paginated `{ docs, total, page, limit, totalPages }`.
- **`archiveShift(id, actor)`**:
  - Verify shift exists and is not already archived.
  - Set `isArchived: true`, `archivedAt: new Date()`, `archivedBy: actor._id`.
  - Audit log: action `shift.archive`.
- **`restoreShift(id, actor)`**:
  - Verify shift is currently archived.
  - Check code uniqueness across active shifts: prevent restore if an active shift already uses the same code.
  - If associated `departmentId` is deleted or archived, verify and handle cleanly.
  - Set `isArchived: false`, `archivedAt: null`, `archivedBy: null`, `isActive: true`.
  - Audit log: action `shift.restore`.
- **`permanentDeleteShift(id, actor)`**:
  - **CRITICAL RESTRICTION RULE**: Count assigned employees:
    ```javascript
    const assignedCount = await Employee.countDocuments({ shiftId: id, isDeleted: false });
    if (assignedCount > 0) {
      throw new ApiError(
        400,
        `This shift cannot be permanently deleted because ${assignedCount} employee(s) are currently assigned to it. Please reassign all employees to another shift before proceeding.`
      );
    }
    ```
  - Purge with `Shift.deleteOne({ _id: id })`.
  - Audit log: action `shift.permanent_delete`.

### Step 3: Implement Cross-Module Assignment Guard in `employee.service.js`
- In `createEmployee`:
  - When `payload.shiftId` is provided:
    ```javascript
    const targetShift = await Shift.findOne({ _id: payload.shiftId, isDeleted: false });
    if (!targetShift) throw new ApiError(404, 'Specified work shift does not exist');
    if (targetShift.isArchived) throw new ApiError(400, `Cannot assign employee to shift '${targetShift.name}' because it is archived.`);
    ```
- In `updateEmployee`:
  - When `payload.shiftId` changes: verify existence and block if `targetShift.isArchived`.

### Step 4: Register Controller & Routes in `shift.routes.js`
- `GET /archived` -> `departmentController.getArchivedShifts` (`checkPermission('org.view')`)
- `PATCH /:id/archive` -> `departmentController.archiveShift` (`checkPermission('org.manage')`)
- `PATCH /:id/restore` -> `departmentController.restoreShift` (`checkPermission('org.manage')`)
- `DELETE /:id/permanent` -> `departmentController.permanentDeleteShift` (`checkPermission('org.manage')`)
- Route ordering invariant: mount `/archived` BEFORE `/:id`.
