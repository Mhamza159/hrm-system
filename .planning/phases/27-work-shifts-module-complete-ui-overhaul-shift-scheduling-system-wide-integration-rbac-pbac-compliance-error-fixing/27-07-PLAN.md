# Plan 27-07: Deep Inspection Details Modal with Assigned Staff Roster & Timing Breakdown

**Phase:** Phase 27: Work Shifts Module — Complete UI Overhaul, Shift Scheduling, System-Wide Integration, RBAC/PBAC Compliance & Error Fixing  
**Objective:** Create a comprehensive Deep Inspection Details Modal (`ShiftDetailModal.jsx`) providing an in-depth view of shift schedule parameters, overnight flags, break rules, work days breakdown, and a live searchable assigned staff roster sub-table.

---

## 1. Files to Modify / Create

- `frontend/src/features/departments/components/ShiftDetailModal.jsx` (New deep inspection modal)
- `frontend/src/features/departments/pages/ShiftsPage.jsx` (Inspection modal trigger and state)

---

## 2. Step-by-Step Implementation

### Step 1: Create `ShiftDetailModal.jsx`
- Structure modal with tabbed or sectioned high-density layout:
  1. **Shift Overview Banner**:
     - Large shift title, uppercase code badge, active status pill, and shift type badge.
     - Color swatch accent and overnight status alert.
     - Creation timestamp and creator attribution.
     - If archived: prominent amber archival banner showing `archivedAt` and `archivedBy`.
  2. **Timing & Schedule Architecture**:
     - Timeline visual bar illustrating:
       - Shift Start (`startTime`).
       - Grace period window (`graceMinutes`).
       - Lunch / Rest Break (`breakMinutes`).
       - Half-day mark (`halfDayMinutes`).
       - Shift End (`endTime`).
       - Net productive working hours vs total elapsed time.
     - Working Days Pill Strip: Active days of the week highlighted with checkmarks.
  3. **Capacity & Operational Metadata**:
     - Headcount vs Max Capacity utilization progress bar.
     - Associated Department info (or "All Departments / Global").
     - Description notes.
  4. **Assigned Staff Roster Sub-Table**:
     - Embedded search bar filtering by employee name, code, or department.
     - Table columns:
       - Employee Name & Avatar.
       - Employee Code & Email.
       - Department & Designation.
       - Employment Status (`active`, `probation`).
     - Pagination controls for rosters exceeding 10 employees.
     - Empty state: "No employees currently rostered to this shift."
  5. **Footer Actions**:
     - "Close" button.
     - "Manage Assignments" button (opens `ShiftAssignModal` if permitted).
     - "Edit Shift" button (opens `ShiftModal` if permitted and not archived).

### Step 2: Wire Inspection Modal into `ShiftsPage.jsx`
- Clicking any shift name in the table or clicking "View Details" on a card opens `ShiftDetailModal`.
- Deep links / URL query parameter support (optional: `?inspectShiftId=<id>`).

---

## 3. Verification Criteria

- [ ] Modal opens seamlessly displaying accurate schedule parameters and timing visualizer.
- [ ] Assigned staff sub-table renders real database records with live search filter.
- [ ] Overnight shifts clearly display overnight warning and cross-midnight indicators.
- [ ] If shift is archived, modal displays archive notice with timestamps and actor.
