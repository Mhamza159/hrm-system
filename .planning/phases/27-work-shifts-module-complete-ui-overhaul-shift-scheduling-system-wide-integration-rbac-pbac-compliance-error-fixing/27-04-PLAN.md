# Plan 27-04: Shift Directory Overhaul, Dual View Switcher (Table & Card Grid) & Multi-Dimensional Filtering Toolbar

**Phase:** Phase 27: Work Shifts Module — Complete UI Overhaul, Shift Scheduling, System-Wide Integration, RBAC/PBAC Compliance & Error Fixing  
**Objective:** Overhaul the primary Shift Directory interface with a high-density Enterprise Table View, interactive Card Grid View (`ShiftCardView.jsx`), dual view mode switcher, and multi-dimensional filter bar (`ShiftFilterBar.jsx`) with live search, shift type filter, status filter, and department selector.

---

## 1. Files to Modify / Create

- `frontend/src/features/departments/components/ShiftFilterBar.jsx` (Filter toolbar & active filter chips)
- `frontend/src/features/departments/components/ShiftCardView.jsx` (Card grid layout with shift timing visualizers)
- `frontend/src/features/departments/pages/ShiftsPage.jsx` (Dual view rendering, active tab management, pagination)

---

## 2. Step-by-Step Implementation

### Step 1: Create `ShiftFilterBar.jsx`
- Search Input: Real-time debounced search on shift name and code.
- Shift Type Filter: Dropdown/pills for `All Types`, `Fixed`, `Flexible`, `Night`.
- Status Filter: `All`, `Active`, `Inactive`.
- Department Filter: Filter by assigned department if set.
- View Switcher Toggle: High-density Table View icon vs Card Grid View icon with persistent local state.
- Quick Reset / Clear Filters button when active filters exist.
- Active filter badge chips showing filter count and quick-dismiss tags.

### Step 2: Create `ShiftCardView.jsx`
- Responsive 1/2/3-column card grid (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).
- Card layout:
  - Header: Shift Name, Uppercase Code badge, and Shift Type badge (`fixed` = Emerald, `flexible` = Amber, `night` = Indigo with `Moon` icon).
  - Timing Banner: Large, readable `09:00 - 18:00` display with duration badge (`9h 0m`, net after break).
  - Cross-Midnight Tag: Distinct moon indicator badge when shift crosses midnight.
  - Work Days: Pills for active days (Mon, Tue, Wed, Thu, Fri, etc.).
  - Metrics Footer:
    - Headcount indicator (`X Staff Assigned`) with `Users` icon.
    - Capacity progress bar (if capacity > 0) showing utilization percentage.
  - Action Menu: View Details (`Eye`), Assign Staff (`UserPlus`), Edit (`Edit2`), Archive (`Archive`), Delete (`Trash2`).

### Step 3: Upgrade Table View in `ShiftsPage.jsx`
- Enhance DataTable columns:
  - **Shift Name & Code**: Color accent bar, code badge, overnight indicator.
  - **Type**: Styled pill with icon (`Sun` for fixed, `RefreshCw` for flexible, `Moon` for night).
  - **Timing & Duration**: Clean 24h format (`09:00 → 18:00`), net duration, break duration (`Break: 60m`).
  - **Grace Period**: Grace minutes badge (`15m grace`).
  - **Work Days**: Abbreviated day chips (`M T W T F`).
  - **Staff Assigned**: Headcount badge with click to inspect/assign.
  - **Status**: Active / Inactive status toggle badge.
  - **Actions**: Responsive dropdown or action icon row with permission checks (`Can I="org.manage" a="Organization"`).

### Step 4: Implement Dual Tab Switcher in `ShiftsPage.jsx`
- Tab 1: **Active Shifts** (with active count badge).
- Tab 2: **Archived Shifts** (with archive count badge).
- Clean tab indicator bar adhering to Forest & Emerald styling.

## 3. Verification Criteria

- [ ] View switcher seamlessly toggles between Enterprise Table and Card Grid views.
- [ ] Filtering by shift type (`fixed`, `flexible`, `night`) updates both views synchronously.
- [ ] Search correctly matches shift name and code.
- [ ] Active filter chips appear and can be cleared individually or all at once.
- [ ] Cards render accurate timing, overnight badges, work days, and staff capacity.
