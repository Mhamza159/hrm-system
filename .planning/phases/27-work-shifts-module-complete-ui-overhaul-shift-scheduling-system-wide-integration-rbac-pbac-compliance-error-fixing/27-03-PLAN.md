## 2. Step-by-Step Implementation

### Step 1: Add RTK Query Endpoints in `departmentsApi.js`
- Add `getShiftStats`:
  ```javascript
  getShiftStats: builder.query({
    query: () => '/shifts/stats',
    providesTags: ['Shifts', { type: 'Shifts', id: 'STATS' }]
  }),
  getShiftAnalytics: builder.query({
    query: () => '/shifts/analytics',
    providesTags: ['Shifts', { type: 'Shifts', id: 'ANALYTICS' }]
  })
  ```
- Export `useGetShiftStatsQuery` and `useGetShiftAnalyticsQuery`.

### Step 2: Build `ShiftStatsCards.jsx`
- Display 7 enterprise KPI cards in an adaptive responsive grid:
  1. **Total Shifts**: Total registered schedules with `Clock` icon.
  2. **Active Shifts**: In-service operational shifts with `CheckCircle2` emerald icon.
  3. **Archived Shifts**: Preserved historical shifts with `Archive` amber icon. Click switches to Archived tab.
  4. **Assigned Staff**: Total employees actively rostered to shifts with `Users` icon.
  5. **Staffed Shifts**: Operational shifts with active staff with `Briefcase` icon.
  6. **Empty Shifts**: Shifts needing assignment with `UserMinus` rose/amber icon.
  7. **Night / Overnight**: Shifts spanning midnight or night hours with `Moon` indigo icon.
- Cards feature subtle dark gradients (`from-[#111D17] to-[#162720]`), hairline borders (`#1A3125`), and theme-compliant typography.

### Step 3: Build `ShiftAnalyticsSection.jsx`
- Collapsible/expandable modern analytics drawer or embedded dashboard panel.
- Left Panel: **Workforce Distribution by Shift**
  - Horizontal progress flex-bars showing headcount and utilization percentage against capacity for top shifts.
  - Interactive hover tooltips showing start time, end time, and break duration.
- Right Panel: **Shift Type & Day/Night Composition**
  - Native SVG Donut chart displaying proportion of `Fixed`, `Flexible`, and `Night` schedules.
  - Central callout showing Total Active Rostered Staff.
  - Department coverage breakdown showing number of departments with dedicated shift rosters.

### Step 4: Wire into `ShiftsPage.jsx`
- Render `ShiftStatsCards` below `PageHeader`.
- Render `ShiftAnalyticsSection` with smooth transition and toggle controls.
- Handle loading skeletons with `ScreenSkeleton` or custom pulsating placeholder cards.
