# Plan 27-06: Employee Shift Assignment Modal & Shift Roster Scheduling

**Phase:** Phase 27: Work Shifts Module — Complete UI Overhaul, Shift Scheduling, System-Wide Integration, RBAC/PBAC Compliance & Error Fixing  
**Objective:** Implement a dedicated Employee Shift Assignment Modal (`ShiftAssignModal.jsx`) using `EmployeeSelectDropdown.jsx` to allow HR and managers to assign or reassign employees to a shift, preview current capacity, and update employee rosters with real-time feedback.

## 2. Step-by-Step Implementation

### Step 1: Add RTK Query Hooks in `departmentsApi.js`
- Add `getShiftEmployees`:
  ```javascript
  getShiftEmployees: builder.query({
    query: ({ id, params }) => ({
      url: `/shifts/${id}/employees`,
      params
    }),
    providesTags: (result, error, { id }) => [{ type: 'Shifts', id: `STAFF_${id}` }]
  }),
  assignEmployeesToShift: builder.mutation({
    query: ({ id, employeeIds, action = 'add' }) => ({
      url: `/shifts/${id}/assign`,
      method: 'POST',
      body: { employeeIds, action }
    }),
    invalidatesTags: (result, error, { id }) => [
      { type: 'Shifts', id },
      { type: 'Shifts', id: 'LIST' },
      { type: 'Shifts', id: 'STATS' },
      { type: 'Shifts', id: 'ANALYTICS' },
      { type: 'Shifts', id: `STAFF_${id}` },
      'Employees'
    ]
  })
  ```

### Step 2: Build `ShiftAssignModal.jsx`
- Header:
  - Target shift details (Name, Code badge, Timing pill, Current headcount vs Max capacity).
- Content:
  - **Employee Selection**:
    - Embed `EmployeeSelectDropdown.jsx` or multi-select employee search component.
    - Ability to search by employee name, employee code, or department.
    - Shows employee's current shift if already assigned to a different schedule (with re-assignment warning).
  - **Currently Assigned Staff Sub-Table**:
    - Compact roster showing staff currently assigned to this shift.
    - Quick "Remove from Shift" button per staff member.
  - **Capacity Safeguard**:
    - Progress bar displaying headcount after assignment.
    - If `capacity > 0`, warns or blocks adding more staff than capacity allows.
- Actions:
  - "Cancel" button.
  - "Save Shift Assignments" button with loading state (`isAssigning`).

### Step 3: Wire Modal into `ShiftsPage.jsx`
- Triggerable from:
  - Table action menu: "Assign Staff" button (`UserPlus`).
  - Card view quick button: "Assign Staff".
  - Details modal footer: "Manage Staff".
- On success:
  - Show emerald success notification.
  - Automatically refresh shift statistics, employee counts, and list views.
