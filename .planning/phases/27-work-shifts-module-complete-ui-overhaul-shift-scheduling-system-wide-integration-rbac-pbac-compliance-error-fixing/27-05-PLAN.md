## 2. Step-by-Step Implementation

### Step 1: Real-Time Timing & Duration Calculation Engine
- Implement client-side calculation helper matching backend `calculateShiftTiming`:
  - Parses `startTime` (`HH:mm`) and `endTime` (`HH:mm`).
  - Detects if `endTime <= startTime` or `type === 'night'`.
  - Flags `isCrossMidnight = true`.
  - Calculates gross minutes:
    - If cross-midnight: adds $1440$ minutes.
  - Subtracts `breakMinutes` to compute `durationMinutes`.
  - Converts `durationMinutes` to hours and minutes (e.g., `8h 30m`).
  - Validation guards:
    - Displays immediate amber warning if `breakMinutes >= grossMinutes`.
    - Enforces gross shift duration $\ge 60$ minutes.

### Step 2: Redesign Form Fields & Visual Layout
- Structure modal into clean logical sections with Forest & Emerald styling:
  1. **Basic Information**:
     - Shift Name (required, text).
     - Shift Code (required, automatically uppercased).
     - Shift Type Selector (`Fixed Schedule`, `Flexible Hours`, `Night / Rotational Shift`).
     - Department Association (optional dropdown to restrict shift to specific department).
     - Color Badge Accent (color picker / preset palette for visual roster tagging).
  2. **Timing & Schedule Configuration**:
     - Start Time & End Time pickers (24h time format with interactive presets: `09:00 - 18:00`, `14:00 - 23:00`, `22:00 - 06:00`).
     - Live Duration & Overnight Indicator Card:
       - Displays gross duration, break deduction, and net working hours.
       - Highlights with animated Moon icon (`Crosses Midnight: Next Day Departure`) when overnight is detected.
     - Grace Period (`graceMinutes`, default 15m, min 0, max 120m).
     - Break Duration (`breakMinutes`, default 60m, min 0, max 240m).
     - Half-Day Threshold (`halfDayMinutes`, default 240m).
  3. **Work Days Selection**:
     - Interactive multi-select button group for days of the week: Mon, Tue, Wed, Thu, Fri, Sat, Sun.
     - Quick presets: `Mon - Fri (Standard)`, `Mon - Sat`, `Custom`.
  4. **Capacity & Operational Controls**:
     - Maximum Capacity (`capacity`: 0 = unlimited, or numerical limit).
     - Active Status Toggle.
     - Description (optional textarea).

### Step 3: Integrate with RTK Query Mutations
- Wire modal to `useCreateShiftMutation` and `useUpdateShiftMutation`.
- Clean error presentation: map backend `ApiError` responses to friendly inline alerts.
- Optimistic feedback: display success notifications upon creation/update and auto-refresh active queries.
