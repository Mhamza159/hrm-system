# Plan 10-01: High-Precision Degree & Experience Extraction Engine

## Objective
Fix false-positive degree and experience hallucinations in `ai.service.js`. Replace brittle unanchored regular expressions with context-aware, strict word-boundary extractors. Ensure that candidates with a Bachelor's degree are accurately extracted as `Bachelor's Degree`, and missing or ambiguous degrees return `Not Specified / Verification Required`.

## Proposed Changes
1. **`backend/src/services/ai.service.js`**:
   - Refactor `heuristicResumeParser`:
     - Implement strict word boundaries for degrees (`\bBSCS\b`, `\bBS\b\s+(?:in|of)?\s+Computer Science`, `\bBachelor(?:'s)?(?:\s+(?:of|degree|in))?\b`, etc.).
     - Strictly guard Master's degree regex (`\b(?:Master(?:'s)?\s+(?:of|in|degree)|M\.?Sc|M\.?Phil|MBA|M\.?Tech)\b`). Prevent words like "mastering", "scrum master", "systems", "cms" from triggering.
     - Add explicit support for Pakistani and international degree codes (`BSCS`, `BSSE`, `BSIT`, `B.E.`, `B.Tech`, `MCS`, `MSCS`, `F.Sc`, `ICS`).
     - Refine experience year estimation: calculate work experience spans while excluding education spans (`(2018 - 2022)` under Education).
     - If no degree is identified with high confidence, set `highestEducation: 'Not Specified / Verification Required'` instead of defaulting to an assumed degree.
2. **AI Prompt Hardening**:
   - Update `systemPrompt` in `parseResumeText`:
     - *"Do not assume or inflate educational degrees. If the resume states a Bachelor's degree, return exactly Bachelor's Degree; never convert to a Master's degree. If an attribute is missing or ambiguous, return 'Not Specified / Verification Required'."*
3. **Unit Tests**:
   - Create `backend/tests/m15.degreeAndExperienceAccuracy.test.js`:
     - Test all 3 real candidate CV texts (Noraiz Ali, Muhammad Naik, Muhammad Adnan) and verify they are identified as `Bachelor's Degree`.
     - Test negative boundary cases (e.g. "Mastering React", "Systems Architect", "CMS Developer", "Scrum Master").
     - Test zero-experience and multi-job experience cases.
