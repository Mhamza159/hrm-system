# Plan 30-03: Time, Attendance, Shifts & Leaves Frontend Visibility Audit

## Goal
Audit and enforce strict permission visibility across all Time, Attendance, Work Shifts, and Leaves modules. Ensure that unauthorized actions (e.g. Field Check-In, Attendance Lock/Unlock, Flagged Punch Approvals, Shift Allocation, Leave Approvals, Policy Configurations, and Leave Encashment) are completely hidden and never rendered as disabled or accessible controls.

## Target Files
- `frontend/src/features/attendance/pages/MyAttendancePage.jsx`
- `frontend/src/features/attendance/pages/TeamAttendancePage.jsx`
- `frontend/src/features/attendance/pages/AttendanceLockPage.jsx`
- `frontend/src/features/attendance/pages/KiosksPage.jsx`
- `frontend/src/features/attendance/components/PunchCardWidget.jsx`
- `frontend/src/features/attendance/pages/ShiftManagementPage.jsx`
- `frontend/src/features/leaves/pages/MyLeavesPage.jsx`
- `frontend/src/features/leaves/pages/LeaveApprovalsPage.jsx`
- `frontend/src/features/leaves/pages/EncashmentPage.jsx`
- `frontend/src/features/leaves/pages/TeamLeaveCalendarPage.jsx`

## Detailed Implementation Tasks
1. **Attendance Tracking & Punch Controls (`MyAttendancePage.jsx`, `PunchCardWidget.jsx`)**:
   - Field Check-in button: Only render if `can('attendance.fieldCheckIn') || isSuperAdmin`.
   - WFH Request trigger: Only render if `can('attendance.wfh') || isSuperAdmin`.
   - Attendance Correction modal trigger: Only render if `can('attendance.correction') || isSuperAdmin`.
   - Face Enrollment action: Only render if `can('attendance.mark') || isSuperAdmin`.
2. **Managerial Attendance & Governance (`TeamAttendancePage.jsx`, `AttendanceLockPage.jsx`, `KiosksPage.jsx`)**:
   - "Lock / Unlock Month" controls: Strictly hidden if `cannot('attendance.lock')`.
   - Punch approval / adjustment buttons on `TeamAttendancePage`: Only render if `can('attendance.approve')`.
   - Attendance export actions: Only render if `can('attendance.export')`.
   - Kiosk terminal registration & key reset: Strictly hidden if `cannot('attendance.kiosk.manage')`.
3. **Shift Scheduling & Allocation (`ShiftManagementPage.jsx`)**:
   - "Create New Shift" & "Assign Shift" triggers: Only render if `can('org.manage') || isSuperAdmin`.
   - Edit Shift & Delete Shift row buttons: Completely hidden if `cannot('org.manage')`.
4. **Leaves & Holidays Management (`MyLeavesPage.jsx`, `LeaveApprovalsPage.jsx`, `EncashmentPage.jsx`)**:
   - "Apply Leave" modal trigger: Only render if `can('leave.apply') || isSuperAdmin`.
   - "Approve" and "Reject" buttons in `LeaveApprovalsPage`: Strictly hidden if `cannot('leave.approve')`.
   - "Leave Encashment" submission / approval controls: Only render if `can('leave.encash')`.
   - "Export Leaves" button: Only render if `can('leave.export')`.
   - Leave policy settings triggers: Only render if `can('leave.settings')`.

## Verification & Acceptance Criteria
- Standard employees without managerial or approval permissions see zero approval buttons or lock controls.
- Users lacking `attendance.lock` cannot see the lock month button anywhere in attendance views.
- Users lacking `leave.approve` see zero action buttons on leave requests.
- Super Admin retains full administrative visibility across all attendance and leave controls.
