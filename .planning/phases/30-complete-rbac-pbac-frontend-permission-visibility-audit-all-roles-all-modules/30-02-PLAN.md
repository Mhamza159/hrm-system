# Plan 30-02: Core HR, Organization & Dashboard Frontend Visibility Audit

## Goal
Perform a complete frontend visibility audit and fix across the Core HR, Organization, and Dashboard modules. Ensure that unauthorized action buttons, menus, tabs, and modals (e.g. Onboard Employee, Bulk Ingest, Export, Edit, Delete, Compensation/Salary viewing, Add Department, Add Designation) do not render in the DOM for roles lacking the corresponding permission.

## Target Files
- `frontend/src/features/dashboard/pages/DashboardPage.jsx`
- `frontend/src/features/employees/pages/EmployeeListPage.jsx`
- `frontend/src/features/employees/pages/EmployeeProfilePage.jsx`
- `frontend/src/features/employees/components/EmployeeDetailModal.jsx`
- `frontend/src/features/departments/pages/DepartmentsPage.jsx`
- `frontend/src/features/departments/pages/DepartmentDetailPage.jsx`
- `frontend/src/features/departments/pages/DesignationsPage.jsx`
- `frontend/src/features/orgchart/pages/OrgChartPage.jsx`

## Detailed Implementation Tasks
1. **Executive Dashboard (`DashboardPage.jsx`)**:
   - Audit quick-action cards and executive metric widgets.
   - Guard quick actions: "Mark Attendance" (`attendance.mark`), "Apply Leave" (`leave.apply`), "Submit Expense" (`expense.create`), "View Reports" (`report.view`).
   - If user lacks permission for an action, the corresponding card or button must not render.
2. **Employee Management (`EmployeeListPage.jsx`, `EmployeeProfilePage.jsx`, `EmployeeDetailModal.jsx`)**:
   - "Onboard Employee" button: Only render if `can('employee.create') || isSuperAdmin`.
   - "Bulk Ingest" button: Only render if `can('employee.create') || isSuperAdmin`.
   - "Export" button: Only render if `can('employee.export') || isSuperAdmin`.
   - Row action menus (Edit, Archive, Reset Password, View Details):
     - Hide "Edit Employee" action if `cannot('employee.edit')`.
     - Hide "Archive / Delete" action if `cannot('employee.delete')`.
   - In `EmployeeDetailModal.jsx` and `EmployeeProfilePage.jsx`:
     - Completely hide the "Salary & Compensation" tab and all salary cards if `cannot('employee.salary.view')`.
     - Completely hide emergency contact or sensitive details if field-level permissions restrict them.
3. **Departments & Designations (`DepartmentsPage.jsx`, `DesignationsPage.jsx`, `DepartmentDetailPage.jsx`)**:
   - "Add Department" / "Add Designation": Only render if `can('org.manage') || isSuperAdmin`.
   - Edit and Archive/Delete row actions: Completely hide if `cannot('org.manage')`.
   - Manager assignment and headcount modification controls: Strictly hide if unauthorized.
4. **Org Chart (`OrgChartPage.jsx`)**:
   - Hide structural editing or node management tools unless actor has `org.manage`.
   - Hide export actions unless actor has `org.manage` or `report.export`.

## Verification & Acceptance Criteria
- Non-admin users without `employee.create` see zero Onboard/Ingest buttons in the employee directory.
- Users without `employee.salary.view` see zero salary tabs or compensation data anywhere in profiles or modals.
- Users without `org.manage` see clean read-only department/designation views with zero add/edit/delete buttons.
- Admin maintains complete visibility and control across all components.
