# Plan 30-04: Payroll, Loans, Expenses & Finance Frontend Visibility Audit

## Goal
Audit and enforce strict permission visibility across all Payroll, Loans, Expenses, and Finance modules. Ensure that unauthorized actions (e.g. Run Payroll, Approve Payroll Run, Adjust Payslip, Create Salary Structure, Disburse Loan, Foreclose Loan, Approve Expense, and Configure Categories) are strictly hidden from non-authorized roles.

## Target Files
- `frontend/src/features/payroll/pages/PayrollRunsPage.jsx`
- `frontend/src/features/payroll/pages/SalaryStructuresPage.jsx`
- `frontend/src/features/payroll/components/PayslipAdjustmentDrawer.jsx`
- `frontend/src/features/loans/pages/LoansPage.jsx`
- `frontend/src/features/loans/pages/LoanRequestsPage.jsx`
- `frontend/src/features/expenses/pages/ExpensesPage.jsx`
- `frontend/src/features/expenses/pages/ExpenseApprovalsPage.jsx`
- `frontend/src/features/expenses/pages/ExpenseCategoriesPage.jsx`

## Detailed Implementation Tasks
1. **Payroll Processing & Structure Administration (`PayrollRunsPage.jsx`, `SalaryStructuresPage.jsx`)**:
   - "Execute Payroll Run" button: Only render if `can('payroll.run') || isSuperAdmin`.
   - "Approve Run" & "Disburse" triggers: Only render if `can('payroll.approve') || isSuperAdmin`.
   - "Adjust Payslip" action button: Only render if `can('payroll.manage') || isSuperAdmin`.
   - "Download Bank Advice / Salary Summary" export buttons: Only render if `can('payroll.export') || isSuperAdmin`.
   - In `SalaryStructuresPage.jsx`: Hide "Create Component", "Edit Structure", and "Delete" if `cannot('payroll.manage')`.
2. **Loans & Advances Management (`LoansPage.jsx`, `LoanRequestsPage.jsx`)**:
   - "Apply for Loan" button: Only render if `can('loan.create') || isSuperAdmin`.
   - "Recommend Loan" action: Only render if `can('loan.recommend') || isSuperAdmin`.
   - "Approve Loan" & "Reject Loan" actions: Only render if `can('loan.approve') || isSuperAdmin`.
   - "Disburse" & "Early Foreclose" controls: Strictly hidden if `cannot('loan.prepay')`.
   - Loan Policy Settings modal: Strictly hidden if `cannot('loan.settings')`.
3. **Expense Claims & Approvals (`ExpensesPage.jsx`, `ExpenseApprovalsPage.jsx`, `ExpenseCategoriesPage.jsx`)**:
   - "Submit New Expense" trigger: Only render if `can('expense.create') || isSuperAdmin`.
   - "Approve Claim" & "Reject Claim" buttons on `ExpenseApprovalsPage`: Strictly hidden if `cannot('expense.approve')`.
   - "Mark as Reimbursed" payout controls: Only render if `can('expense.reimburse') || isSuperAdmin`.
   - In `ExpenseCategoriesPage.jsx`: Hide "Create Category", "Edit", and "Archive" if `cannot('expense.settings')`.

## Verification & Acceptance Criteria
- Non-finance roles see zero "Run Payroll" or "Approve Payroll" triggers.
- Non-approvers see zero approval/rejection buttons across loan and expense requests.
- All export and policy adjustment controls render exclusively for authorized actors.
- Super Admin retains full access to payroll, loan, and expense administration.
