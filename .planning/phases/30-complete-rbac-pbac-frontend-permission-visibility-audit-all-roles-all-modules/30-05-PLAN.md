# Plan 30-05: Talent, Recruitment, Performance, Assets & Governance Visibility Audit

## Goal
Audit and enforce strict frontend permission visibility across Talent & Recruitment (ATS), Performance Appraisals, Asset Management, Governance & Policies, Announcements, Roles & Permissions, Company Settings, and Anonymous Grievances. Ensure unauthorized actions do not render anywhere in the DOM.

## Target Files
- `frontend/src/features/recruitment/pages/JobsPage.jsx`
- `frontend/src/features/recruitment/pages/CandidatePipelinePage.jsx`
- `frontend/src/features/performance/pages/CycleManagementPage.jsx`
- `frontend/src/features/assets/pages/AssetsPage.jsx`
- `frontend/src/features/policies/pages/PoliciesPage.jsx`
- `frontend/src/features/announcements/pages/AnnouncementsPage.jsx`
- `frontend/src/features/roles/pages/RolesListPage.jsx`
- `frontend/src/features/settings/pages/CompanySettingsPage.jsx`
- `frontend/src/features/feedback/pages/GrievanceAdminPage.jsx`
- `frontend/src/features/feedback/pages/CommitteeDashboardPage.jsx`

## Detailed Implementation Tasks
1. **Recruitment & ATS (`JobsPage.jsx`, `CandidatePipelinePage.jsx`)**:
   - "Post Job Opening": Only render if `can('recruitment.job.create') || isSuperAdmin`.
   - "Advance Candidate Stage" & "Hire": Only render if `can('recruitment.candidate.edit') || isSuperAdmin`.
   - "Schedule Interview": Only render if `can('recruitment.interview.schedule') || isSuperAdmin`.
2. **Performance Management (`CycleManagementPage.jsx`)**:
   - "Create Appraisal Cycle" & "Launch Review": Only render if `can('performance.cycle.create') || isSuperAdmin`.
   - Rating calibration and reviewer reassignment: Strictly hidden if `cannot('performance.review.manage')`.
3. **Asset Inventory & Allocation (`AssetsPage.jsx`)**:
   - "Add New Asset": Only render if `can('asset.create') || isSuperAdmin`.
   - "Allocate to Staff" & "Return": Only render if `can('asset.assign') || isSuperAdmin`.
   - "Dispose / Mark Lost" actions: Only render if `can('asset.manage') || isSuperAdmin`.
4. **Corporate Policies & Announcements (`PoliciesPage.jsx`, `AnnouncementsPage.jsx`)**:
   - "Draft Policy" & "Publish": Only render if `can('policy.create') || can('policy.publish')`.
   - "Create Announcement" & "Pin to Top": Only render if `can('announcement.create') || can('announcement.pin')`.
   - Delete/Edit announcement buttons: Strictly hidden if unauthorized.
5. **Roles & Permissions Module (`RolesListPage.jsx`)**:
   - "Create Custom Role" button: Only render if `can('role.manage') || isSuperAdmin`.
   - Row action buttons (Edit Role, Delete Role, Clone Role):
     - Hide "Edit Role" if `cannot('role.manage')`.
     - Hide "Delete Role" if `cannot('role.manage')` or role is a system role.
     - Hide "Clone Role" if `cannot('role.manage')`.
   - "Assign Roles to User" modal button: Only render if `can('role.assign') || isSuperAdmin`.
6. **Company Settings & Grievance Governance (`CompanySettingsPage.jsx`, `GrievanceAdminPage.jsx`)**:
   - In `CompanySettingsPage.jsx`: Hide "Save Configuration", security policies, and integrations if `cannot('settings.manage')`.
   - In `GrievanceAdminPage.jsx` & `CommitteeDashboardPage.jsx`: Hide investigation controls, status progression, and disciplinary actions if `cannot('feedback.manage')` and not committee member.

## Verification & Acceptance Criteria
- Unauthorized users see clean read-only interfaces with zero action buttons or admin toolbars.
- Candidates cannot be moved or hired by users without recruitment management authority.
- Custom roles cannot be created or cloned by users without `role.manage`.
- Super Admin retains complete access across all governance, recruitment, asset, and settings controls.
