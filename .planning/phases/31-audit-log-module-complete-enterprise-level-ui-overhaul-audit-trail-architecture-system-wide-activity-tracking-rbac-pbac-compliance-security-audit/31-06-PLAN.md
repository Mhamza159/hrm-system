# Plan 31-06: RBAC/PBAC Enforcement, Zero UI Leakage, System-Wide Vitest Test Suite & Master Audit Documentation

## Objective
Enforce strict RBAC and PBAC authorization across the Audit Log module. Ensure Zero UI Leakage (unauthorized navigation, tabs, export buttons, and actions return `null` immediately rather than rendering disabled or greyed-out). Implement comprehensive automated Vitest test suites verifying multi-role security boundaries, analytics accuracy, export filtering, and immutability invariants. Update master roadmap and documentation.

## Tasks
1. **RBAC & PBAC Permissions Audit (`backend/src/shared/permissions.js` & `frontend/src/lib/ability.js`)**:
   - Register explicit granular audit permissions:
     - `audit.view`: Access the audit log screen, inspect timeline, and view details modal.
     - `audit.analytics`: View audit analytics, statistics, and activity charts.
     - `audit.export`: Trigger CSV/Excel compliance data export.
   - Guard frontend routes in `App.jsx` and navigation items in sidebar:
     - If role lacks `audit.view`, the sidebar navigation pill does not render at all (`null`).
     - In `AuditLogsPage.jsx`, if role lacks `audit.export`, the export action button is omitted completely (`null`).
     - In `AuditLogsPage.jsx`, if role lacks `audit.analytics`, the analytics section is omitted completely (`null`).
   - Retain full administrative authority for `manage:all` and `Super Admin`.

2. **Automated End-to-End Test Suite (`backend/tests/audit.module.overhaul.test.js`)**:
   - Test 1: Super Admin can query audit logs, fetch stats, and retrieve analytics.
   - Test 2: Multi-filter query verification (module, action, status, severity, category, date range).
   - Test 3: Single audit log forensic inspection with structured before/after diffs.
   - Test 4: Export endpoint generates CSV format and logs an internal `AUDIT_LOGS_EXPORTED` event.
   - Test 5: Retention summary endpoint returns verified active/archived counts.
   - Test 6: Sensitive data masking test (passwords and raw authorization tokens are redacted).
   - Test 7: Unauthorized role rejection (HR Manager without audit permission receives HTTP 403).
   - Test 8: Regular employee rejection (receives HTTP 403 on all audit endpoints).
   - Test 9: Public unauthenticated requests receive HTTP 401 Unauthorized.
   - Test 10: Immutability test — verify `PUT` / `PATCH` / `DELETE` on `/api/v1/audit-logs/:id` returns 404/405 (audit logs cannot be modified or deleted via CRUD).

   - Update Serena persistent memories and Memory MCP.
