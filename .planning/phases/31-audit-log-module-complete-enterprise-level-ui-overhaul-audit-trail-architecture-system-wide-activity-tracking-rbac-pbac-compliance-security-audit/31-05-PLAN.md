# Plan 31-05: Enterprise Audit Explorer, Multi-View Suite & Forensic Details Modal

## Objective
Deliver a comprehensive audit exploration console with multi-view capabilities (Standard Table, Chronological Timeline, and User Activity History). Redesign the main listing, advanced filter bar, export dialog, retention information modal, and the deep-diff forensic details modal with side-by-side state comparison, actor attribution card, device parsing, and request context.

## Tasks
1. **Multi-View Audit Explorer (`frontend/src/features/audit/pages/AuditLogsPage.jsx`)**:
   - Integrate view mode switcher pills:
     - `Table View`: High-density enterprise data table.
     - `Timeline View`: Chronological event feed grouped by date with visual connectors.
     - `User Activity View`: Grouped breakdown by actor to review an individual user's complete operational history.
   - Embed search and filter toolbar with multi-criteria support:
     - Free-text search (actor email, action, target model).
     - Module dropdown (All, Auth, Employees, Payroll, Attendance, Leaves, Roles, Settings, Shifts).
     - Category dropdown (All, Authentication, Data Change, Security, Administrative, System).
     - Status toggle (All, Success, Failure).
     - Severity dropdown (All, Low, Medium, High, Critical).
     - Date range picker (Today, Yesterday, Last 7 Days, This Month, Custom).

2. **Forensic Details Modal (`frontend/src/features/audit/components/AuditLogDiffModal.jsx`)**:
   - Completely overhaul into an enterprise forensic inspection modal:
     - **Header Bar**: Action title, event reference ID, timestamp (PKT), status badge (`SUCCESS` / `FAILURE`), and severity pill.
     - **Actor Attribution Card**: Avatar, full name, email, role badge, IP address, and parsed client device (Browser icon + OS name).
     - **Target Entity Card**: Module pill, Target Model, Target Record ID, with conditional navigation button to target document if user has permissions.
     - **State Transition Diff**:
       - Structured side-by-side comparison (Before vs. After).
       - Color-coded highlights: Green for added fields, Amber for modified values, Red for removed fields.
       - Deep handling for nested objects and arrays with formatted types (numbers, booleans, dates).
       - Redaction masking for sensitive fields.
     - **Request Context & Outcome**: HTTP method, route/endpoint, failure reason (if error occurred).

3. **Export & Retention Modals**:
   - Build `AuditExportModal.jsx`: Select export format (CSV / Excel), choose date range and module scope, with live progress spinner and instant download.
   - Build `AuditRetentionModal.jsx`: Display active vs archived record counts, statutory retention policy details (Pakistan Companies Act / Labor Law record keeping), and archival trigger.

## Verification Criteria
- All 3 views (Table, Timeline, User Activity) render identical authorized audit data cleanly.
- Forensic Details Modal renders complete actor, device, target, and before/after diffs without exposing raw MongoDB internals or passwords.
- Modals handle responsive viewports and light/dark theme seamlessly.
- Table pagination, sorting, and multi-filter resets execute instantaneously.
