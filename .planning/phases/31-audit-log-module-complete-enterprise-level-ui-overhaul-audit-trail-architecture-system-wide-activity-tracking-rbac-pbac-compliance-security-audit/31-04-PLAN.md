# Plan 31-04: Audit Log Dashboard, Hero Metrics & Real-Time Analytics UI

## Objective
Design and implement an enterprise-grade Audit Log Monitoring Dashboard following the official design system (`Docs/design.md` and `Docs/UI-reference.md`). Create responsive summary KPI cards, interactive activity velocity charts, module distribution visuals, security trend meters, and time-range selector controls.

## Tasks
1. **RTK Query Endpoints Enhancement (`frontend/src/features/audit/auditApi.js`)**:
   - Add `getAuditStats: builder.query({ query: (params) => ({ url: '/audit-logs/stats', params }), providesTags: ['AuditLog'] })`.
   - Add `getAuditAnalytics: builder.query({ query: (params) => ({ url: '/audit-logs/analytics', params }), providesTags: ['AuditLog'] })`.
   - Add `getAuditRetentionSummary: builder.query({ query: () => '/audit-logs/retention', providesTags: ['AuditLog'] })`.
   - Add `exportAuditLogs: builder.mutation({ query: (params) => ({ url: '/audit-logs/export', params, responseHandler: 'blob' }) })`.

2. **Dashboard Hero KPI Metric Cards (`frontend/src/features/audit/components/AuditStatsCards.jsx`)**:
   - Build a 4x2 responsive card grid featuring:
     - **Total Audit Events**: All-time recorded immutable activities with activity indicator.
     - **Today's Activity**: Daily volume with comparison to 7-day average velocity.
     - **Successful Operations**: Green theme pill with success rate percentage badge.
     - **Failed Operations**: Amber/Red badge highlighting failures requiring review.
     - **Security Events**: Shield icon tracking authentication failures and lockouts.
     - **Administrative Actions**: Key role/privilege modifications and structural changes.
     - **Critical Events**: High-impact administrative actions requiring forensic attention.
     - **Active Actors**: Count of unique team members generating audit entries.
   - Use Emerald/Slate semantic tokens, subtle borders (`#EAECF0`), and clean Lucide iconography.

3. **Analytics Visualization Section (`frontend/src/features/audit/components/AuditAnalyticsSection.jsx`)**:
   - **Activity Velocity Trend Chart**: Recharts Area/Line chart visualizing hourly/daily event throughput with Success vs. Failure curves.
   - **Module Distribution Donut / Bar Chart**: Breakdown of event frequency across Employees, Attendance, Payroll, Roles, Shifts, and Auth.
   - **Security Activity Monitor**: Dedicated indicator bar for failed logins, access denials, and permission modifications.
   - **Time Range Selector Toolbar**: Quick toggles for `Last 24 Hours`, `Last 7 Days`, `Last 30 Days`, and `Custom Range`.
   - Support light/dark mode with proper tooltip styling and zero fake/hardcoded numbers.

## Verification Criteria
- Dashboard KPI cards display live database data and animate gracefully on refresh.
- Analytics charts render real time-series data with formatted PKT tooltips.
- Visual language adheres strictly to `docs/ui-reference.png` and `docs/UI-REFERENCE.md`.
- Layout is responsive across mobile (single column), tablet (2 columns), and desktop (4 columns).
