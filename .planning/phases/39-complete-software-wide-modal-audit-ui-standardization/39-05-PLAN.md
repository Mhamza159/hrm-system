# Plan 39-05: Software-Wide Modal Backdrop & Black Shadow Cleanup

**Objective:** Audit and eliminate all harsh, opaque black overlays (`bg-black/70`, `bg-black/80`, `bg-slate-950/70`, etc.) and duplicate backdrops across all feature module modals, establishing uniform `bg-slate-900/40 backdrop-blur-sm` and clean `shadow-2xl` elevation.

## 2. Requirements & Implementation Details

- **Standard Backdrop Token:**
  - Replace all `bg-black/60`, `bg-black/70`, `bg-black/75`, `bg-black/80`, `bg-slate-950/60`, `bg-slate-950/70` with the standard:
    `bg-slate-900/40 backdrop-blur-sm` (or `bg-black/30 backdrop-blur-xs` where lightweight blur is preferred).
- **Remove Duplicate Backdrop Layers:**
  - In components where an outer wrapper has a dark background AND an inner `<div className="fixed inset-0 bg-..." />` exists, consolidate into a single clean backdrop container with `onClick={onClose}` on the backdrop and `onClick={(e) => e.stopPropagation()}` on the modal card.
- **Card Shadow & Border Standardization:**
  - Ensure every modal dialog container has `shadow-2xl border border-slate-200 dark:border-[#1A3125] rounded-2xl bg-white dark:bg-[#111D17]`.
  - Remove any custom `shadow-[0_0_..._black]` or sprawling CSS drop shadows.

## 3. Verification Criteria

- [ ] Zero instances of `bg-black/70`, `bg-black/80`, `bg-slate-950/70`, or `bg-opacity-75+` remain.
- [ ] No dark "black shadow" engulfs the screen when opening any modal across all modules.
- [ ] Modals display a clean, contained `shadow-2xl` on their own container.
- [ ] Oxlint reports 0 errors.
