# Plan 39-01: Shared Modal Architecture & Universal Modal Standard Contract

**Objective:** Audit, align, and harden all shared modal and dialog primitives in `frontend/src/components/common` to establish the universal design tokens and structural contract for the entire application.

---

## 1. Scope & Targeted Files

1. `frontend/src/components/common/ConfirmDialog.jsx`
2. `frontend/src/components/common/ErrorModal.jsx`
3. `frontend/src/components/common/PermissionDeniedModal.jsx`
4. `frontend/src/components/common/SessionExpiredModal.jsx`
5. `frontend/src/components/common/SuccessModal.jsx`
6. `frontend/src/components/common/ModalSkeleton.jsx`

---

## 2. Requirements & Implementation Details

- **Backdrop Standardization:**
  - Standardize all overlays to `fixed inset-0 z-[60] flex items-center justify-center p-4 bg-slate-900/40 backdrop-blur-sm animate-in fade-in duration-200`.
  - Remove duplicate backdrop elements or harsh dark opacity (`bg-black/80` or `bg-slate-950/80`).
- **Container Architecture:**
  - Card: `rounded-2xl border border-slate-200 dark:border-[#1A3125] bg-white dark:bg-[#111D17] shadow-2xl animate-in zoom-in-95 duration-200`.
  - Subtle, clean elevation; no heavy black box shadows spreading over the screen.
- **Header, Typography & Close Button:**
  - Semantic title with accessible ID (`aria-labelledby`).
  - Standardized close icon button with rounded-lg hover states.
- **Accessibility & Keyboard Navigation:**
  - Escape key listener cleanly registered and detached on unmount.
  - Initial focus retention.

---

## 3. Verification Criteria

- [ ] All 6 shared components render with the standardized `bg-slate-900/40 backdrop-blur-sm` overlay.
- [ ] No double backdrops or stacked opaque layers exist.
- [ ] Keyboard dismissal (`Escape`) works predictably.
- [ ] Oxlint reports 0 errors.
