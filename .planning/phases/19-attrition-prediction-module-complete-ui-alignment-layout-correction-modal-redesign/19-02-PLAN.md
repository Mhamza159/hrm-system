# Plan 19-02: Charts Suite Geometry, Grid Height Balance & SVG Responsive Polish

## 1. Goal
Audit, align, and completely polish the **Analytical Charts Suite** in the Attrition Prediction Module. Standardize the container heights and padding across the grid so that `AttritionRiskDonutChart.jsx` and `AttritionFactorsChart.jsx` share the exact same height (`h-full`), align the header badges and typography, refine the native SVG donut ring and legend layout, and polish `DepartmentRiskChart.jsx` with responsive SVG viewBox, aligned X-axis labels, standardized bar widths, and elevated glassmorphism tooltips.

---

## 2. Target Files & Scope
- `frontend/src/features/attrition/components/AttritionRiskDonutChart.jsx`
- `frontend/src/features/attrition/components/AttritionFactorsChart.jsx`

## 3. Detailed Tasks

### Task 1: Equal-Height Grid Alignment for Row 1 Charts
- Standardize the outer grid container: `grid grid-cols-1 lg:grid-cols-3 gap-6 items-stretch`.
- Both `AttritionRiskDonutChart.jsx` (`lg:col-span-1`) and `AttritionFactorsChart.jsx` (`lg:col-span-2`):
  - Must use `h-full flex flex-col justify-between` to ensure identical top and bottom card boundaries.
  - Standardized header section: `p-5 pb-3 border-b border-[#1A3125] flex items-center justify-between` with identical icon box (`w-8 h-8 rounded-lg`) and header badge typography.

### Task 2: Donut Chart Layout & SVG Centering (`AttritionRiskDonutChart.jsx`)
- Center the SVG donut circle and central score gauge cleanly within its container.
- Prevent vertical stretching or distortion on wide desktop screens.
- Standardize the legend button list:
  - Uniform button height, clean spacing (`gap-2`), and non-wrapping text.
  - Percentage labels formatted in monospace tabular font.
  - Interactive hover state that elevates without shifting the container layout.

### Task 3: Contributing Factors Chart Layout & Spacing (`AttritionFactorsChart.jsx`)
- Distribute the 5 factor signal rows evenly across the vertical space (`space-y-4 py-3 flex-1 flex flex-col justify-around`).
- Factor progress bar containers:
  - Standardized height: `h-2` with `rounded-full overflow-hidden bg-[#162820]`.
  - Factor labels and percentage values aligned to the same baseline with `font-mono`.
  - Description tooltips styled with consistent muted text (`text-[11px] text-[#7E9E8F]`) that wraps cleanly without breaking flex containers.

### Task 4: Department Stacked Bar Chart Polish (`DepartmentRiskChart.jsx`)
- Standardize chart padding (`p-5 rounded-2xl border border-[#1A3125] bg-[#111D17]`).
- X-Axis & Y-Axis Alignment:
  - Ensure horizontal gridlines line up with tabular numerical labels.
  - Department names below bars truncated cleanly to prevent overlap on narrow viewports.
  - Average risk score tags positioned consistently below department names.
- Elevated Glassmorphism Tooltip:
  - Modernized tooltip card with dark backdrop blur (`bg-[#061A14]/95 backdrop-blur-md border border-[#1A3125] rounded-xl p-3 shadow-2xl`).
  - Standardized width (`min-w-[220px]`), structured rows, and high-contrast typography.
