# Plan 17-03: Message Composer, Attachment Vaulting & Real-Time Socket Telemetry

## 1. Goal
Audit, modernize, and completely redesign the **Message Composer** (`MessageInput.jsx`) and refine the **Socket Lifecycle Hook** (`useChatSocket.js`). Deliver an intuitive, responsive message composer with multiline auto-expansion, 10MB file and image upload previews, typing debouncers, keyboard shortcuts, archival locks, and synchronized real-time WebSocket state.

---

## 2. Target Files & Scope
- `frontend/src/features/chat/components/MessageInput.jsx`
- `frontend/src/features/chat/hooks/useChatSocket.js`

---

## 3. Detailed Tasks

### Task 1: Message Composer & File Uploading (`MessageInput.jsx`)
- **Composer Layout & Container**:
  - Dark enterprise footer container (`bg-[#111D17] border-t border-[#1A3125] p-3`).
  - Textarea with multiline support: auto-expands from 1 to 4 rows on input.
  - Placeholder: `"Type a message... (Press Enter to send, Shift+Enter for new line)"`.
- **Vaulted File Upload Interface**:
  - Hidden file input triggered by a paperclip icon button.
  - Client-side validation: 10MB maximum file size limit with immediate Sonner toast feedback for oversized files.
  - Upload via `useUploadAttachmentMutation` (`/chat/upload`).
  - Pending Attachment Preview Card:
    - Renders directly above the input bar when a file is staged.
    - Shows file type icon (Image vs Document), file name, size, and remove button (`X`).
- **Send & Keyboard Action Controls**:
  - Emerald Send Action Button (`bg-[#00C471] hover:bg-[#00B064] text-white p-2.5 rounded-xl`).
  - Disabled state when both message text and pending attachment are empty.
  - Loading state with animated spinner while dispatching.
  - Keyboard handling: Enter key sends message; Shift + Enter inserts a newline.
- **Archival Lock Banner**:
  - If `isArchived` is true, replace the composer with a clean read-only banner:
    - Lock icon in amber.
    - Advisory text: `"This channel has been archived by executive administration and is in read-only mode."`

### Task 2: Real-Time Socket Lifecycle & Telemetry (`useChatSocket.js`)
- **Room Subscriptions**:
  - Automatically emits `chat:join` when `activeConversationId` changes.
  - Automatically emits `chat:leave` when navigating away or changing conversations.
- **Typing Telemetry**:
  - `emitTyping(isTyping)` triggers `chat:typing` with 2-second debounce timer.
  - Tracks incoming `chat:typing` events by user ID and clears after 3 seconds of inactivity.
- **Presence Tracking**:
  - Listens to `chat:presence` and maintains a reactive `Set` of online user IDs.
  - Provides helper `isUserOnline(userId)` for instant presence check.
- **Cache Invalidation**:
  - On incoming `chat:message`, invalidates `{ type: 'Message', id: conversationId }` and `{ type: 'Conversation', id: 'LIST' }`.
  - On `chat:read`, updates read receipt status across participants.
