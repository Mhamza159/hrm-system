## 3. Detailed Tasks

### Task 1: New Direct Chat Modal (`NewChatModal.jsx`)
- Redesign modal dialog using Forest & Emerald styling (`#111D17` surface, `#1A3125` border, `#00C471` accents):
  - Header with `UserPlus` icon and clean close button.
  - Search input filtering active directory coworkers in real time.
  - Coworker list items:
    - Avatar image with fallback initials.
    - Coworker display name, designation, department tag, and email.
    - Online presence indicator dot.
  - One-click conversation creation (`createConversation({ type: 'direct', participantId })`), instantly selecting the new/existing room and closing the modal.

### Task 2: New Group Channel Modal (`NewGroupModal.jsx`)
- Redesign modal dialog for custom multi-user group creation:
  - Inputs for Group Name (required) and Description (optional).
  - Colleague multi-select search picker:
    - Searchable directory of coworkers.
    - Checkbox toggle for each colleague.
    - Selected members badge pills at the top with one-click remove (`X`).
  - Validation: Requires group name and at least 1 other participant.
  - "Create Group Channel" action button with loading spinner and Sonner toast confirmation.

### Task 3: Channel Info & Participant Drawer (`GroupInfoDrawer.jsx`)
- Redesign slide-over drawer (`#111D17` panel, `#1A3125` border):
  - **Header & Meta**: Channel name, type badge (`Group` vs `Department`), and creation date.
  - **Participants Roster**:
    - List of members with avatar, name, and live online presence dot.
    - Admin badge / star icon next to the channel administrator.
    - Member removal button (`UserMinus`) available exclusively to Group Admin and Super Admin.
  - **Add Member Section**:
    - Colleague selector for adding existing coworkers to the group.
    - Restricted to Group Admin and Super Admin.
  - **Super Admin Archival Control**:
    - "Archive Conversation" button visible strictly to Super Admins (`chat.archive`).
    - Confirmation dialog warning of irreversible read-only freeze.

### Task 4: Complete Module Verification Gate
- Verify full PBAC permission enforcement:
  - `chat.access`: All active employees can chat in their assigned conversations.
  - `chat.create_group`: Employees can create custom groups.
  - `chat.archive`: Super Admin only can archive conversations.
- Ensure zero `prop-types` imports across all 9 chat files.
- Run Oxlint on `frontend/src/features/chat/` and verify 0 errors and 0 warnings.
- Run `npm run build` in `frontend/` and verify the Vite production build exits with code 0.
