# Plan 17-02: Active Chat Feed, Header & Message Bubbles Stream

## 1. Goal
Audit, modernize, and completely redesign the **Active Chat Feed** (`ChatArea.jsx`) and **Message Bubbles** (`MessageBubble.jsx`). Deliver a high-craft real-time messaging experience with Forest & Emerald styling, conversational header with presence status, in-conversation message search, typing telemetry, distinct sender/receiver message geometry, rich attachment previews, and read receipt indicators.

---

## 2. Target Files & Scope
- `frontend/src/features/chat/components/ChatArea.jsx`
- `frontend/src/features/chat/components/MessageBubble.jsx`

---

## 3. Detailed Tasks

### Task 1: Chat Area Header & In-Conversation Search (`ChatArea.jsx`)
- **Active Channel Header**:
  - Left Section:
    - Mobile back navigation arrow (`md:hidden`).
    - Participant/Group Avatar with real-time online presence dot.
    - Channel Name: Direct chat partner name or Group title (`font-bold text-sm text-slate-900 dark:text-[#F8FAFC]`).
    - Subtitle:
      - For 1-to-1 chats: Live status indicator ("🟢 Active Now" or "Offline").
      - For Groups/Departments: Total participant count (`"12 members"`).
  - Right Section Actions:
    - In-conversation search toggle button.
    - Channel Info Drawer trigger button (`Info` icon).
- **In-Conversation Search Bar**:
  - Slide-down or inline search bar when toggled.
  - Full-text search across current conversation messages using `useLazySearchMessagesQuery`.
  - Result counter and quick dismissal button.

### Task 2: Message Stream Container & Typing Telemetry (`ChatArea.jsx`)
- **Scroll Container**:
  - Smooth auto-scrolling to the latest message (`messagesEndRef`).
  - Loading skeleton / spinner during historical message retrieval.
  - Empty channel hero: "This is the start of your encrypted conversation with [Name]. Say hello!"
- **Live Typing Telemetry Indicator**:
  - Smooth animated typing banner positioned right above the input bar ("Sarah is typing...").
  - Animated pulsing dots in emerald.
- **Archival Lock Banner**:
  - Display when `conversation.isArchived === true`.
  - Warning banner indicating the channel has been placed in read-only mode by executive administration.

### Task 3: Message Bubble Redesign (`MessageBubble.jsx`)
- **Sender Message Bubble (Outgoing)**:
  - Aligned to the right.
  - Background: Emerald accent (`bg-[#00C471] text-white`).
  - Geometry: Rounded 2xl with tailored bottom-right tail.
  - Timestamp in subtle white opacity (`text-white/80`).
  - Read receipts: Double checkmark (`CheckCheck`) in bright white when read by recipient.
- **Recipient Message Bubble (Incoming)**:
  - Aligned to the left.
  - Background: Dark enterprise card (`bg-[#111D17] border border-[#1A3125] text-[#F8FAFC]`).
  - Geometry: Rounded 2xl with tailored bottom-left tail.
  - Sender avatar and name shown for group channels.
  - Timestamp in muted slate/emerald (`text-[#7E9E8F]`).
- **Rich Attachment Display**:
  - Image attachments: Inline rounded preview thumbnail with hover zoom and click-to-expand.
  - Documents & PDFs: Styled card showing document icon, file name, formatted file size (KB/MB), and direct download button.

---

- [ ] Header accurately displays coworker name, avatar, and live presence status.
- [ ] In-conversation search finds matching messages.
- [ ] Outgoing and incoming message bubbles have distinct, accessible styling with high contrast.
- [ ] Read receipts display single checkmark for sent and double checkmarks for read.
