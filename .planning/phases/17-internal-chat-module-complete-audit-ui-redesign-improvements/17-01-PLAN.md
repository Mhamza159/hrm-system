# Plan 17-01: Chat Workspace Layout, Split View & Conversation List Sidebar

## 1. Goal
Audit, modernize, and completely redesign the **Chat Workspace Layout** (`ChatPage.jsx`) and the **Conversation List Sidebar** (`ConversationList.jsx`). Elevate the messaging interface with Forest & Emerald Enterprise styling (`#061A14` canvas, `#111D17` panels, `#1A3125` borders, `#00C471` emerald accents), responsive mobile view toggling, real-time presence indicators, unread count badges, and categorized conversation tabs (`All`, `Direct`, `Groups`, `Department`).

---

## 2. Target Files & Scope
- `frontend/src/features/chat/pages/ChatPage.jsx`
- `frontend/src/features/chat/components/ConversationList.jsx`

---

## 3. Detailed Tasks

### Task 1: Chat Workspace Container & Layout Redesign (`ChatPage.jsx`)
- Redesign the root container to fit seamlessly within the HRMS dashboard layout (`h-[calc(100vh-4rem)]` with `#061A14` canvas, `#111D17` surfaces, and `#1A3125` borders).
- Implement responsive view switching:
  - **Desktop ($\ge$ 768px)**: Split view displaying persistent sidebar and active chat feed side-by-side.
  - **Mobile (< 768px)**: When a conversation is selected, the message feed fills 100% width with a "Back to Conversations" navigation button.
- Empty State Hero:
  - Display when no conversation is active.
  - High-craft illustration/badge with MessageSquare icon.
  - Quick action buttons: "Start Direct Chat" (opens `NewChatModal`) and "Create Group Channel" (opens `NewGroupModal`).
- Loading State:
  - Clean animated loader with "Connecting to enterprise communication channels..." indicator.

### Task 2: Conversation List Sidebar (`ConversationList.jsx`)
- **Header & Action Toolbar**:
  - Title: "Team Messages" with message icon badge.
  - Quick action triggers:
    - Sync Department Channel button with spinner (`useSyncDepartmentChannelMutation`).
    - Create Group button.
    - "New Chat" primary action button with emerald styling (`bg-[#00C471] hover:bg-[#00B064] text-white`).
- **Full-Text Filter Search Bar**:
  - Integrated search input filtering conversations by coworker name or message preview text in real time.
- **Segmented Filter Tabs**:
  - 4 tabs: `All`, `Direct`, `Groups`, `Department`.
  - Active tab highlighted with emerald pill styling (`bg-[#00C471] text-white`).
- **Conversation Card Roster**:
  - Coworker Avatar: Circular avatar image with fallback initials.
  - Online Presence Indicator: Glowing emerald dot (`#00C471`) for online coworkers; subtle ring for offline.
  - Channel Type Insignia: Subtle icon for group conversations (Users) vs department rooms (Building).
  - Timestamp: Relative time formatting (`formatLastTime`).
  - Message Snippet: Truncated single-line preview of latest message with sender attribution.
  - Unread Count Badge: High-contrast emerald pill (`bg-[#00C471] text-white font-bold`).
  - Active Selection Indicator: Border glow and emerald tint (`bg-[#00C471]/10 border-l-2 border-[#00C471]`).

- [ ] Searching conversations filters by coworker name and message content dynamically.
- [ ] Segmented tabs correctly partition `direct`, `group`, and `department` channels.
