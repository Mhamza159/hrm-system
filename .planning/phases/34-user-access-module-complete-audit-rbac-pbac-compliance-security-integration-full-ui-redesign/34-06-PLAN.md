## 1. Goal
Overhaul and integrate all user access mutation dialogs (guarded role assignment modal with privilege escalation defense, account status confirmation modal, security action modals for unlocking accounts, session revocation, and emergency password resets), orchestrate `UsersPage.jsx`, and conduct end-to-end automated testing to guarantee 100% test pass rate and clean production build.

---

## 2. Requirements & Scope

1. **Guarded Role Assignment Modal (`UserRoleAssignModal.jsx`)**:
   - Displays target user identity summary and current assigned role(s).
   - Fetches available system and custom roles from `rolesApi.js`.
   - **Privilege Escalation Defense**:
     - Disables Super Admin role selection for non-Super Admin actors.
     - Disables roles containing permissions not possessed by the acting administrator.
     - Warning banner when assigning high-privilege roles.
   - Shows role description, system badge, and permission count.
   - Captures assignment reason for audit trail.

2. **Account Status Modal (`UserStatusActionModal.jsx`)**:
   - Guarded confirmation for Activating or Deactivating user accounts.
   - Clear warning explaining that deactivation immediately terminates active sessions and blocks authentication.
   - Mandatory justification reason input.

3. **Security Action Modals (`UserSecurityActionsModal.jsx`)**:
   - **Unlock Account Dialog**: Displays remaining lockout duration and clears failed login attempts upon confirmation.
   - **Revoke Sessions Dialog**: Confirms immediate eviction of all active refresh tokens without changing password.
   - **Emergency Password Reset Dialog**: Confirms dispatching temporary credentials via email.
   - **Force Password Change Dialog**: Mandates password change on user's next login attempt.

4. **Master Page Orchestration (`UsersPage.jsx`)**:
   - Replace legacy implementation with modular component architecture:
     - `PageHeader` with real-time stats refresh.
     - `UserAccessDashboard` with clickable metric cards.
     - `UserAccessFilterBar` with live filters.
     - `UserAccessTable` with full pagination and action menus.
     - Modals for Inspection, Role Assignment, Status Toggle, and Security Actions.
   - Toast feedback with Sonner and real-time cache invalidation.

5. **Automated Verification Suite (`backend/tests/userAccess.module.overhaul.test.js`)**:
   - Test 1: User listing with pagination, search, and deep employee population.
   - Test 2: KPI statistics aggregation (`/users/stats`).
   - Test 3: Account status toggle (activate/deactivate) and session invalidation.
   - Test 4: Account lockout simulation and administrative unlock API.
   - Test 5: Role assignment with privilege escalation checks.
   - Test 6: Effective permissions calculation and compilation.
   - Test 7: PBAC departmental scoping enforcement.
   - Test 8: Session revocation API execution.
   - Test 9: Force password change mandate enforcement.
   - Test 10: Zero Oxlint errors and clean Vite production build.
