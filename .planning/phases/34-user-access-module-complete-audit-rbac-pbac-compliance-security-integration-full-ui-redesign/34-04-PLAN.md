# Plan 34-04: Enterprise User Access Explorer, Multi-Criteria Filter Suite & High-Density DataTable

**Phase**: 34 — User Access Module Overhaul  
**Status**: Planned  
**Layer**: Frontend UI & Interactive Components  
**Estimated Complexity**: High  

---

## 1. Goal
Build a high-density, enterprise-grade User Access Explorer featuring a sticky multi-criteria filter toolbar (debounced search, role dropdown, department filter, account status chips, 2FA toggle, active filter counter) and a full-featured DataTable showcasing complete employee identity, assigned role badges, account state, relative last login timestamps, and quick action dropdowns.

---

## 2. Requirements & Scope

1. **Sticky Multi-Criteria Filter Toolbar (`UserAccessFilterBar.jsx`)**:
   - Debounced text search (searching full name, email, employeeCode).
   - Role filter dropdown (All, Super Admin, HR Manager, Department Manager, Employee).
   - Department filter dropdown (fetched via `useGetDepartmentsQuery`).
   - Account Status segmented pills (All, Active, Inactive, Locked).
   - Access Status toggle (All, Assigned Roles, Unassigned Roles).
   - Active filter count chip with a 1-click "Reset All Filters" button.

2. **High-Density User Access DataTable (`UserAccessTable.jsx`)**:
   - **User & Employee Identity Cell**: Avatar with fallback initials, full personal name, email address, and employee code pill.
   - **Department & Designation Cell**: Linked department name and job title with icons.
   - **Assigned Roles Cell**: Styled role badges with multiple role chips support.
   - **Account & Security Status Cell**:
     - Semantic Status Badge (`Active` in Emerald, `Inactive` in Rose/Slate).
     - Locked indicator banner if `lockUntil > now` with remaining lockout minutes.
     - 2FA badge (Shield check indicator).
   - **Last Login & Registration Cell**: Relative timestamp (e.g., "2 hours ago", "Yesterday") or "Never logged in" fallback.
   - **Actions Column**:
     - Quick Inspect button (opens 5-tab forensic modal).
     - Quick Role Assign button (opens role assignment modal).
     - Security Actions dropdown (Unlock Account, Reset Password, Force Password Change, Revoke Sessions, Toggle Active/Inactive).
   - Pagination footer with page-size selector (10, 25, 50 per page), record counter ("Showing 1 to 10 of 48 users"), and pagination buttons.

3. **Loading, Empty & Error States**:
   - Skeleton shimmer placeholders for loading state.
   - Empty state illustration with helpful filter reset suggestions.

---

## 3. Implementation Steps

1. Create `frontend/src/features/users/components/user-access/UserAccessFilterBar.jsx`.
2. Create `frontend/src/features/users/components/user-access/UserAccessTable.jsx`.
3. Integrate RTK Query paginated hook in `frontend/src/features/users/usersApi.js`.
4. Connect filter states and pagination in `frontend/src/features/users/pages/UsersPage.jsx`.
