# Plan 34-03: User Access Dashboard, Actionable KPI Metrics & Security Analytics UI

**Phase**: 34 — User Access Module Overhaul  
**Status**: Planned  
**Layer**: Frontend UI & Visual Analytics  
**Estimated Complexity**: Moderate  

---

## 1. Goal
Design and construct an actionable KPI metrics dashboard and pure SVG security analytics component adhering to `docs/UI-REFERENCE.md` (Elvara Forest `#061A14`, Emerald `#00C471`, Canvas `#F8FAFC`, Borders `#EAECF0`), displaying real-time counters, user role breakdown, and account status distributions without heavy third-party charting bloat.

---

## 2. Requirements & Scope

1. **Theme Configuration (`userAccessTheme.js`)**:
   - Semantic color system for account status (`active`, `inactive`, `locked`, `suspended`).
   - Semantic color system for access status (`assigned`, `unassigned`).
   - Role badge palettes (Super Admin, HR Manager, Department Manager, Employee).
   - Priority and security badge styling.

2. **6-Card Actionable KPI Deck (`UserAccessDashboard.jsx`)**:
   - Card 1: **Total Users** (Overall registered system user count).
   - Card 2: **Active Accounts** (Users with `isActive: true` and no lockouts).
   - Card 3: **Inactive / Deactivated** (Accounts blocked from logging in).
   - Card 4: **Locked Accounts** (Temporary lockout due to 5+ failed attempts).
   - Card 5: **Unassigned Roles** (Users without any assigned role, requiring access setup).
   - Card 6: **2FA Enforced** (Security posture metric showing two-factor adoption).
   - Interactive click handlers allowing quick filtering of the table by clicking a KPI card.

3. **Pure SVG Security Analytics**:
   - **Users by Assigned Role Bar Chart**: SVG horizontal distribution showing user count across Super Admin, HR Manager, Department Manager, Employee, and Custom roles.
   - **Account Security & Health Status Donut/Meter**: Pure SVG visual representation of Active vs Inactive vs Locked accounts.
   - Fully accessible SVG code with responsive viewBox, semantic text tags, dark/light theme awareness, and zero external charting dependencies.

4. **RTK Query Hook Integration**:
   - Connect to `useGetUserStatsQuery` with automated polling or tag-based invalidation (`UserStats`).
   - Skeleton loading states and clean error boundaries.
