# Plan 21-02: Administrative Policy Console, Analytics Dashboard & Category Management

## 1. Goal
Build the administrative command center for the **Company Policies Module** in the frontend. This includes creating the RTK Query API slice (`policyApi.js`), designing the executive dashboard with real-time KPI metrics, implementing dynamic category-based filtering and management modals, and crafting responsive policy card and tabular list views conforming to the Forest & Emerald Enterprise theme.

## 3. Detailed Tasks

### Task 1: RTK Query Slice (`policyApi.js`)
- Define endpoints:
  - `getPolicies`: Query with `search`, `category`, `status`, `scope`, `page`, `limit`.
  - `getPolicyStats`: Query dashboard KPIs.
  - `getCategories`: Query all policy categories.
  - `createCategory`: Mutation for creating categories.
  - `updateCategory`: Mutation for updating categories.
  - `deleteCategory`: Mutation for soft-deleting categories.
  - `getPolicyById`: Query single policy details with active version.
  - `createPolicy`: Mutation for authoring a draft policy.
  - `updatePolicy`: Mutation for modifying an existing draft.
  - `deletePolicy`: Mutation for archiving/deleting a policy.
  - `submitPolicyForApproval`: Mutation to advance status to `Pending Approval`.
  - `approvePolicy`: Mutation to approve a policy draft.
  - `rejectPolicy`: Mutation to reject a policy draft with feedback.
  - `publishPolicy`: Mutation to transition status to `Published`.
  - `acknowledgePolicy`: Mutation to record employee sign-off.
  - `getPolicyAcknowledgements`: Query compliance roster.
  - `getPolicyVersions`: Query revision ledger.
- Provide tag invalidation (`['Policy', 'PolicyStats', 'PolicyCategory', 'PolicyVersion']`).

### Task 2: Executive Policy Dashboard (`PoliciesDashboardPage.jsx`)
- **Page Header**:
  - Title: "Company Policies & Regulatory Compliance".
  - Subtitle: "Corporate handbooks, standard operating procedures, regulatory guidelines, and workforce acknowledgement tracking."
  - Action buttons: "Manage Categories" (`policy.manage`), "Create Policy" (`policy.create`), and "Refresh" button.
- **KPI Summary Cards Grid (7 Cards, `h-32`)**:
  1. **Total Policies** (`FileText` icon, total count, neutral badge).
  2. **Published Policies** (`CheckCircle2` icon, active corporate guidelines, emerald badge).
  3. **Draft Proposals** (`Clock` icon, policies in draft authoring, blue badge).
  4. **Pending Approval** (`AlertTriangle` icon, awaiting administrative sign-off, amber badge).
  5. **Archived / Inactive** (`Archive` icon, superseded or expired policies, slate badge).
  6. **Mandatory Sign-off** (`ShieldAlert` icon, policies requiring employee acknowledgement, violet badge).
  7. **Overall Compliance Rate** (`TrendingUp` icon, percentage gauge across required staff, emerald font).
- **Filter Toolbar**:
  - Search bar: `Search by policy title, code, or description...` (`h-9`).
  - Dynamic Category segmented pills: `All`, `General`, `IT Security`, `Conduct`, `Leaves & Attendance`, etc.
  - Status dropdown: `All Statuses`, `Published`, `Draft`, `Pending Approval`, `Archived`.
  - View switcher: Toggle between **Card Grid View** and **Tabular Data View**.
  - Reset filters button.

### Task 3: Policy Card & Table Presentation
- **`PolicyCard.jsx`**:
  - Modern card container in Forest & Emerald theme (`bg-[#111D17] border border-[#1A3125] rounded-2xl p-5`).
  - Header: Category badge with custom color, policy code (`POL-IT-001`), version badge (`v1.0`), and action menu.
  - Title and description with truncate handling.
  - Scope pill: "All Staff", "Department Specific", or "Role Specific".
  - Status badge: Color-coded status (`Published` in green, `Draft` in blue, `Pending Approval` in amber, `Rejected` in red).
  - Acknowledgement pill: If required, displays completion progress bar (`75% acknowledged · 30/40 staff`).
  - Footer: Effective date, last updated timestamp, and quick action buttons ("View Policy", "Edit", "Submit").
- **`PolicyTable.jsx`**:
  - Table constraint: `min-w-[1150px]`, `whitespace-nowrap` on headers.
  - Columns: Policy Code & Title, Category, Scope, Version, Status, Effective Date, Acknowledgement Rate, Actions.
  - Row action dropdown: View Details, Edit, Submit for Approval, Publish, View Versions, Delete.

### Task 4: Category Management Modal (`CategoryManagementModal.jsx`)
- Dialog allowing authorized administrators (`policy.manage`) to:
  - View list of existing categories with policy count.
  - Create new category with name, code, description, icon picker, and color theme.
  - Edit or deactivate categories.

### Task 5: Policy Authoring & Revision Modal (`PolicyFormModal.jsx`)
- Multi-step or tabbed structured editor:
  - **General Info**: Title, policy code (auto-suggested based on category), category select, description.
  - **Policy Content**: Clean Markdown/text editor for policy articles, terms, clauses, and responsibilities.
  - **Applicability & Scoping**: Scope selector (`All Employees`, `Department Specific`, `Role Specific`), multi-select for target departments or roles.
  - **Compliance & Schedule**: Effective date picker, review date picker, expiry date, toggle for "Requires Employee Acknowledgement", grace period input (default 7 days).
  - **Attachments**: Optional file attachment (PDF/DOCX) with drag-and-drop file upload.
  - **Actions**: "Save as Draft" or "Submit for Approval".
