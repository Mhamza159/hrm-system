# Plan 13-03: Role Governance Hub & Master Orchestrator Consolidation

## Goal
Implement the role-specific navigation hub (`RoleGovernanceCard.jsx`) and completely consolidate `frontend/src/features/employees/pages/MyProfilePage.jsx` from a 1,782-line duplicate monolith into a clean, maintainable, single orchestrator (<300 lines) adhering strictly to the Forest & Emerald Enterprise theme and PBAC authorization policies.

## Scope & Implementation Details

1. **`frontend/src/features/employees/components/profile/RoleGovernanceCard.jsx` (New Component)**:
   - Dynamic navigation and quick-action hub that renders tailored operational shortcuts based on the active role:
     - **Super Admin (`System Governance & Master Hub`)**:
       - Shortcuts to `/users` (User Access), `/roles` (Roles & Security), `/departments` (Departments), `/designations` (Designations), `/settings` (Global Configuration).
     - **HR Manager (`People Operations Hub`)**:
       - Shortcuts to `/employees` (Employee Directory), `/change-requests` (Profile Requests), `/onboarding` (Onboarding), `/offboarding` (Exit Clearance), `/attendance/shifts` (Work Shifts).
     - **Department Manager (`Department Leadership Hub`)**:
       - Department team oversight summary.
       - Shortcuts to `/delegations` (Approval Delegations), `/leaves` (Team Leave Approvals), `/attendance` (Team Attendance).
     - **Regular Employee (`Self-Service Navigation Hub`)**:
       - Shortcuts to `/org-chart` (Company Hierarchy), `/policies` (Company Policies), `/leaves` (My Leave Requests), `/attendance` (My Clock-in History).

2. **`frontend/src/features/employees/pages/MyProfilePage.jsx` (Consolidation & Refactoring)**:
   - Replace the 4 duplicated ~400-line `if (isRole) return (...)` branches with a single unified, responsive layout.
   - Clean data fetching using `useGetMyProfileQuery()` with skeleton loader state (`ScreenSkeleton`).
   - Unified avatar upload handler with file type validation (`image/jpeg`, `image/png`, `image/webp`) and size checking (<3MB).
   - Unified modal mounting:
     - `ChangeRequestModal`
     - `TwoFactorModal`
     - `ChangePasswordModal`
   - Single layout flow:
     - `PageHeader` with title and role-appropriate primary action button.
     - `ProfileHeader` hero banner.
     - Grid layout containing:
       - Column 1: `PersonalInfoCard`, `EmploymentDetailsCard`, `PayrollBankCard` (when applicable).
       - Column 2: `AccountSecurityCard`, `RoleGovernanceCard`, `SkillsQualificationsCard` (when applicable).
   - Drastic code reduction: From **1,782 lines down to under 300 lines**, strictly following the Ponytail principle (shortest working diff, DRY, zero code duplication).
