# Plan 13-01: Profile Header, Personal Info, Employment Details & Account Security Cards

## Goal
Establish the modular sub-component architecture for the My Profile module under `frontend/src/features/employees/components/profile/` and implement the core reusable cards (`ProfileHeader.jsx`, `PersonalInfoCard.jsx`, `EmploymentDetailsCard.jsx`, `AccountSecurityCard.jsx`) styled with the Forest & Emerald Enterprise theme, eliminating legacy `indigo-*` classes and technical database leaks.

## Scope & Implementation Details

1. **`frontend/src/features/employees/components/profile/ProfileHeader.jsx` (New Component)**:
   - High-impact, responsive Hero banner adhering strictly to Forest & Emerald Enterprise Craft.
   - Surface styling: `#111D17` dark emerald surface with 1px `#1A3125` border, subtle ambient glow, and high-contrast typography.
   - Avatar upload block with hover camera overlay, file validation (JPEG, PNG, WEBP, max 3MB), loading spinner, and role initials fallback.
   - Identity badges: Employee Code (monospaced badge), authoritative Name, Role badge (System Owner / HR Executive / Department Lead / Staff Member), and Status pill.
   - Quick contact strip: Email, Phone, Masked CNIC (`formatCNIC`).
   - Action slot for role-appropriate primary triggers (e.g. Edit Profile, Change Request, Refresh).

2. **`frontend/src/features/employees/components/profile/PersonalInfoCard.jsx` (New Component)**:
   - Structured card presenting personal details:
     - Full Legal Name
     - Primary Email Address
     - Contact Phone Number
     - Masked National Identity (CNIC)
     - Date of Birth & Gender (when available in profile)
     - Residential Address (Street, City, Postal Code, Country)
   - Clean tabular layout with crisp icons (`Mail`, `Phone`, `Shield`, `Calendar`, `MapPin`) and 1px hairline separators.
   - Clear contextual indicator on whether personal fields can be edited directly or require a formal Change Request.

3. **`frontend/src/features/employees/components/profile/EmploymentDetailsCard.jsx` (New Component)**:
   - Displays role-tailored organizational and employment parameters:
     - Job Designation & Grade
     - Department & Code
     - Reporting Manager (with manager name & employee code, or Apex notice for Super Admin)
     - Employment Type (Permanent, Contract, Intern, Probation)
     - Employment Status (Active, Notice, Probation)
     - Joining Date (`formatDate`)
     - Assigned Shift & Timings (Shift name, working hours, grace period) — hidden for Super Admin where not applicable.
   - Role-aware suppression: Omits irrelevant employee operational fields (e.g., probation end dates, shift rosters) for Super Admin.

4. **`frontend/src/features/employees/components/profile/AccountSecurityCard.jsx` (New Component)**:
   - Comprehensive account defense & credentials overview:
     - Account Email
     - Account Password section with "Change Password" button triggering `ChangePasswordModal`.
     - Two-Factor Authentication (2FA) section displaying active state ("Active & Protected" in emerald vs "Disabled" in amber) and button triggering `TwoFactorModal`.
     - Sign-in and session activity section displaying `lastLoginAt` and a link to `/login-history`.
   - Clean, professional enterprise copy (removes all database jargon like "CASL Policy Boundary" and "Encrypted JWT + Salted Bcrypt").
