# Plan 13-02: Skills Taxonomy, Bank Coordinates, Emergency Details & Change Request Flow

## Goal
Implement the interactive self-service cards (`SkillsQualificationsCard.jsx` and `PayrollBankCard.jsx`) and refine `ChangeRequestModal.jsx` to ensure clean PBAC boundaries, secure masking of financial data, and seamless submission of profile change requests.

## Scope & Implementation Details

1. **`frontend/src/features/employees/components/profile/SkillsQualificationsCard.jsx` (New Component)**:
   - Self-service competency tag management:
     - Interactive skill chips with emerald badge styling (`bg-emerald-50 dark:bg-[#162820] text-emerald-700 dark:text-[#00C471] border-emerald-200 dark:border-emerald-900/60`).
     - Inline remove button on each chip (disabled while mutation is loading).
     - Clean input form for adding new skill tags with Enter key or "Add" button.
     - Integration with `useUpdateSkillsMutation`.
     - Toast notifications on addition/removal and duplicate prevention.

2. **`frontend/src/features/employees/components/profile/PayrollBankCard.jsx` (New Component)**:
   - Displays sensitive payroll bank coordinates and emergency contact details:
     - Bank Name, Account Title, Account Number, and IBAN (masked/formatted).
     - Emergency Contact Name, Relationship, and Phone.
   - Guarded Display:
     - Clear security notice explaining that bank and emergency coordinates are protected fields under PBAC policy.
     - "Request Change" button embedded directly on the card to open `ChangeRequestModal`.
     - Suppressed for Super Admin role where direct corporate bank account details are irrelevant.

3. **`frontend/src/features/employees/components/ChangeRequestModal.jsx` (Refinement & Theme Modernization)**:
   - Ensure the modal adheres to Forest & Emerald styling (`#111D17` dark surface, `#1A3125` border, `#00C471` emerald accents).
   - Form field options:
     - Target field selection: `bankDetails`, `address`, `emergencyContact`.
     - Contextual form fields pre-populated with current employee values.
     - Mandatory justification reason field (minimum 3 characters).
   - Clean validation, submit loading state (`Loader2`), and clear error handling.
