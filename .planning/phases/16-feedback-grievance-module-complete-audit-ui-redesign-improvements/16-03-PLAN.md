# Plan 16-03: Grievance Admin Submodule & Management Drawer Audit & Redesign

## 1. Goal
Audit, modernize, and completely redesign the **Grievance Admin** submodule (`GrievanceAdminPage.jsx`) and its core interaction drawers/modals (`CaseDetailsDrawer.jsx`, `StatusChangeModal.jsx`, `EscalateModal.jsx`). Elevate case investigation, triaging, and status lifecycles with Forest & Emerald Enterprise styling, real-time KPI metrics, rich status filtering, monospaced tracking indicators, public/private note sanitation, and PBAC enforcement (strictly barring Department Managers and quarantining harassment complaints).

---

## 2. Target Files & Scope
- `frontend/src/features/feedback/pages/GrievanceAdminPage.jsx`
- `frontend/src/features/feedback/components/CaseDetailsDrawer.jsx`
- `frontend/src/features/feedback/components/StatusChangeModal.jsx`
- `frontend/src/features/feedback/components/EscalateModal.jsx`

---

## 3. Detailed Tasks

### Task 1: Grievance Admin Dashboard & KPI Header (`GrievanceAdminPage.jsx`)
- **Header & Governance Controls**:
  - Title: "Grievance Administration & Case Management".
  - Subtitle: "Confidential case docket, triage, and resolution pipeline for HR and Super Administrators."
  - Strict PBAC Gate: Ensure Department Managers receive an explicit 403 Access Denied view.
- **Executive Metric Cards**:
  - Pull live metrics from `useGetGrievanceStatsQuery`:
    - **Total Grievances**: Grand total cases filed across all departments.
    - **Active Investigations**: Cases with `status: 'Pending'` or `'Under Review'`.
    - **Escalated Cases**: Cases flagged with `isEscalated: true` requiring Super Admin intervention.
    - **Resolved / Closed**: Cases marked `Resolved` or `Dismissed` with resolution timestamps.
    - **Urgent Priority**: Cases flagged with urgent or high severity.
- **Filter & Search Toolbar**:
  - Full-text search by tracking code (`TRK-...`) or subject keywords.
  - Category dropdown filter (Workplace Issue, Formal Grievance, Health & Safety, Open Suggestion, Other).
  - Priority dropdown filter (All, Low, Medium, High, Urgent).
  - Segmented status tabs with badges: `All`, `Active`, `Under Review`, `Escalated`, `Resolved`, `Dismissed`.

### Task 2: Case Docket Management Table (`GrievanceAdminPage.jsx`)
- Redesign the case docket table using Forest & Emerald styling (`#111D17` surface, `#1A3125` border, `#F8FAFC` headers):
  - **Case Identifier**: Monospaced tracking code with copy button (`font-mono font-bold text-xs text-[#00C471]`).
  - **Subject & Description Preview**: Bold subject title with single-line truncated summary.
  - **Category**: Styled badge with category icon.
  - **Complainant**: Shows employee name and department for named submissions; shows "🛡️ Anonymous Submitter" with privacy badge for anonymous submissions.
  - **Priority**: Semantic pills (Urgent crimson, High amber, Medium emerald, Low slate).
  - **Status**: Status indicator pill matching the 4-phase lifecycle.
  - **Submission Date**: Formatted date with relative time tooltip (`formatDate`).
  - **Actions**: "Inspect Case" button triggering the case details drawer.

### Task 3: Comprehensive Case Details Drawer (`CaseDetailsDrawer.jsx`)
- Redesign the slide-over drawer (`#061A14` backdrop, `#111D17` drawer panel, `#1A3125` border):
  - **Drawer Header**:
    - Tracking code, category pill, priority indicator, and status badge.
    - Close button and last updated timestamp.
  - **Case Summary Section**:
    - Subject title, full incident description, target department, submission date, and attachment download links.
    - Complainant verification card (confirming whether anonymous identity protection is active).
  - **Investigation Notes Timeline**:
    - Chronological list of case notes with author role, timestamp, and visibility badge (`🔒 Internal Note` vs `🌐 Public Update`).
    - Inline Note Input Form: Add note with validation and segmented visibility toggle (`Internal Only` vs `Share on Tracking Timeline`).
  - **Action Toolbar**:
    - "Update Case Status" (opens `StatusChangeModal`).
    - "Escalate Case" (opens `EscalateModal`).
    - "Quarantine to Committee" button for formal inquiry elevation.

### Task 4: Redesign Status Change & Escalation Modals
- **Status Change Modal (`StatusChangeModal.jsx`)**:
  - Dropdown to select new status (`Pending`, `Under Review`, `Resolved`, `Dismissed`).
  - Resolution / reason comments textarea (required for Resolved or Dismissed).
  - Checkbox: "Share remarks on public tracking timeline for the employee".
  - Submit button with loading spinner and Sonner toast notification.
- **Escalation Modal (`EscalateModal.jsx`)**:
  - Warning banner explaining Super Admin escalation procedure.
  - Escalation reason textarea (min 10 characters).
  - Confirmation button: "Confirm Escalation to Super Admin".

---

## 4. Verification & Acceptance Criteria
- [ ] Users without `feedback.manage` (e.g. Department Managers) are blocked from accessing Grievance Admin.
- [ ] Harassment category cases are quarantined and not listed in general Grievance Admin.
- [ ] KPI cards correctly display counts from `getGrievanceStats`.
- [ ] Case filtering by search text, category, priority, and status tabs works seamlessly.
- [ ] Drawer displays case notes, allows adding notes with internal/public toggle, and renders attachments safely.
- [ ] Updating status and escalating grievance update backend records and invalidate cached queries.
- [ ] 0 Oxlint errors, 0 warnings, and 0 `prop-types` imports.
