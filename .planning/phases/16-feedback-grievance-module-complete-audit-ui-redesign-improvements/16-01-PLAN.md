# Plan 16-01: Submit Feedback Submodule Audit & UI Redesign

## 1. Goal
Audit, modernize, and completely redesign the **Submit Feedback** submodule (`SubmitFeedbackPage.jsx`). Elevate the feedback submission experience with Forest & Emerald Enterprise styling, structured category cards with active indicators, an anonymous toggle with privacy guarantees, department targeting, secure attachment links, and a modern tracking code generation dialog with copy functionality and direct navigation to case tracking.

---

## 2. Target Files & Scope
- `frontend/src/features/feedback/pages/SubmitFeedbackPage.jsx`

---

## 3. Detailed Tasks

### Task 1: Header & Category Selection Redesign
- Redesign the top header with a distinct shield icon badge, page title, and supportive description explaining the submission channels.
- Redesign the Category Selection Grid:
  - 6 interactive category cards:
    - **Open Suggestion**: Workplace ideas, team culture, productivity.
    - **Formal Grievance**: General disputes, unfair treatment, policy violations.
    - **Workplace Issue**: Interpersonal friction, environment concerns.
    - **Harassment Complaint**: Quarantined channel routed strictly to Inquiry Committee.
    - **Health & Safety**: Physical workplace hazards, ergonomic equipment issues.
    - **Other**: General inquiries and leadership attention.
  - Active card state styled with Forest & Emerald tokens (`border-[#00C471] bg-[#00C471]/10 ring-1 ring-[#00C471]`), clean icon badges, and category descriptions.

### Task 2: Form Inputs & Anonymity Controls
- **Anonymity Switcher**:
  - Segmented pill or card switch for `Anonymous Mode` (Identity protected, no user record stored) vs `Named Submission` (Linked to employee profile for direct follow-up).
  - Clear guarantee banner explaining cryptographic tracking code isolation.
- **Form Fields**:
  - Case Subject / Title input (min 3, max 150 chars).
  - Target Department dropdown (using `departmentsApi`).
  - Priority selector (Low, Medium, High, Urgent) with semantic pill indicators.
  - Comprehensive Description textarea (min 10, max 3000 chars) with live character counter.
  - Optional Secure Attachment URLs input (supporting HTTPS file references).

### Task 3: Redesign Tracking Code Success Dialog
- High-craft modal dialog appearing immediately upon successful submission:
  - Prominent celebration / confirmation icon.
  - Large monospaced tracking code display (`font-mono text-xl font-bold tracking-widest text-[#00C471] bg-[#0A110D] border border-[#1A3125] p-3 rounded-xl`).
  - One-click copy-to-clipboard button with visual feedback (`Copied! ✓`).
  - Critical advisory notice: "Please copy or save this tracking code. It is the only key to track your case progress if submitted anonymously."
  - Action buttons: "Track Case Now" (navigating to `/feedback/track?code=TRK-XXXXXX`) and "Submit Another Feedback".

---

## 4. Verification & Acceptance Criteria
- [ ] Users with `feedback.submit` can submit in all 6 categories.
- [ ] Selecting `Harassment` displays a clear advisory that the complaint is quarantined directly to the Inquiry Committee.
- [ ] Selecting `isAnonymous: true` ensures the backend saves `submittedBy: null`.
- [ ] Tracking code is generated and displayed in the modal with functioning copy button.
- [ ] 0 Oxlint errors, 0 warnings, and 0 `prop-types` imports.
