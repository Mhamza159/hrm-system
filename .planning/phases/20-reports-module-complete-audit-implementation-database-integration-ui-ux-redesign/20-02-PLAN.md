## 3. Detailed Tasks

### Task 1: Enterprise Reports Console Shell Redesign
- In `frontend/src/features/reports/pages/ReportsPage.jsx`:
  - Set root container to `space-y-6 max-w-7xl mx-auto`.
  - Reorganize header with title, subtitle, live refresh button with spinner state, and last updated time.
  - Redesign report type tab selector with `#111D17` surface, `#1A3125` border, active emerald pill (`bg-[#00C471] text-white shadow-sm`), and clean icons for all 6 reports:
    - Attendance (`Clock`)
    - Leaves (`Calendar`)
    - Headcount (`Users`)
    - Payroll (`DollarSign` - HR/Admin only)
    - Turnover (`UserMinus` - HR/Admin only)
    - Department Cost (`PieChart` - HR/Admin only)
  - Ensure tabs hidden dynamically for non-authorized roles based on user permissions.

### Task 2: Comprehensive 8+ Date Presets & Synchronized Pickers
- In `frontend/src/features/reports/components/ReportFilterToolbar.jsx`:
  - Implement full 8+ date presets with instant calculation:
    1. **Today**: Current date for both `from` and `to`.
    2. **Yesterday**: Previous calendar day.
    3. **This Week**: Monday to current date.
    4. **Last Week**: Prior week Monday to Sunday.
    5. **This Month**: 1st of current month to today.
    6. **Last Month**: 1st to last day of previous month.
    7. **This Quarter**: Start of current calendar quarter to today.
    8. **This Year**: January 1st to today.
    9. **Custom Range**: Open date picker inputs.
  - Active preset highlight with emerald pill styling.
  - Standardize start/end date inputs to `h-9 px-3 rounded-xl border border-[#1A3125] bg-white dark:bg-[#061A14] text-xs`.

### Task 3: Dynamic Department Filtering & Filter Reset
- Department Selector:
  - Populate from `useGetDepartmentsQuery` with employee count badges where available.
  - Standardized `h-9 px-3 text-xs rounded-xl border border-[#1A3125] bg-white dark:bg-[#061A14] text-slate-900 dark:text-white`.
  - Automatically locked/hidden or pre-filtered for Department Managers based on user scope.
- Sub-View Segmented Pill (Attendance & Leaves):
  - Toggle between **Daily Log Timeline** and **Employee-Wise Summary**.
  - Standardized `h-9 p-0.5 rounded-xl border border-[#1A3125] bg-slate-100 dark:bg-[#061A14]` with `h-7.5 px-3` buttons.
- Reset Filters Button:
  - Resets dates to current month, clears department, resets page to 1.
  - Shows count of active non-default filters.

### Task 4: Executive KPI Summary Cards Across ALL 6 Reports
- Create uniform `h-32 p-5 rounded-2xl border border-slate-200 dark:border-[#1A3125] bg-white dark:bg-[#111D17] shadow-sm flex flex-col justify-between` cards for every report:
  1. **Attendance**: Attendance Rate (%), Productive Hours, Overtime Hours, Incidents (Late/Absent).
  2. **Leaves**: Total Applications, Approved Leave Days, Paid Leaves Quota Taken, Pending Action.
  3. **Headcount**: Total Active Headcount, New Hires in Period, Exits in Period, On-Leave Today.
  4. **Payroll**: Total Gross Payroll (PKR), Total Net Payable (PKR), FBR Tax Withheld (PKR), Total Deductions (PKR).
  5. **Turnover**: Total Exits Recorded, Voluntary Resignations, Involuntary Terminations, Period Turnover Rate (%).
  6. **Department Cost**: Total Company Workforce Cost, Average Cost Per Employee, Highest Department Cost, Tax Component.
- Tabular figures rendered in bold monospace font (`font-mono font-bold text-2xl`).

### Task 5: Export Action Toolbar
- Polish `ExportButtons.jsx` with standardized `h-9` buttons:
  - Export to Excel (XLSX) with `FileSpreadsheet` icon.
  - Export to PDF with `FileText` icon.
  - Pass all active query parameters (`from`, `to`, `departmentId`, `view`) to the backend export endpoint.
