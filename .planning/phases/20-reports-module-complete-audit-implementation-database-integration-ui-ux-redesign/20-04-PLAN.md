- In `frontend/src/features/reports/components/ReportDataTable.jsx`:
  - Enforce `min-w-[1050px]` on the table element within `<div className="overflow-x-auto">` to prevent columns from being crushed or headers wrapping into awkward multi-line towers.
  - Apply explicit column widths and `whitespace-nowrap` on badges and numeric cells.
  - Avatar and employee identity: 32px circular badge, non-wrapping name, and muted code badge.
  - Codified status badges conforming to DESIGN.md (`Present`, `Late`, `Half-Day`, `Absent`, `Approved`, `Pending`, `Rejected`, `Paid`).

    - Standardized `h-8 w-8` navigation buttons.
    - Page indicator in monospace font (`Page X of Y`).
    - Accurate record counter (`Showing X to Y of Z total entries`).
