# Plan 20-03: Interactive Visual Analytics Suite & Charts for All 6 Reports

## 1. Goal
Design, implement, and integrate an interactive, responsive native SVG analytics chart suite across all six report sections. Provide visual distributions, stacked comparisons, and trajectory trends with elevated dark glassmorphic hover tooltips, click-to-filter drilldowns, and strict Forest & Emerald Enterprise styling without heavy external charting libraries.

## 3. Detailed Tasks

### Task 1: Attendance Analytics Chart (`AttendanceStatusChart.jsx`)
- Render a paired analytics panel:
  - Left: Native SVG Status Distribution Donut (`Present`, `Late`, `Half-Day`, `Absent`) with central attendance rate gauge.
  - Right: Daily Attendance Trajectory Stacked Bar Chart across the selected period.
- Dark glassmorphic tooltip with date, present count, late arrivals, and absent counts.
- Responsive scaling (`viewBox 0 0 ...`) with non-clipping labels.

### Task 2: Leaves Utilization Chart (`LeaveDistributionChart.jsx`)
- Render a paired analytics panel:
  - Left: Leave Type Distribution Donut (Casual, Annual, Sick, Unpaid LWP, etc.) with total approved days in center.
  - Right: Approval Status Funnel & Breakdown (Approved vs Pending vs Rejected).
- Interactive legend with percentage tags and color-coded status chips.

### Task 3: Headcount & Demographics Chart (`HeadcountAnalyticsChart.jsx`)
- Render a paired analytics panel:
  - Left: Department-wise Headcount Stacked Bar Chart comparing active staff per department.
  - Right: Employment Type Breakdown Donut (Permanent, Probation, Contract, Intern).
- Hover tooltips showing exact headcount and percentage of total workforce.

### Task 4: Payroll Expenditure Chart (`PayrollTrendChart.jsx`)
- Render a paired analytics panel:
  - Left: Monthly Payroll Trend Bar Chart comparing Gross Salary, Statutory Tax, and Net Pay across payroll runs.
  - Right: Component Breakdown Gauge (Basic, Allowances, Deductions).
- Tabular PKR figures formatted cleanly (e.g. `PKR 4.2M`).

### Task 5: Turnover & Attrition Chart (`TurnoverAnalysisChart.jsx`)
- Render a paired analytics panel:
  - Left: Separation Reason & Type Donut Chart (Voluntary Resignation vs Involuntary Termination).
  - Right: Monthly Turnover Rate & Separation Trend Line/Bar Chart.
- Central turnover rate percentage gauge (`e.g. 2.4%`).

### Task 6: Department Cost Comparison Chart (`DepartmentCostComparisonChart.jsx`)
- Render a full-width department cost comparison stacked bar chart:
  - Bars represent each department's total payroll cost with Gross Pay, Tax Component, and Net Payout segments.
  - Cost per employee marker/badge above each bar.
  - Dark glassmorphic tooltip with department staff count, total cost PKR, and average per-head cost.

---

## 4. Verification & Acceptance Criteria
- [ ] Every one of the 6 reports features dedicated, responsive native SVG analytics charts.
- [ ] Tooltips render with smooth glassmorphism, high contrast text, and accurate backend figures.
- [ ] No chart elements clip, overflow, or distort on desktop, tablet, or mobile viewports.
- [ ] Zero heavy charting dependencies added (adheres strictly to Ponytail stdlib / native SVG principles).
- [ ] 0 Oxlint errors, 0 warnings, and 0 `prop-types` imports.
