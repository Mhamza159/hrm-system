# Plan 20-01: Backend Analytics Engine & Aggregation Overhaul

## 1. Goal
Audit and completely overhaul the backend reporting aggregations in `backend/src/modules/reports/reports.service.js` and `reports.validation.js`. Provide complete KPI summaries, visual analytics chart datasets, and period-aware calculations for all 6 report types (`attendance`, `leave`, `headcount`, `payroll`, `turnover`, `department-cost`). Add deep inspection query support for individual employees and departments, and enforce strict PBAC/RBAC data scoping.

---

## 2. Target Files & Scope
- `backend/src/modules/reports/reports.validation.js`
- `backend/src/modules/reports/reports.routes.js`
- `backend/src/modules/reports/reports.controller.js`
- `backend/src/modules/reports/reports.service.js`
- `tests/reports.test.js` or backend test verification

---

## 3. Detailed Tasks

### Task 1: Validation Schema & Query Parameter Extensions
- In `backend/src/modules/reports/reports.validation.js`:
  - Support `type` enum: `attendance`, `leave`, `headcount`, `payroll`, `turnover`, `department-cost`.
  - Add optional `employeeInspectionId` (ObjectId) and `departmentInspectionId` (ObjectId) query params for drilldown inspection sheets.
  - Support date filtering parameters `from` and `to` across all 6 report types with format validation (`YYYY-MM-DD`).
  - Support sub-view toggling: `daily` vs `employee` for attendance and leaves.

### Task 2: Attendance & Leaves Aggregation Enhancements
- In `backend/src/modules/reports/reports.service.js`:
  - **Attendance**:
    - Compute comprehensive `summary`: `totalRecords`, `totalWorkHours`, `totalOvertimeHours`, `totalLates`, `totalAbsents`, `totalHalfDays`, `attendanceRate`.
    - Generate `chartData`:
      - `statusDistribution`: Counts and percentages of `present`, `late`, `half_day`, `absent`.
      - `dailyTrend`: Daily attendance counts across the selected date range.
    - Provide complete punch event timelines (checkIn, checkOut, workHours, overtimeHours, lateMinutes).
  - **Leaves**:
    - Compute comprehensive `summary`: `totalApplications`, `totalLeaveDays`, `paidLeaveDays`, `unpaidLeaveDays`, `pendingApplications`, `approvedApplications`, `rejectedApplications`.
    - Generate `chartData`:
      - `typeBreakdown`: Distribution across leave types (Casual, Annual, Sick, Unpaid, etc.).
      - `statusDistribution`: Approved, Pending, Rejected, Cancelled.

### Task 3: Headcount Period-Aware Calculations & Demographics
- Distinguish current active workforce from historical period events:
  - `totalHeadcount`: Active employees (`isDeleted: false, status: 'Active'`).
  - `newHires`: Employees with `joiningDate` falling between `from` and `to`.
  - `periodExits`: Employees with `status: Resigned | Terminated` whose exit occurred between `from` and `to`.
  - `onLeave`: Employees currently on approved leave.
- Generate `chartData`:
  - `departmentBreakdown`: Headcount and percentage per department.
  - `employmentTypeBreakdown`: Permanent, Contract, Probation, Intern.

### Task 4: Payroll & Turnover Formula Accuracy
- **Payroll**:
  - Filter across all payroll runs whose month or cycle start date matches `from` and `to`.
  - Compute `summary`: `totalGrossPkr`, `totalNetPkr`, `totalTaxPkr`, `totalDeductionsPkr`, `totalRuns`, `totalEmployees`.
  - Generate `chartData`:
    - `monthlyTrend`: Gross pay, net pay, and tax withheld per payroll cycle.
    - `departmentExpenditure`: Aggregate payroll cost grouped by department.
- **Turnover**:
  - Implement accurate period turnover rate formula:
    $$\text{Turnover Rate} = \left(\frac{\text{Period Separations}}{\text{Average Headcount}}\right) \times 100$$
  - Compute `summary`: `totalExits`, `voluntaryResignations`, `involuntaryTerminations`, `turnoverRate`, `averageTenureMonths`.
  - Generate `chartData`:
    - `exitTypeDistribution`: Voluntary vs Involuntary exits.
    - `monthlyExitTrend`: Exits recorded per month across the date range.

### Task 5: Department Cost Date-Range & Drilldown Aggregation
- Update `generateDepartmentCostReport` to accept `from` and `to` date ranges and aggregate payslips across matching payroll cycles.
- Compute `summary`: `totalCostPkr`, `avgCostPerEmployeePkr`, `topDepartmentName`, `topDepartmentCostPkr`, `totalTaxComponentPkr`.
- Generate `chartData`:
  - `departmentCostComparison`: Stacked breakdown of gross pay, tax, and net payout per department.

### Task 6: Deep Inspection Queries for Dossier Sheets
- Add helper `getReportInspectionDetails({ type, employeeId, departmentId, from, to, userScope })`:
  - Attendance Inspection: All punches, punctuality score, overtime breakdown for an individual employee.
  - Leave Inspection: Leave balance ledger, application timeline, approval comments for an employee.
  - Payroll Inspection: Detailed itemized payslip breakdown (earnings, allowances, deductions, tax, net pay).
  - Department Cost Inspection: Department staff roster with individual cost attribution.
- Wire into `reports.controller.js` and enforce horizontal scoping (Department Managers restricted to own team).

## 4. Verification & Acceptance Criteria
- [ ] All 6 report types return real database aggregations with complete `summary` and `chartData` payloads.
- [ ] Turnover rate is computed accurately using the verified separation/headcount formula.
- [ ] Headcount distinguishes active staff from new hires and period exits.
- [ ] Department cost aggregates payslips across the selected date range.
- [ ] Financial reports (`payroll`, `turnover`, `department-cost`) return HTTP 403 Forbidden for Department Managers and regular Employees.
