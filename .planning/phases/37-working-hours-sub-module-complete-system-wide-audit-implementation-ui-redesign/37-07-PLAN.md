## Detailed Implementation Steps

1. **Author `backend/tests/working-hours-integration.test.js`**:
   - Test 1: Saturday and Sunday default to OFF in new/clean state.
   - Test 2: Super Admin toggles Saturday ON -> `workingDays` updates to 6 days; Setting cache invalidates immediately.
   - Test 3: Saturday attendance: unpunched Saturday in active schedule is marked as work day (absent/present), not `weekly_off`.
   - Test 4: Sunday toggled ON -> 7-day work week recognized; both weekend days allow regular punches.
   - Test 5: Weekday toggled OFF (e.g. Friday off in 4-day week) -> unpunched Friday is marked `weekly_off`, never `absent`.
   - Test 6: Deductible leave calculation respects dynamic working days:
     - 5-day week (Sat/Sun off): Fri-Mon leave = 2 days.
     - 6-day week (Sat ON): Fri-Mon leave = 3 days.
     - 4-day week (Fri off): Thu-Mon leave = 2 days.
   - Test 7: Standard shift start time (09:00), end time (18:00), and break duration (60m) yield exact 8 hours net working duration.
   - Test 8: Break duration correctly deducted in `calculateWorkMetrics`.
   - Test 9: Half-day threshold in `statusEngine.service.js` consumes `officeHours.halfDayMinutes` when shift has no override.
   - Test 10: Shift-specific `workDays` override company defaults for assigned employees.
   - Test 11: Unassigned employees fall back cleanly to company `officeHours` and `workingDays`.
   - Test 12: Weekly off days never create unexcused absence salary deductions in `payrollProcessor`.
   - Test 13: Finalized/paid historical payroll records remain untouched by setting updates.
   - Test 14: Setting cache invalidation: `SettingService.getSetting('workingDays')` returns updated data immediately after mutation without restarting process.
   - Test 15: RBAC/PBAC: `PATCH /api/v1/settings/workingDays` allows `Super Admin` and `HR Manager` (HTTP 200).
   - Test 16: RBAC/PBAC: `Department Manager` and `Employee` receive HTTP 403 Forbidden.
   - Test 17: Public policies endpoint `/api/v1/settings/public-branding` sanitizes and exposes `workingDays` and `officeHours`.
