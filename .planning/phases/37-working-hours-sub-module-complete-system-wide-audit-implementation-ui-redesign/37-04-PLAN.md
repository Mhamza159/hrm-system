# Plan 37-04: Shift Management & Half-Day Calculation Engine Harmonization

## Objective
Establish a unified source of truth between Shift Management (`shift.model.js`, `shift.service.js`) and Working Hours settings. Ensure employee assigned shifts take precedence, inherit company defaults when unset, normalize day casing across all layers, and harmonize half-day / break duration calculations in `statusEngine.service.js`.

---

## Technical Context
- **Files Touched**:
  - `backend/src/models/shift.model.js`
  - `backend/src/modules/attendance/shift.service.js` (or `backend/src/modules/shifts/shift.service.js`)
  - `backend/src/modules/attendance/services/statusEngine.service.js`
  - `frontend/src/features/attendance/pages/ShiftManagementPage.jsx`
- **Dependencies**: `SettingService`, `workdayHelper.js`.

---

## Detailed Implementation Steps

1. **Shift Model & Service Normalization**:
   - In `shift.model.js`:
     - Ensure `workDays` array stores normalized lowercase day names (`['monday', 'tuesday', ...]`) with a pre-save hook that converts any TitleCase input to lowercase.
     - Add virtual / getter for legacy display if needed.
   - In shift creation service:
     - When a shift is created without explicit `workDays`, populate with current `SettingService.getSetting('workingDays')`.

2. **Status Engine Harmonization (`statusEngine.service.js`)**:
   - In `evaluateAttendanceStatus`:
     - Resolve `halfDayThresholdMinutes = shift?.halfDayMinutes ?? officeHours?.halfDayMinutes ?? 240`.
     - Evaluate `half_day` status strictly against this configured threshold.
   - In `calculateWorkMetrics`:
     - Resolve `shiftBreak = shift?.breakMinutes ?? officeHours?.breakMinutes ?? 60`.
     - Calculate net scheduled minutes and overtime based on effective break duration.

3. **Refactor `ShiftManagementPage.jsx`**:
   - Standardize day toggles to lowercase keys while displaying friendly labels ("Mon", "Tue", etc.).
   - Display company default off-days when configuring a shift.

---

## Verification Criteria
- [ ] Shift creation respects company `workingDays` default.
- [ ] `evaluateAttendanceStatus` and `calculateWorkMetrics` dynamically consume `officeHours.halfDayMinutes` and `officeHours.breakMinutes`.
- [ ] Shift-specific working schedules override company defaults for assigned employees without mutating company-wide settings.
