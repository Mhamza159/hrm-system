# Plan 37-05: Leave Management Module Integration — Dynamic Working Day Deductions & Apply Modal Sync

## Objective
Connect Leave Management directly to the Working Hours configuration so that leave deductible days calculations, quota reservations, and the employee leave application modal accurately reflect active working days and weekly offs without hardcoded weekend logic.

---

## Technical Context
- **Files Touched**:
  - `backend/src/modules/leaves/leaveCalculator.js`
  - `backend/src/modules/leaves/leave.service.js`
  - `frontend/src/features/leaves/components/ApplyLeaveModal.jsx`
  - `frontend/src/features/leaves/pages/TeamLeaveCalendarPage.jsx`
- **Dependencies**: `SettingService`, `workdayHelper.js`, `Holiday` model.

---

## Detailed Implementation Steps

1. **Refactor `leaveCalculator.js`**:
   - Update `calculateDeductibleDays(startDateInput, endDateInput, halfDay = 'none', employeeId = null)`:
     - Fetch employee's assigned shift if `employeeId` is provided.
     - Resolve `effectiveWorkDays = getEffectiveWorkDays(shift, companyWorkingDays)` via `workdayHelper.js`.
     - In the daily iteration loop:
       - Check `isCompanyWorkingDay = effectiveWorkDays.includes(dayOfWeek)`.
       - Check `isPublicHoliday = holidayDateMap.has(dateKey)`.
       - `isWorkingDay = isCompanyWorkingDay && !isPublicHoliday`.
     - Deductible days calculation:
       - If Saturday or Sunday is configured as a working day, leaves spanning Saturday/Sunday deduct quota.
       - If any weekday is configured as off (e.g. Friday), it is NOT deducted (unless corporate sandwich rule applies).
   - In `leave.service.js`: Pass `employeeId` to `calculateDeductibleDays(start, end, halfDay, employeeId)`.

2. **Refactor `ApplyLeaveModal.jsx`**:
   - Eliminate hardcoded `if (day !== 0 && day !== 6) count++`.
   - Read `workingDays` from `useGetPublicPoliciesQuery`.
   - Estimate deductible days dynamically:
     ```javascript
     const activeDaysSet = new Set((publicPolicies?.workingDays || ['monday', 'tuesday', 'wednesday', 'thursday', 'friday']).map(d => d.toLowerCase()));
     const dayName = cur.toLocaleDateString('en-US', { weekday: 'long' }).toLowerCase();
     if (activeDaysSet.has(dayName)) count++;
     ```
   - Quota warnings and medical proof triggers recalculate in real time based on dynamic working days.

3. **Refactor `TeamLeaveCalendarPage.jsx`**:
   - Highlight weekly off columns dynamically based on `workingDays` setting rather than static Saturday/Sunday.

---

## Verification Criteria
- [ ] Friday-to-Monday leave with Sat/Sun off deducts exactly 2 days.
- [ ] Friday-to-Monday leave with Saturday ON deducts 3 days.
- [ ] 4-day work week (Friday OFF): Monday-to-Friday leave deducts 4 days.
- [ ] `ApplyLeaveModal.jsx` estimated days match backend `calculateDeductibleDays` exactly.
