# Plan 37-01: Backend Schema Enhancement, Zod Validators, Break Duration, Canonical Working Days Normalizer & SettingService Cache Bus

## Objective
Enhance the backend `officeHours` and `workingDays` settings schemas in `backend/src/modules/settings/` to support break duration (`breakMinutes`), full-day attendance threshold (`fullDayMinutes`), canonical timezone (`timeZone`), and create a single shared `workdayHelper.js` utility in `backend/src/utils/workdayHelper.js` to normalize day calculations, resolve shift precedence, and guarantee case-insensitive comparisons across all modules.

---

## Technical Context
- **Files Touched**:
  - `backend/src/modules/settings/setting.validation.js`
  - `backend/src/modules/settings/setting.service.js`
  - `backend/src/utils/workdayHelper.js` (New canonical utility)
- **Dependencies**: Zod, Setting Model, In-memory cache bus (`SettingService.settingsCache`), AuditLogService.

---

## Detailed Implementation Steps

1. **Enhance `setting.validation.js`**:
   - Update `officeHoursSchema`:
     ```javascript
     export const officeHoursSchema = z.object({
       startTime: z.string().regex(timeRegex, "Start time must be in HH:mm format (e.g. 09:00)"),
       endTime: z.string().regex(timeRegex, "End time must be in HH:mm format (e.g. 18:00)"),
       breakMinutes: z.number().int().min(0).max(240).default(60),
       halfDayMinutes: z.number().int().min(60).max(480).default(240),
       fullDayMinutes: z.number().int().min(180).max(720).default(480),
       flexibleShiftAllowed: z.boolean().default(false),
       timeZone: z.string().default('Asia/Karachi')
     });
     ```
   - Ensure `workingDaysSchema` accepts any combination of `monday`..`sunday` with a minimum of 1 day and maximum of 7 days.

2. **Create Central `backend/src/utils/workdayHelper.js`**:
   - `DAY_NAMES`: `['sunday', 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday']`.
   - `normalizeDayName(day)`: Lowercase trim helper that converts `'Monday'` or `'monday'` or day index `0..6` to canonical lowercase `'monday'`.
   - `getEffectiveWorkDays(shift, companyWorkingDays)`:
     - If `shift?.workDays` has length > 0, return normalized lowercase array of shift work days.
     - Else, return normalized lowercase array of `companyWorkingDays` (or default `['monday', 'tuesday', 'wednesday', 'thursday', 'friday']`).
   - `isWeeklyOff(date, shift, companyWorkingDays)`:
     - Extracts day of week in target timezone (default `Asia/Karachi`).
     - Returns `true` if that day is NOT in the effective work days.
   - `calculateWorkingDaysInMonth(year, month, effectiveWorkDays, holidayDatesSet = new Set())`:
     - Computes exact total working days in a calendar month excluding configured weekly offs and gazetted holidays.
   - `getNetWorkHours(startTime, endTime, breakMinutes = 60)`:
     - Computes gross span, break, and net working minutes.

3. **Update `setting.service.js`**:
   - Update `DEFAULT_SETTINGS.officeHours` to include `breakMinutes: 60`, `fullDayMinutes: 480`, `timeZone: 'Asia/Karachi'`.
   - Expose `officeHours` and `workingDays` in `getPublicPolicies()` so client apps and public readers know the operating schedule.
   - Ensure cache invalidation (`this.cache.delete('workingDays')`, `this.cache.delete('officeHours')`) and audit logging on update.
