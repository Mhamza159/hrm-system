# Plan 37-02: Working Hours & Office Hours Form Complete Enterprise UI/UX Redesign

## Objective
Completely overhaul `frontend/src/features/settings/components/WorkingHoursForm.jsx` into a high-density, polished enterprise schedule control center strictly complying with `docs/UI-reference.md` (Elvara Forest `#061A14`, Emerald `#00C471`). Highlight Saturday and Sunday as default weekly offs, provide intuitive 7-day toggles, incorporate break duration inputs, live net working hours counters, half-day threshold indicators, and robust form validation.

- **Files Touched**:
  - `frontend/src/features/settings/components/WorkingHoursForm.jsx`
  - `frontend/src/features/settings/pages/SettingsPage.jsx`

---

## Detailed Implementation Steps

1. **Interactive Weekly Schedule Studio Card**:
   - 7-day interactive grid (Monday to Sunday).
   - Distinct badges for **Saturday & Sunday** marked as "Default Off" when unselected.
   - Dynamic status pill for each day:
     - Active (Working): Emerald styling (`bg-[#00C471]`, white text, `CheckCircle2` icon, "WORKING DAY").
     - Inactive (Weekly Off): Slate/Rose muted styling (`bg-slate-100 dark:bg-white/5`, "OFF DAY").
   - Summary stat pill: "X Working Days · Y Weekly Offs".
   - Guard against disabling all days (enforce minimum 1 working day).

2. **Standard Shift & Time Coordinates Card**:
   - Start Time (`startTime`) input with clean custom time styling.
   - End Time (`endTime`) input.
   - Break Duration (`breakMinutes`) with preset quick-pills (30m, 45m, 60m, 90m) and custom number input.
   - **Real-Time Duration Compute Deck**:
     - Gross Shift Hours (e.g. 9h 00m)
     - Break Duration (e.g. 1h 00m)
     - **Net Productive Work Hours** (e.g. 8h 00m) highlighted in bold Emerald.
     - Overnight Shift Banner if `endTime < startTime`.

3. **Half-Day & Attendance Thresholds Card**:
   - Half-day threshold in minutes/hours (`halfDayMinutes`, default 240m / 4h).
   - Full-day minimum threshold (`fullDayMinutes`, default 480m / 8h).
   - Flexible shift allowed switch with clear helper explanation.
   - Canonical Timezone display locked to `Asia/Karachi (PKT UTC+5)`.

4. **Action Bar & States**:
   - Save Changes button with loading spinner.
   - Reset button to restore currently loaded database values.
   - Unsaved changes indicator badge.
   - Fully responsive for mobile, tablet, and desktop viewports.
   - Seamless dark mode support using `#111D17` container backgrounds.
