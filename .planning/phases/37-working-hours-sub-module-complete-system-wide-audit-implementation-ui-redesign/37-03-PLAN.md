# Plan 37-03: Attendance Module System-Wide Integration — Dynamic Working Days, Monthly Attendance Sheet & Rest-Day Punch Logic

## Objective
Harmonize the Attendance Module with the central Working Hours configuration so that changes to working days (e.g. enabling Saturday, enabling Sunday, or disabling Friday) dynamically propagate across attendance calculations, monthly sheets, and attendance calendars without hardcoded weekend assumptions or incorrect absent marks.

---

## Technical Context
- **Files Touched**:
  - `backend/src/modules/attendance/attendance.service.js`
  - `frontend/src/features/attendance/pages/MyAttendancePage.jsx`
  - `frontend/src/features/attendance/pages/TeamAttendancePage.jsx`
- **Dependencies**: `SettingService`, `workdayHelper.js`, `Attendance` model.

---

## Detailed Implementation Steps

1. **Refactor `attendance.service.js`**:
   - In `getShiftAndPolicies(employeeId)`:
     - Replace direct `Setting.find()` with cached `SettingService.getSetting('workingDays')` and `SettingService.getSetting('officeHours')`.
     - Standard shift fallback: use `officeHours.startTime` (default 09:00) and `officeHours.endTime` (default 18:00) instead of hardcoded 11:00 AM / 05:00 PM.
   - In `getMonthlyAttendanceSheet`:
     - Eliminate hardcoded `['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday']`.
     - Resolve employee workdays using `getEffectiveWorkDays(emp.shiftId, companyWorkingDays)` via `workdayHelper.js`.
     - Compute `isWeeklyOff = isWeeklyOff(dayDate, emp.shiftId, companyWorkingDays)`.
     - Unpunched past days on a weekly off MUST be marked strictly as `status: 'weekly_off'`, never `'absent'`.
   - In `checkIn` / `checkOut`:
     - If an employee clocks in on a configured weekly off, mark punch as `present` with flag `'rest_day_work'` rather than mutating the day into a normal scheduled work day.

2. **Refactor `MyAttendancePage.jsx`**:
   - Eliminate hardcoded `isWeekend = dayName === 'Sat' || dayName === 'Sun'` and `dayObj.getDay() === 0 || dayObj.getDay() === 6`.
   - Read `workingDays` from `useGetPublicPoliciesQuery` or user shift info.
   - Use dynamic evaluation: `const isOff = isWeeklyOff(d, effectiveWorkingDays)`.
   - If Saturday or Sunday is enabled in Settings, the calendar re-renders them as standard working days. If a weekday (e.g. Friday) is toggled off, it renders as a "Weekly Off" pill.

3. **Refactor `TeamAttendancePage.jsx`**:
   - Ensure the monthly team matrix derives `emp.offLabel` dynamically from the employee's effective working days.

---

## Verification Criteria
- [ ] Attendance sheet marks unpunched weekly off days as `weekly_off`, never `absent`.
- [ ] When Saturday is set to working day, unpunched Saturday is marked `absent` (if in past) and punches are allowed.
- [ ] When Friday is set to weekly off, unpunched Friday is marked `weekly_off`.
- [ ] `MyAttendancePage.jsx` and `TeamAttendancePage.jsx` calendars dynamically update off-day columns.
