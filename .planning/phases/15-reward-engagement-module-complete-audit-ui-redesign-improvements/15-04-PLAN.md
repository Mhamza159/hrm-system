## 3. Detailed Tasks

### Task 1: Overview KPIs, Status Tabs & Filters in `SurveysPage.jsx`
- Add 4 header metric summary cards:
  - **Active Surveys**: Open surveys accepting responses.
  - **Total Responses**: Cumulative company-wide responses collected.
  - **Average Participation**: Average employee turnout percentage.
  - **Closed / Archived**: Completed historical surveys.
- Segmented status tabs:
  - `All Surveys`, `Active Polls`, `Closed / Historical`, `My Pending Surveys`.
- Survey Cards Grid:
  - Display title, survey type pill (`pulse`, `poll`, `quarterly`, `culture`), target audience badge (`Company-wide` or department name), deadline countdown, question count, and anonymous shield icon (`🔒 100% Anonymous`).
  - Action buttons based on user role and state:
    - If user has NOT responded and survey is active: "Take Survey" CTA (emerald button).
    - If user has responded: "Response Submitted" badge with checkmark.
    - If user has `rewards.manage`: "View Analytics & Results" button.

### Task 2: Distraction-Free Survey Participation Modal (`SurveyFillModal.jsx`)
- Redesign `SurveyFillModal.jsx` with an executive questionnaire interface:
  - Prominent Privacy Guarantee Notice: "🔒 Your responses are cryptographically anonymized. No manager or administrator can trace your answers back to your account."
  - Step indicator / Progress bar showing completion percentage (`Question 2 of 5`).
  - Question renderers:
    - `rating_5`: 5-star interactive rating or 1–5 numerical scale with labels (Poor $\rightarrow$ Exceptional).
    - `multiple_choice` / `poll`: Radio list or check pills with smooth hover and selected states.
    - `text`: Clean textarea for qualitative feedback with character counter.
  - Required validation check before submission.
  - Submit confirmation and celebration screen upon completion.

### Task 3: Survey Builder Wizard (`SurveyBuilderModal.jsx`)
- Redesign `SurveyBuilderModal.jsx` (Guarded by `hasPermission('rewards.manage')`):
  - Step 1: General Info (Title, description, survey type, anonymous toggle, audience selection company vs specific department, expiration date).
  - Step 2: Question Composer:
    - Add question button with question type selector (`5-Point Rating`, `Multiple Choice Poll`, `Open Text Feedback`).
    - Option manager for multiple choice questions (add, remove, reorder options).
    - "Required" checkbox per question.
  - Step 3: Review & Publish:
    - Live preview of questions as employees will see them.
    - Single-click publish with immediate socket broadcast.

### Task 4: Survey Analytics & Sentiment Breakdown (`RatingBreakdownChart.jsx`)
- Redesign Analytics Modal / Drawer:
  - Participation summary: Total eligible employees, total responses, and response rate progress bar.
  - Per-question distribution breakdown:
    - For ratings: Average score, distribution bar breakdown (1 to 5 stars) with counts and percentages.
    - For polls: Horizontal percentage bars for each answer option.
    - For text: Scrollable list of anonymous feedback comments (strictly anonymized, displaying "Anonymous Employee").
  - Export summary or print report option.

### Task 5: Module Verification Gate
- Run Playwright E2E test suite: `tests/e2e/m20-rewards.spec.js`.
- Audit all changed files with Oxlint: 0 errors, 0 warnings.

- Run production Vite build: `npm run build` in `frontend` directory.
