# Plan 15-01: Award & Honors Submodule Audit, UI Redesign & PBAC Enforcement

## 1. Goal
Audit, modernize, and completely redesign the **Award & Honors** submodule (`AwardsPage.jsx` and related modals/cards). Enforce dynamic PBAC permissions (`rewards.manage`, `rewards.nominate`, `rewards.vote`), replace ad-hoc styling with the **Forest & Emerald Enterprise** design language, introduce KPI summary cards, segmented status tabs, advanced filtering, and craft a cohesive honors showcase.

---

## 2. Target Files & Scope
- `frontend/src/features/rewards/pages/AwardsPage.jsx`
- `frontend/src/features/rewards/components/CreateAwardModal.jsx`
- `frontend/src/features/rewards/components/NominateModal.jsx`
- `frontend/src/features/rewards/components/AnnounceWinnerModal.jsx`
- `frontend/src/features/rewards/components/VotingCard.jsx`

---

## 3. Detailed Tasks

### Task 1: Overview KPIs, Segmented Tabs & Filter Bar in `AwardsPage.jsx`
- Add 4 high-density metric summary cards at the top:
  - **Total Award Cycles**: Count of all active & archived cycles.
  - **Open Nominations**: Count of cycles currently in `nomination` status.
  - **Active Voting Ballots**: Count of cycles in `voting` status.
  - **Honored Winners**: Total historical winners announced.
- Implement segmented status tabs with active emerald pill styling:
  - `All Cycles`, `Accepting Nominations`, `Voting Open`, `Announced Winners`.
- Build a unified filter bar:
  - Text search by cycle title or winner name.
  - Month selector (`YYYY-MM`).
  - Clear filters button.

### Task 2: Honors Showcase Banner & Ballot Section Redesign
- Redesign the Announced Winner Showcase Banner:
  - Replace rainbow gradient with an elegant dark forest surface (`#111D17`) bordered by `#1A3125` with emerald/gold accents and subtle glow.
  - Display winner avatar/initials, full name, designation, department, award month badge, citation quote, and prize details.
- Redesign `VotingCard.jsx`:
  - Show shortlisted nominees in a grid with nominee avatar, name, designation, and nomination citations.
  - Single-ballot radio selection with visual indicator.
  - Submit vote action button with confirmation and loading spinner.
  - Visual badge indicating "Ballot Cast" if the user has already voted.
  - If user has `rewards.manage`, show a toggle to inspect live vote tallies (`GET /rewards/awards/:id/stats`).

### Task 3: Award Cycles & Nomination Management Table/Cards
- Redesign cycle list cards:
  - Display cycle title, month pill, status badge (Violet for Nomination, Amber for Voting, Emerald for Announced).
  - Deadlines for nominations and voting with countdown indicators.
  - Nominations list: expandable drawer or section showing candidate nominations, nominator info, and nomination reason.
  - Shortlist toggle: Guarded by `hasPermission('rewards.manage')`.
  - Status progression actions: "Open Voting", "Close Voting", "Announce Winner" (guarded by `rewards.manage`).
  - "Nominate Colleague" button: Guarded by `hasPermission('rewards.nominate')`.

### Task 4: Modals Redesign (`CreateAwardModal`, `NominateModal`, `AnnounceWinnerModal`)
- **`CreateAwardModal.jsx`**:
  - Dark/light responsive surface with hairline borders.
  - Cycle title, award month picker, department dropdown (or "Entire Company"), nomination deadline, voting deadline, and prize details.
  - Invariant validation: `nominationDeadline < votingDeadline`.
- **`NominateModal.jsx`**:
  - Searchable employee selector (excluding self).
  - Citation reason textarea with min 10 characters counter.
  - Error banner and loading state.
- **`AnnounceWinnerModal.jsx`**:
  - Winner selector from shortlisted nominees.
  - Winner citation text and optional final prize note.
  - Confirmation alert with warning that winner announcement broadcasts company-wide.

---

## 4. Verification & Acceptance Criteria
- [ ] Regular Employee cannot see "Launch Cycle", "Shortlist", or "Announce Winner" buttons.
- [ ] Department Manager can see "Nominate" button for team members, but cannot advance award status.
- [ ] Admin / HR with `rewards.manage` can create cycles, shortlist, and announce winners.
- [ ] Real-time updates reflect without page refresh via Socket.io events (`award:voted`, `award:statusUpdated`, `award:announced`).
- [ ] 0 Oxlint errors and 0 `prop-types` imports.
