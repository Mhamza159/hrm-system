# Plan 15-02: Appreciation Wall Submodule Audit, UI Redesign & Interaction Overhaul

## 1. Goal
Completely audit and redesign the **Appreciation Wall** submodule (`AppreciationWallPage.jsx`, `KudosCard.jsx`, `GiveKudosModal.jsx`). Elevate peer-to-peer recognition with a high-craft modern feed, metric overview cards, interactive badge filter chips, full-text search, live Socket.io updates, optimistic like reactions, and strict PBAC gating (`rewards.kudos`).

---

## 2. Target Files & Scope
- `frontend/src/features/rewards/pages/AppreciationWallPage.jsx`
- `frontend/src/features/rewards/components/KudosCard.jsx`
- `frontend/src/features/rewards/components/GiveKudosModal.jsx`

---

## 3. Detailed Tasks

### Task 1: Overview KPIs, Badge Filters & Search in `AppreciationWallPage.jsx`
- Add 3 header metric summary cards:
  - **Total Kudos Shared**: Total peer recognition posts.
  - **Badges Awarded**: Count of active badge recognitions.
  - **Community Cheers**: Total like reactions accumulated across posts.
- Redesign Badge Filter Chips:
  - Horizontal scrollable row of badge chips (`All`, `Team Player`, `Problem Solver`, `Customer Hero`, `Innovation Champ`, `Leadership Star`, `Above & Beyond`, `Rockstar`).
  - Active chip styled in bold emerald (`bg-[#00C471] text-white shadow-sm`), inactive styled in subtle surface borders.
- Add Search & Scope Bar:
  - Text search by employee name or recognition text.
  - Clear filter action.
- Action Button:
  - "Send Kudos" button visible only to users with `hasPermission('rewards.kudos')`.

### Task 2: High-Craft Peer Kudos Card (`KudosCard.jsx`)
- Redesign `KudosCard.jsx` using the Forest & Emerald surface specification:
  - Card frame: `#FFFFFF` (light) / `#111D17` (dark) with `#EAECF0` / `#1A3125` hairline border.
  - Sender and receiver header:
    - Sender avatar + name + role $\rightarrow$ arrow icon $\rightarrow$ Receiver avatar + name + role + department badge.
    - Relative timestamp (`2 hours ago`, `Yesterday`).
  - Recognition Badge Pill:
    - Custom icon for each badge type with specialized accent pill color (e.g. Amber for Rockstar, Cyan for Problem Solver, Emerald for Team Player).
  - Quotation body:
    - Styled blockquote with clean typography, proper line clamping, and comfortable reading height.
  - Social reaction bar:
    - Heart / Like button with animated heart icon, live counter, and optimistic state update via `useToggleLikeKudosMutation`.
    - Guard like action with `hasPermission('rewards.kudos')`.
    - Public / Private visibility indicator.

### Task 3: Redesign `GiveKudosModal.jsx`
- Modern form modal with Forest & Emerald tokens:
  - Receiver selector: Searchable employee dropdown with employee avatars, names, and department tags (automatically filtering out the logged-in user to prevent self-kudos).
  - Badge picker: Grid of 7 interactive badge cards with icon, badge title, and short descriptive tag.
  - Message input: Textarea with auto-expanding height, placeholder suggestions, and live character counter (min 5, max 500 characters).
  - Visibility toggle: Switch or segmented pill for "Public on Wall" vs "Direct Private Recognition".
  - Validation: Real-time validation preventing submission with empty receiver or message under 5 characters.
  - Success feedback: Instant toast confirmation and automatic modal close.

### Task 4: Real-Time Sockets & Pagination
- Verify live listener for `kudos:created` socket events, ensuring incoming kudos appear at the top of the feed smoothly without resetting user scroll or search filters.
- Pagination or "Load More" controls for feeds exceeding 15 posts.

---

## 4. Verification & Acceptance Criteria
- [ ] Users with `rewards.kudos` can post kudos and toggle likes.
- [ ] Users without `rewards.kudos` cannot post kudos or toggle likes (buttons hidden or disabled).
- [ ] Employees cannot select themselves as the receiver in `GiveKudosModal`.
- [ ] Live WebSocket event `kudos:created` adds new posts in real-time.
- [ ] 0 Oxlint errors, 0 warnings, and 0 `prop-types` imports.
