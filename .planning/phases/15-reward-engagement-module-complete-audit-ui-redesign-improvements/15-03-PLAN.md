# Plan 15-03: Celebration Wall Submodule Audit, UI Redesign & Lifecycle Integration

## 1. Goal
Audit, modernize, and completely redesign the **Celebration Wall** submodule (`CelebrationsWallPage.jsx`, `CelebrationCard.jsx`). Elevate workplace celebrations (birthdays, work anniversaries, new hires, and milestone achievements) into a visually captivating, professionally organized feed with today's spotlight, customizable lookahead periods, and an interactive "Send Milestone Kudos" bridge connecting to the Appreciation Wall.

---

## 2. Target Files & Scope
- `frontend/src/features/rewards/pages/CelebrationsWallPage.jsx`
- `frontend/src/features/rewards/components/CelebrationCard.jsx`
- Integration with `frontend/src/features/rewards/components/GiveKudosModal.jsx`

---

## 3. Detailed Tasks

### Task 1: Header Metrics & Lookahead Controls in `CelebrationsWallPage.jsx`
- Header summary metrics:
  - **Celebrating Today**: Combined count of today's birthdays and work anniversaries.
  - **Upcoming Milestones**: Count of employees celebrating in the selected lookahead window.
  - **Work Anniversaries**: Count of tenure milestones in the window.
- Modern lookahead segmented selector:
  - Quick pills: `15 Days`, `30 Days`, `60 Days`, `90 Days`.
- Today's date banner with localized greeting (`PKT / Asia/Karachi` alignment).

### Task 2: Today's Spotlight Celebration Banner
- Featured Spotlight Card for celebrations occurring **today**:
  - Festive yet executive presentation: subtle emerald particles/glow with dark forest surface (`#111D17`) and `#1A3125` hairline border.
  - Highlight each today's celebrant:
    - High-resolution avatar with celebratory festive ring (cake emoji for birthdays, trophy/star emoji for anniversaries).
    - Employee name, department, designation, and tenure badge ("🎂 28th Birthday Today" or "🏆 3-Year Work Anniversary!").
    - Action CTA: "Send Celebration Kudos" button which opens `GiveKudosModal` pre-populated with this employee and a congratulatory badge (`Rockstar` or `Team Player`).

### Task 3: Upcoming Milestones Grid & Timeline (`CelebrationCard.jsx`)
- Redesign `CelebrationCard.jsx`:
  - Category indicator: Distinct icon and subtle badge for Birthday vs Work Anniversary vs Tenure Milestone.
  - Days Remaining countdown badge:
    - `Tomorrow` (Amber badge)
    - `In X days` (Emerald/Neutral badge)
    - Date formatted cleanly (`Mon, Nov 24`).
  - Employee coordinates: Avatar, name, designation, department.
  - Tenure indicator: For work anniversaries, show "Completing Year X at Company".
  - One-click "Wish Colleague" quick button linking to peer kudos.

### Task 4: Empty States & Loading Shimmers
- Add polished empty states:
  - When no celebrations occur today: clean banner with calendar icon and "No milestones scheduled for today".
  - When no upcoming celebrations in selected lookahead: helpful message suggesting extending lookahead to 60 or 90 days.
- Skeleton loading shimmers matching the card grid layout for seamless transitions when toggling lookahead.

---

## 4. Verification & Acceptance Criteria
- [ ] Today's celebrations correctly display all birthdays and anniversaries matching the current month and day.
- [ ] Lookahead selector dynamically refetches upcoming celebrations for 15, 30, 60, or 90 days.
- [ ] Clicking "Send Kudos" on a celebration card opens `GiveKudosModal` with that colleague already selected.
- [ ] Responsive across desktop, tablet, and mobile (390px) viewports with zero horizontal overflow.
- [ ] 0 Oxlint errors and 0 `prop-types` imports.
