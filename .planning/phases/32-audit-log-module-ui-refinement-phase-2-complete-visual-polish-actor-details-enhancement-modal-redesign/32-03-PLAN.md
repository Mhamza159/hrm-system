# Plan 32-03: Actor Identity Presentation Across All Audit Explorer Views (Table, Timeline, User Activity)

## Objective
Upgrade all three audit explorer views (`AuditLogTableView.jsx`, `AuditLogTimelineView.jsx`, and `AuditLogUserActivityView.jsx`) to feature rich, comprehensive actor identification cards and polished visual presentation adhering to enterprise design standards. Polish `AuditLogFilterToolbar.jsx` with active filter chips and enhanced search UX.

---

## Proposed Changes

### 1. Master Table View Actor Enhancement (`AuditLogTableView.jsx`)
- Redesign Actor Cell:
  - If avatar image URL exists: render crisp round image (`w-8 h-8 rounded-full object-cover border border-border`).
  - Fallback initials avatar: styled emerald/slate circular badge with initials.
  - Prominent full user name (`font-semibold text-foreground text-xs truncate`).
  - Employee ID pill (`text-[10px] font-mono bg-muted text-muted-foreground px-1.5 py-0.2 rounded border border-border/60`).
  - Subtitle metadata: Role badge + Department (`text-[10px] text-muted-foreground truncate`).
- Polish Action & Severity columns using `auditTheme.js` semantic badges.
- Format Device / IP column with subtle icons and OS/browser badges.
- Standardize the Forensics "Inspect" button to a polished outline button (`border border-border hover:border-primary hover:text-primary hover:bg-primary/5 rounded-xl px-2.5 py-1 text-xs font-semibold`).

### 2. Timeline View Enhancement (`AuditLogTimelineView.jsx`)
- Refactor timeline item cards:
  - Header: Action tag, module badge, severity pill, and PKT timestamp.
  - Operational Synopsis: Readable text with high contrast.
  - Footer Actor Strip: Complete actor card with avatar/initials, full name, employee ID, role badge, department, and IP address.
  - Consistent hover animations and connector line styling.

### 3. User Activity View Enhancement (`AuditLogUserActivityView.jsx`)
- Group events by actor and enrich user group cards:
  - Display actual user full name alongside email.
  - Display employee ID, designation, and department.
  - Avatar image or initials circle.
  - Role pill and account active status badge.
  - Mini activity KPI counters (Total, Succeeded, Failed) with color-coded badges.
  - Recent events list inside each user card with direct "Inspect" action.

### 4. Filter Toolbar Polish (`AuditLogFilterToolbar.jsx`)
- Add active filter chips: when filters are selected (module, category, severity, status, search), display removable tags.
- Add clear button inside the search input.
- Polish select dropdowns with consistent border and focus ring tokens (`focus:ring-2 focus:ring-[#00C471]/20 focus:border-[#00C471]`).

---

## Verification Criteria
- [ ] Table View displays full actor identity (name, avatar, employee code, role, department).
- [ ] Timeline View displays enriched actor credentials.
- [ ] User Activity View groups by actor with full identity cards.
- [ ] Filter toolbar supports active filter removal chips and smooth search input.
