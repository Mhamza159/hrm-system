# Plan 32-05: Statutory Retention & Archival Modal Complete Overhaul

## Objective
Completely redesign `frontend/src/features/audit/components/AuditRetentionModal.jsx` into a professional compliance and archival management console. Clearly articulate Pakistan labor compliance retention mandates (365-day statutory ledger), provide active vs. archived metric cards, and introduce a guarded two-step archival confirmation workflow to prevent accidental data modification.

---

## Proposed Changes

### 1. Compliance & Policy Overview Section
- Prominent Statutory Compliance Header:
  - Policy title: "Pakistan Statutory Labor Audit Retention Policy".
  - Mandate description: Records are permanently immutable and must be preserved for at least 365 days before archival eligibility.
  - Immutability Assurance Badge: Verified cryptographic and append-only database enforcement.

### 2. Live Ledger Metric Cards
- 3-card responsive grid:
  - **Active Searchable Records**: Total unarchived audit entries indexed in the primary search pool.
  - **Archived Audit Records**: Total preserved records in cold storage.
  - **Statutory Retention Threshold**: 365 Days standard (with oldest and newest record timestamps).

### 3. Archival Configuration & Impact Preview
- Retention Duration Selector:
  - Preset options: 90 Days, 180 Days, 365 Days (Statutory Recommended), 730 Days (2 Years).
  - Clear notice explaining that archival is non-destructive (soft-archival via `isArchived: true` and `archivedAt: Date`).
  - Records older than the selected threshold will be transitioned to cold archive.

### 4. Guarded Two-Step Archival Confirmation Flow
- Phase 1: User selects retention threshold and clicks "Review Archival Scope".
- Phase 2: Confirmation modal/state displaying the exact warning:
  - "Are you sure you want to archive audit records older than {olderThanDays} days? This action moves records out of standard search views while maintaining legal compliance."
  - Action buttons: "Cancel" (Secondary) and "Confirm Archival" (Primary Emerald / Indigo).
  - Loading state with spinner during archival execution.
  - Refetch retention summary and toast notification upon success.

---

## Verification Criteria
- [ ] Retention Modal displays statutory compliance policy details clearly.
- [ ] Metric cards show real active and archived records from backend `/api/v1/audit-logs/retention`.
- [ ] Guarded two-step confirmation prevents accidental archival triggers.
- [ ] Soft-archival action calls backend API and updates data cleanly without errors.
