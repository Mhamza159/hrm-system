# Plan 32-04: Complete Inspect Details (Forensic Diff) Modal Overhaul

## Objective
Completely redesign `frontend/src/features/audit/components/AuditLogDiffModal.jsx` into a high-density, enterprise-grade forensic investigation modal featuring comprehensive actor identification, clear activity metadata, advanced Before/After visual state comparison, device diagnostics, and raw payload inspection.

---

## Proposed Changes

### 1. Header & Quick Summary
- Modal Title: Forensic Record Investigation with Action key (`log.action`).
- Status Badge: `SUCCESS` (Emerald) or `FAILURE` (Rose).
- Severity Tag: `CRITICAL` / `HIGH` / `MEDIUM` / `LOW`.
- Event Reference ID: Copyable ID chip with clipboard feedback.
- Category Badge and PKT Formatted Timestamp.

### 2. Comprehensive Actor Identification Profile Section
- Prominent Actor Card containing:
  - High-resolution avatar photo or fallback initials avatar badge.
  - Full Name (`text-sm font-bold text-foreground`).
  - Employee Code (e.g. `EMP-001`) with copy action.
  - Email Address.
  - Role pill (e.g. `Super Admin`, `HR Manager`).
  - Designation (e.g. `Senior HR Officer`).
  - Department (e.g. `Human Resources`).
  - Account & Employment Status pill (`Active`, `Notice Period`, `Archived`).

### 3. Execution Context & Device Diagnostics Grid
- 4-card forensic context strip:
  - **Target Resource**: Module name, target model, target document ID (copyable).
  - **Network & IP**: Client IP address, request origin/source.
  - **Client Hardware / OS**: Detected OS (e.g. Windows 11, macOS), Device type (Desktop, Mobile, Tablet).
  - **Browser & User-Agent**: Browser name (Chrome, Firefox, Safari) and full User-Agent string available via tooltip or expansion.

### 4. Advanced Before/After State Mutation Inspector
- Dual-view toggle:
  - **Visual Field Comparison (Default)**:
    - Lists all mutated, added, and removed properties.
    - Added properties highlighted with emerald tag.
    - Removed properties highlighted with rose tag.
    - Modified properties highlighted with amber indicator showing Before $\rightarrow$ After transition.
    - Gracefully formats booleans, dates, nulls, arrays, and nested objects.
    - Filter toggle: "Show only changed fields" (default true) vs "Show all properties".
  - **Raw Forensic JSON Inspector**:
    - Syntax-highlighted preformatted JSON with one-click copy button.

### 5. Operation Outcome & Error Diagnostics
- For `FAILURE` logs: Prominent failure alert box detailing error message, failure reason, and operational impact without exposing internal stack traces or secrets.
- For `SUCCESS` logs: Operational synopsis with timestamp and immutable ledger confirmation.

---

## Verification Criteria
- [ ] Modal displays full actor identity card with all 10 attributes.
- [ ] Target resource and device diagnostics displayed accurately.
- [ ] Before/After state comparison highlights additions, removals, and changes cleanly.
- [ ] Dual-view toggle between Visual Diff and Raw JSON operates smoothly.
- [ ] Modal is responsive, scrollable, and accessible with Esc key and close button.
