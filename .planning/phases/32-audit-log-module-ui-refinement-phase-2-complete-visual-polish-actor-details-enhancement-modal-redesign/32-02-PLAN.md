# Plan 32-02: Universal Design System Tokens, Button & Pill Palette Harmonization

## Objective
Establish a centralized design system token module (`frontend/src/features/audit/utils/auditTheme.js`) strictly aligned with `docs/UI-REFERENCE.md` that maps every action, severity, category, status, and button variant to semantic classes, subtle tinted backgrounds, and crisp icons. Update the summary metric cards, analytics section, and filter toolbar to use these standardized styles.

## Proposed Changes

- Define semantic color mappings for:

  - **Severities**:

    - `HIGH`: `bg-orange-50 text-orange-700 border-orange-200 dark:bg-orange-500/10 dark:text-orange-400 dark:border-orange-500/20`
    - `MEDIUM`: `bg-amber-50 text-amber-700 border-amber-200 dark:bg-amber-500/10 dark:text-amber-400 dark:border-amber-500/20`
    - `LOW`: `bg-slate-100 text-slate-700 border-slate-200 dark:bg-slate-800 dark:text-slate-300 dark:border-slate-700`
  - **Categories**:
    - `AUTHENTICATION`: `bg-cyan-50 text-cyan-700 border-cyan-200 dark:bg-cyan-500/10 dark:text-cyan-400 dark:border-cyan-500/20`
    - `SECURITY`: `bg-rose-50 text-rose-700 border-rose-200 dark:bg-rose-500/10 dark:text-rose-400 dark:border-rose-500/20`

    - `SYSTEM`: `bg-slate-100 text-slate-700 border-slate-200 dark:bg-slate-800 dark:text-slate-300 dark:border-slate-700`
  - **Standard Button Styles**:
    - Primary CTA: `bg-[#00C471] hover:bg-[#049856] text-white font-medium rounded-xl px-4 py-2 text-xs shadow-sm transition-all duration-150`
    - Secondary / Outline: `bg-card border border-border text-foreground hover:bg-muted font-medium rounded-xl px-3.5 py-1.5 text-xs transition-all shadow-sm`
    - Ghost / Subtle: `text-muted-foreground hover:text-foreground hover:bg-muted/80 rounded-xl px-3 py-1.5 text-xs transition-all`
