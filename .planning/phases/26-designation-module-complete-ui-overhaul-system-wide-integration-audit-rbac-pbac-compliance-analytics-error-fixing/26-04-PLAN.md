# Plan 26-04: Designation Directory Overhaul, Dual View Switcher (Table & Card Grid) & Multi-Dimensional Filtering

**Phase:** Phase 26: Designation Module — Complete UI Overhaul, System-Wide Integration Audit, RBAC/PBAC Compliance, Analytics & Error Fixing  
**Objective:** Transform the active designation directory into a high-density enterprise workspace with a dual view switcher (Table View vs. Card Grid View), an advanced multi-dimensional filter bar, and dual-tab segmentation between active titles and archived designations.

---

## 1. Files to Modify / Create

- `frontend/src/features/departments/components/DesignationCardView.jsx` (New Card Grid view)
- `frontend/src/features/departments/components/DesignationFilterBar.jsx` (New multi-filter toolbar)
- `frontend/src/features/departments/pages/DesignationsPage.jsx` (Page overhaul with dual-view and state management)

---

## 2. Step-by-Step Implementation

### Step 1: Create `DesignationCardView.jsx`
- Accepts props: `{ designations = [], onInspect, onEdit, onArchive }`.
- Features:
  - Responsive 1/2/3-column card grid (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).
  - Card anatomy:
    - **Top Bar**: Icon badge, designation title, uppercase code badge (`font-mono`), grade tier badge (`Junior`, `Mid`, `Senior`, `Lead`, `Executive`), and active status badge.
    - **Description**: Truncated 2-line description with fallback text.
    - **Department Link**: Department icon, name, and code.
    - **Headcount Pill**: Visual staff badge (`X staff assigned`).
    - **Bottom Action Bar**: "Inspect" button (`Eye` icon) and action buttons for authorized users (`Can I="org.manage"`: Edit `Edit2`, Archive `Archive`).
  - Empty state with clear messaging when search or filters return 0 results.

### Step 2: Create `DesignationFilterBar.jsx`
- Accepts props:
  - `search`: string search keyword
  - `onSearchChange`: callback
  - `departmentId`: selected department filter
  - `onDepartmentChange`: callback
  - `grade`: selected grade tier filter
  - `onGradeChange`: callback
  - `status`: active/inactive status filter
  - `onStatusChange`: callback
  - `headcountFilter`: 'ALL' | 'STAFFED' | 'EMPTY'
  - `onHeadcountFilterChange`: callback
  - `departmentOptions`: array of active departments
  - `onReset`: reset callback
  - `showStatusFilter`: boolean
- Features:
  - Instant search input with search icon and clear (X) button.
  - Department dropdown selector.
  - Grade tier dropdown selector (`All Grades`, `Junior`, `Mid`, `Senior`, `Lead`, `Executive`).
  - Headcount selector (`All Headcount`, `Staffed (≥1 member)`, `Empty (0 members)`).
  - Status segmented pill buttons (`All`, `Active`, `Inactive`).
  - Active filter chips bar:
    - Displays chips for all active filters (Keyword, Department, Grade, Status, Headcount) with individual dismiss (X) buttons.
    - "Clear all" shortcut button.

### Step 3: Overhaul `DesignationsPage.jsx`
- **State Management**:
  - `activeTab`: `'ACTIVE'` | `'ARCHIVED'`
  - `viewMode`: `'TABLE'` | `'CARD'`
  - Filter states: `search`, `departmentFilter`, `gradeFilter`, `statusFilter`, `headcountFilter`, `archivePage`.
  - Toggle state: `showAnalytics` (boolean, defaults to true).
- **Queries Integration**:
  - `useGetDesignationStatsQuery()`
  - `useGetDesignationAnalyticsQuery()`
  - `useGetDesignationsQuery(activeQueryParams)`
  - `useGetArchivedDesignationsQuery(archivedQueryParams, { skip: activeTab !== 'ARCHIVED' })`
  - `useGetDepartmentsQuery()`
- **Dual View & Tabs Rendering**:
  - Segmented tab bar: `Active Designations (N)` vs `Archived Titles (N)` with count pills.
  - View switcher buttons (List icon for Table, LayoutGrid icon for Cards) on active tab.
  - Render Table View using `<DataTable columns={activeColumns} ... />` or Card Grid using `<DesignationCardView ... />`.
  - Archived tab renders archived table with archive timestamps, actor, and headcount locks.
- **KPI Card Shortcuts**:
  - Clicking `TOTAL` resets filters.
  - Clicking `ACTIVE` filters to `status='ACTIVE'`.
  - Clicking `ARCHIVED` switches to `activeTab='ARCHIVED'`.
  - Clicking `STAFFED` sets `headcountFilter='STAFFED'`.
  - Clicking `EMPTY` sets `headcountFilter='EMPTY'`.

## 3. Verification Criteria
- [ ] Users can seamlessly toggle between high-density Table View and Card Grid View.
- [ ] All filters (search, department, grade, status, headcount) filter records accurately.
- [ ] Active filter chips display and dismissing an individual chip resets only that filter.
- [ ] Active and Archived tabs display independent, correct records.
- [ ] Responsive across mobile, tablet, and widescreen desktop layouts.
