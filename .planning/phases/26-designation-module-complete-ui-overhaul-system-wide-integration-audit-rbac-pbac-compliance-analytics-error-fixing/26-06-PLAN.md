# Plan 26-06: Deep Inspection Details Modal with Assigned Staff Roster & Search

**Phase:** Phase 26: Designation Module — Complete UI Overhaul, System-Wide Integration Audit, RBAC/PBAC Compliance, Analytics & Error Fixing  
**Objective:** Create `DesignationDetailModal.jsx` to provide deep inspection of corporate job designations, including department associations, grade tiers, description, created/archived metadata, and an in-modal assigned employee roster with instant search.

---

## 1. Files to Modify / Create

- `frontend/src/features/departments/components/DesignationDetailModal.jsx` (New deep inspection modal)
- `frontend/src/features/departments/pages/DesignationsPage.jsx` (Wire inspection modal)

---

## 2. Step-by-Step Implementation

### Step 1: Create `DesignationDetailModal.jsx`
- Accepts props: `{ isOpen, onClose, designationId, initialData = null }`.
- Fetch enriched details via `useGetDesignationByIdQuery(designationId, { skip: !isOpen || !designationId })`.
- **Header**:
  - `Award` icon in emerald badge.
  - Designation Title, Monospace Code badge, Grade badge, and Status pill (`Active`, `Inactive`, or `Archived`).
  - Headcount subtitle: `{departmentName} • {headcount} Staff Assigned`.
  - Close button (`X`) and ESC key listener.
- **Section A: Operational Profile & Department Context**:
  - Associated Department: Displays department name, code, and parent division if applicable.
  - Grade Tier: Seniority level explanation.
  - Job Description & Responsibilities block.
- **Section B: Assigned Staff Roster**:
  - Sub-header displaying total members assigned (`{employees.length} Members`).
  - Search input: In-modal search box filtering the staff roster by employee name, employee code, or email.
  - Employee list view (scrollable container):
    - Avatar image or stylized initials circle.
    - Employee Name and monospace `employeeCode` badge (e.g. `EMP-001`).
    - Department name and email.
    - Employment status badge (`Active`, `Probation`, etc.).
  - Empty state: When no employees are assigned or when in-modal search yields 0 matches.
- **Section C: Archival Status Notice**:
  - If `designation.isArchived` is true:
    - Amber alert card showing archival date, archived by administrator, and notification that no new employee assignments can be made.
- **Footer**:
  - Registration timestamp in `Asia/Karachi` timezone (`formatTime`).
  - Close button.

### Step 2: Wire Inspection Modal in `DesignationsPage.jsx`
- State: `isDetailModalOpen`, `detailDesigId`.
- Table and Card views trigger: Clicking `Eye` icon opens `DesignationDetailModal` with `designation._id`.
