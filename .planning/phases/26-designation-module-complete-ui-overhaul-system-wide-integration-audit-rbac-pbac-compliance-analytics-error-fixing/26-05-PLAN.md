# Plan 26-05: Redesigned Create & Edit Modal with Department Selector & Archival Safeguards

**Phase:** Phase 26: Designation Module — Complete UI Overhaul, System-Wide Integration Audit, RBAC/PBAC Compliance, Analytics & Error Fixing  
**Objective:** Redesign the Create and Edit Designation modal (`DesignationModal.jsx`) into a modern, accessible dialog adhering to the Forest & Emerald design system, integrating a department selector that blocks archived departments, visual grade tier cards, code auto-capitalization, and comprehensive error handling.

---

## 1. Files to Modify / Create

- `frontend/src/features/departments/components/DesignationModal.jsx` (Complete modal redesign)

---

## 2. Step-by-Step Implementation

### Step 1: Overhaul Form Fields & Layout in `DesignationModal.jsx`
- **Modal Header**:
  - Modal icon badge (Emerald `Award` icon in `#111D17` / `#1A3125`).
  - Title: "Create New Designation" vs "Edit Designation: {title}".
  - Subtitle explaining corporate job catalog registration.
  - Close button with hover animation and ESC key listener.
- **Field 1: Designation Title**:
  - Input field with placeholder "e.g. Senior Full Stack Engineer".
  - Validation: Min 2, max 100 characters.
- **Field 2: Designation Code**:
  - Input field with automatic uppercase formatting (`toUpperCase()`).
  - Monospace font styling (`font-mono tracking-wider`).
  - Helper note: "Unique within the assigned department (e.g. SDE-SR, HR-MGR)".
- **Field 3: Associated Department**:
  - Dropdown selector displaying full department names and codes (`name (code)`).
  - **Archival Guard**: Filters out archived departments (`d.isArchived !== true`) from the active selection choices, preventing assigning designations to retired business units.
  - If editing a designation whose department was previously archived, displays the department with an `(Archived)` warning label.
- **Field 4: Grade Tier Visual Selector**:
  - 5 interactive grade cards for `Junior`, `Mid`, `Senior`, `Lead`, `Executive`.
  - Displays grade name, seniority level, and semantic badge color:
    - `Junior` (Slate): Entry-level professional
    - `Mid` (Cobalt Blue): Independent contributor
    - `Senior` (Emerald): Advanced specialist
    - `Lead` (Purple): Technical/functional leader
    - `Executive` (Amber): Strategic director/head
  - Radio button or click card to select grade tier.
- **Field 5: Operational Scope & Description**:
  - Multi-line textarea for job description and primary responsibilities (max 500 characters).
- **Field 6: Status Toggle**:
  - Toggle switch for Active / Inactive status.

### Step 2: Form Submission & Error Handling
- Validate required fields client-side before sending (`title`, `code`, `departmentId`, `grade`).
- Disable submit button during `isSubmitting` with spinning `Loader2` indicator.
- Display server-side error messages in a prominent alert banner (e.g., code duplicate in department).
- Display toast notification (`toast.success`) on successful creation or update.
- Close modal and reset form state cleanly.
