**Phase:** Phase 26: Designation Module — Complete UI Overhaul, System-Wide Integration Audit, RBAC/PBAC Compliance, Analytics & Error Fixing

---

## 2. Step-by-Step Implementation

### Step 1: Create `DesignationStatsCards.jsx`
- Accepts props: `{ stats = {}, isLoading = false, onFilterClick = null }`.
- Extract metrics:
  - `total`: Total job titles
  - `active`: Active operating designations
  - `archived`: Archived designations
  - `totalAssignedEmployees`: Total staff members assigned
  - `withEmployees`: Designations with $\ge 1$ staff member
  - `withoutEmployees`: Empty designations ($0$ staff)
  - `departmentsCount`: Distinct departments using designations
- Design 7 responsive cards:
  - Responsive grid: `grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-7 gap-3`.
  - Theming: `#111D17` cards, `#1A3125` borders, emerald `#00C471` accents, tabular numbers (`tabular-nums font-mono`).
  - Skeleton pulse loading state when `isLoading` is true.
  - Interactive click handlers (`onFilterClick(id)`) enabling users to click cards (e.g. `EMPTY`, `STAFFED`, `ARCHIVED`) to immediately trigger the corresponding table filter.

### Step 2: Create `DesignationAnalyticsSection.jsx`
- Accepts props: `{ analytics = {}, isLoading = false }`.
- Features:
  - **Section Header**: Icon, title ("Designation Workforce & Structure Analytics"), subtitle with total divisions and titles, and collapse/expand toggle button.
  - **Top Key Highlights Bar (3 tiles)**:
    - *Largest Title by Headcount*: Name, code, member count, and percentage share.
    - *Executive / Leadership Tier*: Headcount in Lead & Executive tiers.
    - *Smallest Staffed Title*: Focused unit identifying niche specializations.
  - **Grade Tier Distribution Pills**:
    - Visual breakdown of the 5 canonical tiers (`Junior`, `Mid`, `Senior`, `Lead`, `Executive`) with count of titles and total staff in each grade.
  - **Horizontal Bar Chart (Left Column, 7 Cols)**:
    - Renders designations sorted by headcount.
    - Responsive progress bars showing relative allocation (`Math.round((count / maxCount) * 100)`).
    - Title, code badge, grade badge, headcount, and percentage share.
  - **Native SVG Donut Chart (Right Column, 5 Cols)**:
    - Native SVG circle calculation with `strokeDasharray` and `strokeDashoffset` (zero external chart dependencies).
    - Only slices with `count > 0` are rendered, preventing 0% round stroke cap dot artifacts at 12 o'clock.
    - Interactive hover state: hovering a slice or legend item updates the central SVG readout to show that department's code and designation count.
    - Full color-coded legend with department names and percentages.
  - **Zero Data Empty State**:
    - Gracefully handles empty designations or 0 staff allocations with clear, non-breaking placeholder messages.
