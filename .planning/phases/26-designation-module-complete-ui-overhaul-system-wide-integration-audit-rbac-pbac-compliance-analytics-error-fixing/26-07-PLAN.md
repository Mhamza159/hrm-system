## 2. Step-by-Step Implementation

### Step 1: Create `DesignationArchiveModal.jsx`
- Accepts props: `{ isOpen, onClose, designation, onConfirm, isSubmitting }`.
- Header: Amber badge with `Archive` icon and title: *"Archive Designation"*.
- Body:
  - Warning alert: Informs the user that archiving this designation will hide it from active creation dropdowns, new hires, and promotions, while preserving all historical employee records.
  - Designation Summary Card:
    - Designation Title, Monospace Code, Grade Tier badge, Department Name.
    - Assigned Staff indicator: Displays current assigned headcount (`headcount` or `assignedEmployeesCount`).
    - Notice: *"X employee(s) currently hold this designation. Their employment records will remain intact, but no new employees can be assigned until restored."*
  - Optional archive reason text area.
- Actions:
  - Cancel button.
  - Confirm Archive button (Amber background `#F59E0B`, loading spinner during `isSubmitting`).

### Step 2: Create `DesignationRestoreModal.jsx`
- Accepts props: `{ isOpen, onClose, designation, onConfirm, isSubmitting }`.
- Header: Emerald badge with `RotateCcw` or `ArchiveRestore` icon and title: *"Restore Designation"*.
- Body:
  - Details card of the archived designation: Title, Code, Grade Tier, Department.
  - Metadata: When archived (`archivedAt`), by whom (`archivedBy.name`).
  - Department check: Verify if the parent department is active. If parent department is archived, display warning: *"Note: Parent department is archived. You may need to restore the department to assign employees."*
  - Reassurance text: *"Restoring this designation will return it to the active directory and re-enable it for employee assignments."*
- Actions:
  - Cancel button.
  - Confirm Restore button (Emerald `#00C471`, loading spinner).

### Step 3: Create `DesignationPermanentDeleteModal.jsx` with Mandatory Employee Lock
- Accepts props: `{ isOpen, onClose, designation, onConfirm, isSubmitting }`.
- Header: Crimson badge with `AlertTriangle` icon and title: *"Permanently Delete Designation"*.
- **The Non-Negotiable Guard Check**:
  - Evaluate `assignedCount = designation?.headcount || designation?.assignedEmployeesCount || 0`.
  - **Case A: `assignedCount > 0` (BLOCKED STATE)**:
    - Render a prominent crimson alert card (`bg-rose-950/40 border border-rose-500/40 text-rose-300`):
      - Icon: `ShieldAlert` or `Lock`.
      - Message: *"This designation cannot be permanently deleted because {assignedCount} employee(s) are still assigned to it. Please reassign all employees to another designation before proceeding."*
    - Show list or count of affected staff members.
    - The Delete action button is **STRICTLY DISABLED** with lock icon and tooltip.
    - Only a "Close" button is actionable.
  - **Case B: `assignedCount === 0` (EMPTY DESIGNATION - PERMITTED)**:
    - Crimson danger warning: *"This action cannot be undone. This record will be permanently purged from the database."*
    - Exact match confirmation input:
      - Prompt user to type the designation code (e.g. `type "{designation.code}" to confirm`).
      - Delete button disabled until the input string strictly matches `designation.code`.
    - Permanently Delete button (`bg-rose-600 hover:bg-rose-500 text-white font-medium`).

### Step 4: Create `ArchivedDesignationList.jsx`
- Uses `useGetArchivedDesignationsQuery` with search, department filter, grade tier filter, and pagination.
- High-density tabular layout:
  - Column 1: Designation Title, Monospace Code, Grade Tier badge.
  - Column 2: Associated Department.
  - Column 3: Current Headcount (`X Employees`).
  - Column 4: Archival Metadata (`archivedAt` formatted with `Asia/Karachi` time, `archivedBy` user badge).
  - Column 5: Actions:
    - Restore button (`RotateCcw`, emerald hover, opens `DesignationRestoreModal`).
    - Permanent Delete button (`Trash2`, rose hover, opens `DesignationPermanentDeleteModal`).
- Empty State: When no archived designations exist, show clean emerald-themed state with *"Archive is Empty"* illustration.

### Step 5: Wire Archive Tab and Modals in `DesignationsPage.jsx`
- Tabs: `Active Designations` and `Archived Designations (count)`.
- Active designation count vs archived count badges in tabs.
- Hook up state for `archiveModalTarget`, `restoreModalTarget`, `permanentDeleteModalTarget`.
- Connect RTK query mutations: `useArchiveDesignationMutation`, `useRestoreDesignationMutation`, `usePermanentDeleteDesignationMutation`.
- Toast notifications on success/error.

## 3. Verification Criteria
- [ ] Switching between Active and Archived tabs displays their respective datasets accurately.
- [ ] Archiving an active designation moves it immediately to the Archived tab and decrements active count.
- [ ] Restoring an archived designation returns it to the active directory and increments active count.
- [ ] Attempting permanent deletion of a designation with $\ge 1$ assigned employee is strictly blocked in the UI with the exact mandatory guidance text.
- [ ] Permanent deletion of a zero-employee designation requires exact code confirmation and successfully purges the document.
- [ ] RBAC enforcement: Only `org.manage` can archive/restore/delete; non-authorized users see read-only archive listing or hidden controls.
