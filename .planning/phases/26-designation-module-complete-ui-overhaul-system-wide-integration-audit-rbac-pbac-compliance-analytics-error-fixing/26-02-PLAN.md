## 2. Step-by-Step Implementation

### Step 1: Implement `getDesignationAnalytics` in `department.service.js`
- Gather basic counts via `Promise.all`:
  - `totalDesignations`: `Designation.countDocuments({ isDeleted: false })`
  - `activeDesignations`: `Designation.countDocuments({ isArchived: { $ne: true }, isDeleted: false })`
  - `archivedDesignations`: `Designation.countDocuments({ isArchived: true, isDeleted: false })`
- Fetch active designations populated with `departmentId` (`name code`).
- Group employee counts by `designationId` via `Employee.aggregate`:
  ```javascript
  const counts = await Employee.aggregate([
    { $match: { designationId: { $in: activeIds }, isDeleted: false } },
    { $group: { _id: '$designationId', count: { $sum: 1 } } }
  ]);
  ```
- Calculate:
  - `totalAssignedEmployees`: Sum of all assigned employee headcounts across active designations.
  - `staffedDesignations`: Number of active designations with $\ge 1$ employee.
  - `emptyDesignations`: Number of active designations with $0$ employees.
  - `uniqueDepartmentsCount`: Number of distinct departments currently linked to active designations.
- **Grade Tier Breakdown**:
  - Tally count of designations and total employees assigned per grade: `Junior`, `Mid`, `Senior`, `Lead`, `Executive`.
- **Department-wise Designation Distribution (SVG Donut Data)**:
  - Aggregate number of designations and assigned employees grouped by department.
  - Compute share percentage (`percentage`).
- **Designation Headcount Breakdown (Bar Chart Data)**:
  - Sorted array of designations with `title`, `code`, `grade`, `departmentName`, `headcount`, and `percentage` of total staff.
  - Identify `topDesignation` (highest headcount) and `lowestDesignation` (lowest non-zero headcount).
- Return standard structured analytics payload:
  ```javascript
  return {
    summary: {
      totalDesignations,
      activeDesignations,
      archivedDesignations,
      totalAssignedEmployees,
      staffedDesignations,
      emptyDesignations,
      uniqueDepartmentsCount
    },
    gradeBreakdown,
    departmentDistribution,
    designationBreakdown,
    topDesignation,
    lowestDesignation
  };
  ```

### Step 2: Implement `getDesignationStats`
- Call `getDesignationAnalytics()` and return:
  ```javascript
  return {
    total: analytics.summary.totalDesignations,
    active: analytics.summary.activeDesignations,
    archived: analytics.summary.archivedDesignations,
    totalAssignedEmployees: analytics.summary.totalAssignedEmployees,
    withEmployees: analytics.summary.staffedDesignations,
    withoutEmployees: analytics.summary.emptyDesignations,
    departmentsCount: analytics.summary.uniqueDepartmentsCount
  };
  ```

### Step 3: Enriched `getDesignationById(id)` with Staff Roster
- Find designation by ID, populate `departmentId` (`name code description`).
- Query assigned staff roster:
  ```javascript
  const employees = await Employee.find({ designationId: id, isDeleted: false })
    .select('name employeeCode email departmentId status joiningDate avatar')
    .populate('departmentId', 'name code')
    .sort({ name: 1 })
    .lean();
  ```
- Return enriched document including `headcount: employees.length` and `employees: formattedEmployees`.

### Step 4: Wire Routes in `designation.routes.js`
- Mount BEFORE `/:id`:
  ```javascript
  router.get('/analytics', checkPermission('org.view'), departmentController.getDesignationAnalytics);
  router.get('/stats', checkPermission('org.view'), departmentController.getDesignationStats);
  router.get('/archived', checkPermission('org.view'), departmentController.getArchivedDesignations);
  ```

### Step 5: Update `departmentsApi.js` in Frontend
- Add endpoints:
  - `getDesignationStats`: `query: () => '/designations/stats'`, `providesTags: ['DesignationStats']`
  - `getDesignationAnalytics`: `query: () => '/designations/analytics'`, `providesTags: ['DesignationAnalytics', 'DesignationStats']`
  - `getArchivedDesignations`: `query: (params) => ({ url: '/designations/archived', params })`, `providesTags: ...`
  - `archiveDesignation`: `PATCH /designations/:id/archive`, invalidates `['Designations', 'ArchivedDesignations', 'DesignationStats', 'DesignationAnalytics']`
  - `restoreDesignation`: `PATCH /designations/:id/restore`, invalidates `['Designations', 'ArchivedDesignations', 'DesignationStats', 'DesignationAnalytics']`
  - `permanentDeleteDesignation`: `DELETE /designations/:id/permanent`, invalidates `['Designations', 'ArchivedDesignations', 'DesignationStats', 'DesignationAnalytics']`
- Update existing `createDesignation`, `updateDesignation`, and `deleteDesignation` mutations to also invalidate `'DesignationStats'` and `'DesignationAnalytics'`.
