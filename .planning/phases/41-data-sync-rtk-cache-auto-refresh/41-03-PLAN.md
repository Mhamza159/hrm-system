# Plan 41-03: Global Real-Time Socket.io Cache Dispatcher & Backend Invalidation Signals

**Phase:** Phase 41: Software-Wide Real-Time Data Synchronization, RTK Query Cache Invalidation & Automatic Refresh System  
**Plan ID:** 41-03  
**Target:** Frontend Layout Shell & WebSocket Hub (`frontend/src/components/layout/AppLayout.jsx`, `frontend/src/hooks/useRealtimeCacheSync.js`, `backend/src/services/socket.service.js`)  
**Requirement Reference:** Requirement 5 ("Multi-User Real-Time Socket.io Cache Dispatcher")

---

## 1. Goal & Objectives
Enable seamless cross-user and multi-device real-time synchronization. When an action occurs on User A's browser (e.g., manager approves a leave request), User B's open screen (e.g. employee viewing their leave dashboard) immediately updates with zero manual refresh.
- Create a dedicated, universally mounted hook `useRealtimeCacheSync.js` in the frontend.
- Mount `useRealtimeCacheSync()` inside `AppLayout.jsx` so that every authenticated page is permanently connected and listening.
- Listen for real-time invalidation signals (`cache:invalidate`, `notification:new`, `announcement:new`, `attendance:sync`, `leave:sync`, `approval:sync`).
- Enhance backend `socket.service.js` with a lightweight helper `broadcastCacheInvalidation(tags, { userId, departmentId, company })` to emit invalidations to targeted recipient rooms.

---

## 2. File-Level Changes

### 1. `backend/src/services/socket.service.js`
- Export `broadcastCacheInvalidation(tags, scope = {})`:
  - If `scope.userId`: emit to `user:${userId}`.
  - If `scope.departmentId`: emit to `dept:${departmentId}`.
  - If `scope.company` or global: emit to `company:broadcast`.
  - Event payload: `{ event: 'cache:invalidate', tags: Array.isArray(tags) ? tags : [tags], timestamp: Date.now() }`.

### 2. `frontend/src/hooks/useRealtimeCacheSync.js` (New Hook)
- Uses Redux `useDispatch` and socket connection from `getSocket()` / `useSocket()`.
- Binds to `'cache:invalidate'`:
  ```javascript
  socket.on('cache:invalidate', ({ tags }) => {
    if (Array.isArray(tags) && tags.length > 0) {
      dispatch(baseApi.util.invalidateTags(tags));
    }
  });
  ```
- Also listens to domain-specific events (`attendance:punch`, `leave:status`, `notification:new`, `announcement:new`) and invalidates corresponding tags.

### 3. `frontend/src/components/layout/AppLayout.jsx`
- Import and invoke `useRealtimeCacheSync()` alongside `useIdleTimer()`.
- Guarantees that any authenticated route automatically has real-time synchronization active.

## 3. Verification Criteria
1. Open two browser windows (or tabs) with different user roles (e.g. Employee in Tab 1, Manager in Tab 2).
2. Employee submits a leave request in Tab 1 $\rightarrow$ Manager's pending approvals table in Tab 2 immediately updates without refreshing.
3. Manager approves the leave in Tab 2 $\rightarrow$ Employee's leave balance and status in Tab 1 immediately reflects "Approved" without refreshing.
4. Linter passes with 0 errors; Vite production build passes cleanly.
