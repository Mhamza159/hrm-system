# Plan 11-01: KPI Templates Redesign, Dynamic 100% Weightage Modal, Detail View & Test Hardening

## Objective
Harden backend test suite deadline handling for Module M19 to achieve 100% test pass rate, create a reusable enterprise `ConfirmModal` for destructive/state actions across the module, and completely redesign the **KPI Templates** section according to the Forest & Emerald design archetype (`DESIGN.md`). Provide a real-time 100% weightage visual gauge in the authoring modal and add a comprehensive read-only `KpiTemplateDetailModal`.

---

## Proposed Changes

### 1. `backend/tests/m19.performance.e2e.test.js`
- In `Slice 2: Review Cycles Orchestrator & Auto-Instantiation (Row 19.2) > 19.2-2`:
  - Replace hardcoded static past dates with dynamic future dates:
    - `startDate`: current date ISO string.
    - `endDate`: `+60 days`.
    - `selfReviewDeadline`: `+15 days` (e.g. `new Date(Date.now() + 15 * 86400000).toISOString().split('T')[0]`).
    - `managerReviewDeadline`: `+30 days` (e.g. `new Date(Date.now() + 30 * 86400000).toISOString().split('T')[0]`).
  - Ensures 100% green test passes across all 24 e2e test cases.

### 2. `frontend/src/features/performance/components/ConfirmModal.jsx` (New)
- Build a reusable, accessible confirmation dialog:
  - Supports `title`, `description`, `confirmText`, `cancelText`, `variant` (`'danger'` | `'emerald'` | `'warning'`), `isOpen`, `onClose`, `onConfirm`, `isLoading`.
  - Replaces all legacy `window.confirm` browser dialogs across the Performance module.

### 3. `frontend/src/features/performance/components/KpiTemplateDetailModal.jsx` (New)
- Dedicated read-only modal for inspecting a KPI Master Template:
  - Displays template title, designation badge, active status pill, description, creation timestamp, and author.
  - Interactive visual breakdown of all KPIs: title, description, weightage percentage progress bar, and target criteria card.
  - Summary footer with total metrics count and confirmed 100% weightage validation badge.
  - "Edit Template" button guarded by `performance.template.manage`.

### 4. `frontend/src/features/performance/components/KpiTemplateModal.jsx` (Redesign)
- Overhaul modal to Forest & Emerald design:
  - Header with Emerald icon badge and title.
  - Template Name, Designation selector, and Description inputs with focus ring styling.
  - **Dynamic 100% Weightage Visual Gauge:**
    - Live progress bar showing current sum of KPI weights.
    - Status pill indicating:
      - Exactly 100%: Green checkmark ("Valid: Exactly 100%").
      - Under 100%: Amber indicator ("Under by X% — add more weight").
      - Over 100%: Rose indicator ("Exceeded by X% — reduce weight").
    - Disables submit button until sum is exactly 100%.
  - Ergonomic row-by-row KPI card editor with Title, Target Criteria, Weight %, Description, and Remove button.
  - "+ Add Performance Metric" button with automatic default template criteria.

### 5. `frontend/src/features/performance/pages/KpiTemplatesPage.jsx` (Redesign)
- Top KPI Summary Banner:
  - Total Templates, Active Templates, Designations Covered, Total KPIs Defined.
- Modern Filter Bar:
  - Search by template name.
  - Filter by Designation dropdown.
  - Filter by Active / Inactive status toggle.
- High-Density Cards & Table:
  - Shows template title, designation badge, metric count pill, 100% weightage status pill, active indicator, and action menu.
  - Click row or "View Details" to open `KpiTemplateDetailModal`.
  - "Edit" opens `KpiTemplateModal`.
  - "Delete" triggers `ConfirmModal` with deletion confirmation.
- PBAC Guards:
  - Create/Edit/Delete actions wrapped in `Can perform="performance.template.manage"`.
