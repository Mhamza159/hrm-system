# Plan 11-03: Team Reviews Queue, Review Detail Modal, Manager Evaluation & Finalize Redesign

## Objective
Redesign the **Team Reviews** management queue (`TeamReviewsPage.jsx`) into an enterprise dashboard for Department Managers, HR, and Super Admin. Introduce a comprehensive `ReviewDetailModal.jsx` for read-only multi-tab inspection of employee appraisals, upgrade `ManagerReviewModal.jsx` with ergonomic 1–5 scoring and increment recommendation controls, and polish `FinalizeReviewModal.jsx` and `PeerFeedbackModal.jsx`.

---

## Proposed Changes

### 1. `frontend/src/features/performance/components/ReviewDetailModal.jsx` (New)
- Build a comprehensive modal to view any employee review in full detail:
  - Header: Employee avatar, name, code, designation, department, cycle title, and status pill.
  - Multi-tab navigation:
    - **KPI Scorecard Tab:** Snapshotted KPIs with criteria, weightage %, self rating & comments, and manager rating & comments. Visual comparison bar.
    - **Goals / OKRs Tab:** Personal goals defined by the employee with target values, self ratings, and manager scores.
    - **360° Peer Feedback Tab:** Peer ratings and comments with confidentiality masking (anonymous).
    - **Evaluation Summary Tab:** Calculated Self Score vs Manager Score, qualitative strengths & improvements, recommended increment %, final rating, and linked M9 Salary Revision ID (if finalized).
  - Quick action buttons (e.g. "Conduct Manager Review", "Finalize Review") according to user permissions and current review state.

### 2. `frontend/src/features/performance/components/ManagerReviewModal.jsx` (Redesign)
- Upgrade evaluation modal for reporting managers:
  - Header with employee profile snapshot and cycle badge.
  - Self-review insights banner showing employee's self score and remarks.
  - Interactive KPI scoring cards:
    - 1–5 interactive star / button rating control for each KPI.
    - Weightage indicator and target criteria preview.
    - Qualitative manager feedback textarea per KPI.
  - Goals rating section (if employee defined OKRs).
  - Overall evaluation fields:
    - Key Strengths textarea.
    - Areas for Improvement textarea.
    - **Salary Increment Recommendation:**
      - Slider and numeric input ($0\%$ to $30\%$).
      - Justification notes textarea.
  - Dynamic weighted score calculator updating in real time.
  - "Submit Manager Evaluation" button with validation and loading state.

### 3. `frontend/src/features/performance/components/FinalizeReviewModal.jsx` (Redesign)
- Upgrade executive sign-off modal for Super Admin & HR Manager:
  - Side-by-side comparison of Self Score ($1-5$) vs Manager Score ($1-5$).
  - Recommended increment from manager highlighted in an emerald alert box.
  - Final Rating selector ($1-5$ stars).
  - Approved Salary Increment % input:
    - Includes explanatory preview callout: "Approving an increment > 0% will automatically archive the employee's current salary structure and instantiate an updated active structure in Module M9 (Payroll)."
  - Executive appraisal comments textarea.
  - Finalize confirmation button with loading indicator.

### 4. `frontend/src/features/performance/components/PeerFeedbackModal.jsx` (Redesign)
- Upgrade 360° peer review modal:
  - Searchable dropdown to pick peer colleague from active employees.
  - Notice emphasizing that peer submissions are confidential.
  - Clean invitation request submission button.

### 5. `frontend/src/features/performance/pages/TeamReviewsPage.jsx` (Redesign)
- Top KPI Summary Banner:
  - Total Reviews in Queue, Pending Self-Review, Awaiting Manager Review, Ready for Finalization, Finalized.
- Multi-faceted Filter Bar:
  - Search by employee name or code.
  - Filter by Review Cycle.
  - Filter by Review Status (`Active`, `Manager_Review`, `Ready_For_Finalization`, `Finalized`).
  - Clear filters shortcut button.
- Modern High-Density Review Table:
  - Columns:
    - Employee (Avatar, full name, code).
    - Role & Department (Designation, Department badge).
    - Appraisal Cycle (Cycle title, period badge).
    - Status Pill (Semantic colors: Blue for Self, Amber for Manager, Purple for Finalization, Emerald for Finalized).
    - Scores (Self Score pill vs Manager Score pill with star badges).
    - Action Menu:
      - "View Full Scorecard" -> opens `ReviewDetailModal`.
      - "Evaluate Staff" (Manager Review) -> opens `ManagerReviewModal` (visible when status is `Manager_Review` or `Active`).
      - "Finalize Appraisal" -> opens `FinalizeReviewModal` (guarded by `performance.review.finalize`).
      - "360° Peer Feedback" -> opens `PeerFeedbackModal` (guarded by `performance.peer.manage`).
- Responsive layout with mobile card fallback for small screens.
