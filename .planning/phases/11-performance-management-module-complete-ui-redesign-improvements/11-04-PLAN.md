# Plan 11-04: Employee Self-Review, Goals Editor, Historical Timeline & Responsive Polish

## Objective
Redesign the employee-facing performance portal (`MyReviewPage.jsx`), upgrade the quarterly OKRs editor (`GoalsEditor.jsx`), polish the historical appraisal timeline (`EmployeePerformanceTab.jsx`), perform a comprehensive responsive design pass across all breakpoints (390px mobile, 768px tablet, 1280px+ desktop), and verify complete system stability with frontend and backend test runs.

---

## Proposed Changes

### 1. `frontend/src/features/performance/components/GoalsEditor.jsx` (Redesign)
- Upgrade goals editor into the Forest & Emerald theme:
  - Clean card container with Target icon and count badge.
  - Locked badge and informational notice if self-review has already been submitted or cycle is finalized.
  - Interactive goal item cards:
    - Goal Title input.
    - Description textarea.
    - Target Value and Metric Unit inputs.
    - Weightage percentage input.
    - Delete button (when unlocked).
  - "+ Add Quarterly Goal" button.
  - "Save Goals & OKRs" button with loading state.

### 2. `frontend/src/features/performance/pages/MyReviewPage.jsx` (Redesign)
- Overhaul personal review page for employees:
  - **Active Appraisal Cycle Header:**
    - Cycle title, period details, and status badge.
    - **Self-Review Deadline Countdown Pill:** Showing days remaining or overdue warning if passed.
  - **Self-Evaluation State Handling:**
    - **Before Submission:**
      - Form to set goals/OKRs with `GoalsEditor.jsx`.
      - Interactive 1–5 star / rating control for each assigned KPI with criteria description and weightage percentage.
      - Self-assessment reflection textarea for each KPI.
      - Overall summary textarea.
      - Real-time Self-Score calculation badge (`tabular-nums font-mono`).
      - "Submit Self-Appraisal" button with confirmation prompt.
    - **Awaiting Manager Evaluation:**
      - Clear informative banner: "Self-review submitted successfully on [Date]. Currently awaiting manager review."
      - Read-only display of submitted ratings and comments.
    - **Finalized State:**
      - Congratulatory executive summary banner.
      - Final official rating ($1-5$ stars) and score badge.
      - Final executive comments and approved salary increment badge (`+X% Approved Increment`).
      - Detailed breakdown of Manager ratings and qualitative feedback.
  - Empty state when no appraisal cycle is active.

### 3. `frontend/src/features/performance/components/EmployeePerformanceTab.jsx` (Redesign)
- Upgrade the historical appraisal tab inside Employee Profile (`/employees/:id`):
  - Modern timeline showing all historical finalized performance reviews.
  - Each entry features:
    - Cycle title, year, and designation.
    - Final Rating badge ($X/5$) with star icons.
    - Approved increment badge (`+X%` in emerald) if applicable.
    - Executive feedback summary snippet.
  - Clean empty state when no historical reviews exist.

### 4. Overall UI Consistency & Responsive Verification
- Verify that zero `indigo-*` classes remain in any file within `frontend/src/features/performance`.
- Check mobile navigation and layout on 390px (cards stack vertically, tables scroll horizontally, modals scale to viewport).
- Run full frontend production build: `npm --prefix frontend run build`.
- Run full backend performance tests: `npm --prefix backend test -- tests/m19.performance.e2e.test.js`.
