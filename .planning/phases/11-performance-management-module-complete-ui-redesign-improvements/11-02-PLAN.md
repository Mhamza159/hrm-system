# Plan 11-02: Appraisal Cycles Redesign, Cycle Detail View & Telemetry Progress Overhaul

## Objective
Completely redesign the **Appraisal Cycles** module (`ReviewCyclesPage.jsx`) and its progress analytics telemetry view (`CycleProgressPage.jsx`) into the Forest & Emerald design archetype. Add a dedicated `ReviewCycleDetailModal.jsx` for viewing cycle details, replace browser confirms with `ConfirmModal`, and upgrade `ReviewCycleModal.jsx` with date-range validation and an explainer for automatic review instantiation.

---

## Proposed Changes

### 1. `frontend/src/features/performance/components/ReviewCycleDetailModal.jsx` (New)
- Dedicated read-only modal for reviewing appraisal cycle parameters:
  - Cycle title, period type (Quarterly/Annual), quarter, and year badges.
  - Duration dates (Start & End Date).
  - Deadlines section with countdown and visual badges for `selfReviewDeadline` and `managerReviewDeadline`.
  - Review instantiation summary: Total reviews generated, Completed reviews count, and overall Completion Percentage meter.
  - Audit trail card showing who created the cycle and when.
  - Shortcut buttons: "View Telemetry Progress" and "Close / Reopen Cycle" (if permitted).

### 2. `frontend/src/features/performance/components/ReviewCycleModal.jsx` (Redesign)
- Upgrade creation modal with Forest & Emerald styling:
  - Clean form inputs: Title, Period Type (`quarterly` | `annual`), Quarter (`Q1` to `Q4`), and Year.
  - 4-grid date picker setup:
    - Start Date & End Date.
    - Self-Review Deadline & Manager Review Deadline.
  - Interactive validation banner:
    - Verifies `endDate > startDate`.
    - Verifies `selfReviewDeadline < managerReviewDeadline`.
    - Verifies `managerReviewDeadline <= endDate`.
  - Explanatory callout:
    - Informing admins that launching this cycle will automatically instantiate reviews for all active employees and snapshot their designation's active KPI template.
  - Primary button: "Launch Appraisal Cycle" with loading state.

### 3. `frontend/src/features/performance/pages/ReviewCyclesPage.jsx` (Redesign)
- Executive Stat Cards:
  - Total Cycles, Active Cycles, Closed Cycles, Total Reviews Generated, Overall Avg Completion Rate.
- Filter & Search Bar:
  - Search by cycle name.
  - Filter by Period Year.
  - Filter by Status (`Active`, `Closed`, `Draft`).
- Card Grid & Tabular Presentation:
  - Each card features:
    - Title, period badge (`Q3 2026 · Quarterly`), status pill (`Active` / `Closed`).
    - Dual deadline badge box: Self-Review Deadline and Manager Deadline with calendar icons.
    - Progress bar: Completed reviews vs total reviews with percentage (`tabular-nums font-mono`).
    - Actions footer:
      - "View Details" -> opens `ReviewCycleDetailModal`.
      - "Cycle Progress" -> navigates to `/performance/cycles/:id/progress`.
      - "Close Cycle" / "Reopen Cycle" -> triggers `ConfirmModal` for safe state transition.
- PBAC Guards:
  - Launch, status toggle, and progress actions protected with `Can perform="performance.cycle.manage"`.

### 4. `frontend/src/features/performance/pages/CycleProgressPage.jsx` (Redesign)
- Upgrade the cycle telemetry and progress page:
  - Header with back navigation, cycle title, period badge, and refresh button.
  - High-level telemetry stats cards:
    - Total Reviews, Self-Reviews Submitted, Manager Reviews Submitted, Finalized Reviews, Completion Rate.
  - **Department-by-Department Progress Meter:**
    - Cards showing department name, total reviews, completed reviews, and a colored progress meter (`0-49%` Amber, `50-99%` Sky, `100%` Emerald).
  - **Overdue Reviewers Section:**
    - Tabs for "Overdue Self-Reviews" (missed self deadline) and "Overdue Manager Reviews" (missed manager deadline).
    - Table displaying employee name, avatar, code, department, manager name, and overdue status badge.
    - Empty state when all reviews are on schedule.
