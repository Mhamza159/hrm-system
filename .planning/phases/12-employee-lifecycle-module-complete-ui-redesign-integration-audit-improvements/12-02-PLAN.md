# Plan 12-02: Employee Onboarding & Lifecycle Progress Redesign

## Goal
Completely overhaul the active Employee Onboarding workflows page (`OnboardingPage.jsx`), create an interactive employee onboarding detail modal (`OnboardingDetailModal.jsx`), and redesign the employee self-service task portal (`MyTasksPage.jsx`), with complete real-time task completion tracking and welcome email re-dispatch.

## Scope & Changes

1. **`frontend/src/features/onboarding/components/OnboardingDetailModal.jsx` (New Component)**:
   - High-fidelity modal opened when clicking any onboarding record in the table or cards.
   - Header: Employee avatar, name, designation, department, joining date, and overall progress percentage.
   - Categorized task view (`HR`, `IT`, `Department`, `Finance`):
     - Displays task title, role assignee, due date, completion status, and completion timestamp.
     - Interactive task completion checkbox / button for authorized owners or HR managers with optional completion notes.
   - Quick Actions:
     - Resend Welcome Email button (with confirmation dialog).
     - Direct link to view employee profile in Employee Management (`/employees/:id`).

2. **`frontend/src/features/onboarding/pages/OnboardingPage.jsx` (Redesign)**:
   - Modern Forest & Emerald layout with zero `gray-*` slop.
   - Top metric summary cards:
     - Active Onboardings
     - Overall Completion Rate (%)
     - Pending IT & Hardware Provisioning
     - Completed Onboardings
   - Comprehensive filter bar: Search by candidate/employee name, Department filter, Status filter (`pending`, `in_progress`, `completed`).
   - Professional data table with employee ID, department, joining date, progress bar with percentage, status pill, and action buttons.
   - Detail modal integration: Clicking any row opens `OnboardingDetailModal.jsx`.

3. **`frontend/src/features/onboarding/pages/MyTasksPage.jsx` (Redesign)**:
   - Employee self-service view showing all tasks assigned to the logged-in user across active onboarding workflows.
   - Grouped into "Pending Tasks" and "Completed Tasks".
   - One-click task completion with feedback toast and optimistic cache update.
