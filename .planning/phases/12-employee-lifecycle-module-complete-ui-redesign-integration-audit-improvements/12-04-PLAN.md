# Plan 12-04: Exit Clearance, M23 Asset Lock & Final Settlement Redesign

## Goal
Redesign the Exit Clearance & Offboarding page (`OffboardingPage.jsx`), create a multi-departmental clearance inspection and sign-off modal (`ExitClearanceDetailModal.jsx`) featuring live M23 Asset Custody inspection with hardware return locking, M9 Final Settlement preview, Experience/Relieving letter streaming, and execute complete cross-module integration verification.

## Scope & Changes

1. **`frontend/src/features/onboarding/components/ExitClearanceDetailModal.jsx` (New Component)**:
   - High-fidelity clearance inspection and action modal opened when clicking an offboarding record.
   - Header: Departing employee name, code, department, official LWD, and overall clearance progress meter.
   - **Department Sign-Off Cards (IT, Finance, Admin, HR)**:
     - Shows sign-off status, authorized signer, completion timestamp, and notes.
     - Single-click sign-off action for authorized users (`offboard.manage`).
   - **M23 Asset Custody Verification Panel**:
     - Live asset custody table: Queries and displays all company hardware assigned to the departing employee (laptops, monitors, keys, ID badges).
     - Clear lock indicator: If assets remain assigned/in-use, displays a prominent amber/rose alert: *"IT and Admin clearance sign-off is locked until all assets are marked as Returned in Module M23 Asset Management."*
   - **M9 Final Settlement Breakdown**:
     - Displays settlement summary from `GET /api/v1/offboarding/:id/settlement-summary`: Unpaid days compensation, leave encashment balance, outstanding loan deductions, and estimated net settlement.
   - **Official Service Letters Bar**:
     - One-click PDF download for **Experience Letter** and **Relieving Letter** via `/api/v1/employees/:id/letters/:type`.
     - Disabled with helpful tooltip if clearance is incomplete.

2. **`frontend/src/features/onboarding/pages/OffboardingPage.jsx` (Redesign)**:
   - Modern Forest & Emerald layout with zero `indigo-*` styling.
   - Top telemetry metric cards:
     - Total Exit Clearances
     - In Clearance (Pending Sign-Offs)
     - Fully Cleared (Ready for Final Settlement)
     - Pending Asset Returns (M23 Lock Alert)
   - Search by employee name, filter by department and clearance status (`pending`, `in_progress`, `completed`).
   - Clean data table showing employee, department, last working day, 4-pill department status indicators (`IT`, `Finance`, `Admin`, `HR`), and action menu.
   - Clicking an employee opens `ExitClearanceDetailModal.jsx`.

3. **Comprehensive Integration Audit & Verification**:
   - Verify M15 Recruitment $\rightarrow$ M3 Employee $\rightarrow$ M18 Onboarding integration.
   - Verify M18 Resignation $\rightarrow$ M3 Notice Status $\rightarrow$ M18 Offboarding checklist instantiation.
   - Verify M18 Exit Clearance $\rightarrow$ M23 Asset return enforcement (HTTP 400 when assets unreturned, HTTP 200 when cleared).
   - Verify M18 Final Settlement $\rightarrow$ M9 Payroll settlement summary.
   - Verify M18 LWD $\rightarrow$ M1 Auth automated account deactivation.
   - Run Vitest full test suite: `npm --prefix backend test -- tests/m18.onboarding.e2e.test.js` (25/25 tests).
   - Run frontend production build: `npm --prefix frontend run build`.
   - Run Oxlint code quality audit across `frontend/src/features/onboarding`.
