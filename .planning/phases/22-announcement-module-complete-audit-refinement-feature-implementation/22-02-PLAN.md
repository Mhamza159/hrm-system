# Plan 22-02: Announcements Feed, Dedicated Archive Tab & Multi-Filters

## Goal
Redesign the announcements frontend user experience with dedicated **Active Notices** vs **Archived Notices** tabs, live search, dynamic department selection from database, priority pills, pin-to-top notice section, and responsive card views.

## Proposed Changes

### 1. `frontend/src/features/announcements/announcementsApi.js`
- Ensure RTK Query endpoints unwrap payload cleanly (`transformResponse: (res) => res?.data ?? res` or return structured `{ data, pagination }`).
- Add mutations:
  - `archiveAnnouncement: builder.mutation({ query: (id) => ({ url: `/announcements/${id}/archive`, method: 'PATCH' }), invalidatesTags: ['Announcement'] })`
  - `restoreAnnouncement: builder.mutation({ query: (id) => ({ url: `/announcements/${id}/restore`, method: 'PATCH' }), invalidatesTags: ['Announcement'] })`
  - `getAnnouncementById: builder.query({ query: (id) => `/announcements/${id}`, providesTags: (result, error, id) => [{ type: 'Announcement', id }] })`

### 2. `frontend/src/features/announcements/pages/AnnouncementsPage.jsx`
- Introduce View Tabs:
  - `Active Notices` (default, `isArchived: false`).
  - `Archived Notices` (`isArchived: true`).
- Search & Filter Toolbar:
  - Search input with clear button (searches title & content).
  - Target audience selector: `All`, `Company`, `Department`.
  - Dynamic Department dropdown: Loads departments via `useGetDepartmentsQuery()` with counts/names.
  - Priority selector dropdown: `All Priorities`, `Urgent`, `High`, `Normal`, `Low`.
  - Read status filter: `All Status`, `Unread Only`, `Read`.
  - Sort order dropdown: `Newest First`, `Oldest First`, `Highest Priority`.
  - Filter Reset button that returns all controls to default states.
- Feed Layout:
  - Pinned Notices Section (on Active tab only): Renders pinned notices at the top in a highlighted container with gold/amber enterprise accents and "Pinned Bulletin" badge.
  - General Notices Section: Responsive card grid/list.
  - Separate Archive Tab Layout: Displays archived announcements with distinct "Archived" badge, archiving timestamp, and "Restore to Active" action for authorized roles.
  - Meaningful empty states for both Active and Archive tabs.

### 3. `frontend/src/features/announcements/components/AnnouncementCard.jsx`
- Visual polish in Forest & Emerald Enterprise theme:
  - Unread badge & pulsing glow if `!announcement.hasRead`.
  - Priority badges with standardized color-coded tokens.
  - Multiple target departments displayed as chips if more than one department is assigned.
  - Pinned indicator ribbon.
  - Action buttons with permission checks:
    - View Details (opens `AnnouncementDetailModal`).
    - Pin / Unpin (with optimistic state or loading spinner).
    - Edit (for author or users with `announcement.edit`).
    - Archive (for users with `announcement.archive` or `announcement.delete`).
    - Restore (if viewed in Archive tab).
    - Delete (opens `DeleteConfirmationModal`).
  - Footer with seen count and click-to-open read analytics modal for managers/authors.

## Verification Criteria
- Switching to Archive tab fetches only archived records without mixing with active feed.
- Department dropdown populates from database departments.
- Pinned announcements stay anchored at the top of the active feed.
- Read/Unread indicators update reactively when user reads a notice.
