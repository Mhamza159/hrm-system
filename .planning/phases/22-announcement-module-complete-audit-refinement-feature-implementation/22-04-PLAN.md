# Plan 22-04: End-to-End Testing, Vitest Integration Suite & Verification Gate

## Goal
Construct a comprehensive integration test suite (`backend/tests/announcements.e2e.test.js`) verifying all announcement workflows across 4 roles (Super Admin, HR Manager, Department Manager, Employee), execute Oxlint verification, and run a production Vite build.

## Proposed Changes

### 1. `backend/tests/announcements.e2e.test.js` (New)
Construct 10 integration test cases using Supertest and an isolated test MongoDB database (`hrm_test_m8_announcements`):
1. **POST /api/v1/announcements**: HR creates a company-wide announcement with priority 'high' and attachments.
2. **GET /api/v1/announcements**: Employee views active announcements; company-wide announcement is visible with `hasRead: false`.
3. **PATCH /api/v1/announcements/:id/read**: Employee marks announcement as read; `hasRead` flips to `true` and `readCount` increments.
4. **PATCH /api/v1/announcements/:id/pin**: HR pins the announcement; notice is marked `pinned: true` with `pinnedAt`.
5. **PUT /api/v1/announcements/:id**: HR updates title and content; changes persist without wiping read receipts.
6. **POST /api/v1/announcements**: Department Manager creates a department-scoped announcement for their department; blocked from creating company-wide announcement (403).
7. **GET /api/v1/announcements?departmentId=...**: Department member sees the department notice; other department member does NOT see it.
8. **PATCH /api/v1/announcements/:id/archive**: HR archives announcement; record moves to `isArchived: true` and disappears from active feed.
9. **GET /api/v1/announcements?isArchived=true**: Announcement appears in archive listing; HR calls `PATCH /announcements/:id/restore` and restores it to active.
10. **GET /api/v1/announcements/:id/receipts**: HR inspects engagement analytics; returns `totalTargeted`, `seenCount`, `unseenCount`, `compliancePercentage`, and reader roster.

### 2. Quality Gate Verification
- Run `npx oxlint backend/src/modules/announcements frontend/src/features/announcements` -> must be 0 errors, 0 warnings.
- Run `npm --prefix backend test -- tests/announcements.e2e.test.js` -> 10/10 tests passing.
- Run `npm --prefix frontend run build` -> production build succeeds with exit code 0.

## Verification Criteria
- All 10 test cases execute and pass cleanly.
- Strict data scoping and RBAC enforcement verified.
- Production build succeeds without errors.
