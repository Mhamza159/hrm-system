# Plan 29-03: Module Permission Cards, Tri-State Controls & Batch Scope Operations

## Goal
Transform the module listing inside `PermissionMatrix.jsx` into structured, visually engaging Module Permission Cards. Replace raw list items with clean card/accordion headers displaying the module icon, human-readable module name, resource subject badge, operational description, selected/total counter pill, tri-state checkbox (checked, indeterminate, unchecked), and a batch scope selector dropdown.

## Target Files
- `frontend/src/features/roles/components/PermissionMatrix.jsx`
- `frontend/src/features/roles/components/ModulePermissionCard.jsx`

## Detailed Implementation Tasks
1. **Module Card Header Architecture**:
   - Card container styled with `#111D17` dark background, `#1A3125` hairline border, and rounded corners.
   - Distinct icon per module (e.g. `Users` for Employees, `Clock` for Attendance, `BadgeDollarSign` for Payroll, `Laptop` for Assets).
   - Module title, resource subject tag (e.g. `Employee`, `Attendance`, `Payroll`), and description snippet.
2. **Tri-State Module Selection Engine**:
   - **Fully Checked**: All actions in the module are granted.
   - **Indeterminate**: Some (but not all) actions are granted (rendered with solid dash indicator).
   - **Unchecked**: Zero actions in the module are granted.
   - Clicking the module checkbox cycles between selecting all actions and deselecting all actions in that module in a single batched state update.
3. **Module Batch Scope Selector**:
   - Accessible dropdown in the module header allowing the administrator to apply a uniform data scope (e.g. `All Records`, `Department Scope`, `Direct Team`, `Self Only`) to all currently active actions in that module.
4. **Accordion Collapse/Expand Interaction**:
   - Smooth transition toggling the action grid view.
   - Header indicates number of granted actions even when collapsed.

## Verification & Acceptance Criteria
- Module checkbox correctly indicates tri-state selection accurately.
- Toggling a module selects or deselects all actions in that module without affecting other modules.
- Batch scope selector updates all enabled actions in the module reliably.
