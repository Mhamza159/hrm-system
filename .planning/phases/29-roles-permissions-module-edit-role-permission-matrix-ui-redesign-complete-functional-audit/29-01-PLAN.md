# Plan 29-01: Edit Role Studio Layout & Role Metadata Card Overhaul

## Goal
Redesign the Edit Role page (`RoleFormPage.jsx`) layout into an enterprise-grade role authoring studio. Modernize the Role Specifications & Identity card with Elvara Forest & Emerald design tokens (`#061A14`, `#111D17`, `#1A3125`, `#00C471`), crisp typography, system role locked visual indicators (gold crown, amber warning banner, disabled immutable fields), auto-generated monospace slug badge, multi-line auto-growing description with live character counter (0/300), active status toggle, breadcrumb navigation, and dirty state departure guards.

## Target Files
- `frontend/src/features/roles/pages/RoleFormPage.jsx`

## Detailed Implementation Tasks
1. **Studio Header & Breadcrumb Navigation**:
   - Back button with confirmation if form has unsaved modifications.
   - Breadcrumb navigation: `Roles & Permissions` $\rightarrow$ `Edit Role: [Role Name]`.
   - Role status pill: Green `Active` vs Slate `Inactive` toggle switch.
   - For system roles (`isSystem: true`): Display gold crown icon (`Crown`) and amber tag (`Core System Role`).
2. **Role Metadata & Specifications Card**:
   - Container styled with `#111D17` dark card background, `#1A3125` hairline border, and subtle shadow.
   - **Role Name**: Clean input field with required indicator, disabled if `isSystem: true` with explanatory lock icon.
   - **Slug**: Monospace slug badge (`bg-slate-100 dark:bg-[#061A14] text-slate-500 font-mono text-xs px-2.5 py-1.5 rounded-lg border`).
   - **Description**: Textarea with character counter (0/300) and clear placeholder guidance.
   - **System Role Warning Notice**: Clean amber callout banner explaining that system roles cannot be renamed or demoted.
3. **Form State Management**:
   - Preserve original role snapshot to calculate real-time dirty status.
   - Support `window.addEventListener('beforeunload')` warning when uncommitted changes exist.

## Verification & Acceptance Criteria
- Seamless loading of existing role data without layout flicker.
- System roles display explicit visual lock badges and disable role name input.
- Custom roles allow editing name, description, and status cleanly.
- Breadcrumbs and back buttons function reliably.
