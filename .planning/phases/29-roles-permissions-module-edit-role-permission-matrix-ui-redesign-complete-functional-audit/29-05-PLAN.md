# Plan 29-05: Safety Guards, Dependency Auto-Granting & Pre-Save Diff Modal Integration

## Goal
Implement robust safety guards and dependency validation in the Edit Role and Matrix workflow. Automatically resolve permission prerequisites (e.g., granting `employee.edit` automatically grants `employee.view`). Provide a persistent sticky bottom action bar when dirty form state is detected, itemizing pending modifications. Provide a pre-save differential review modal (`PermissionDiffModal.jsx`) allowing administrators to inspect color-coded additions, modifications, and revocations before committing changes to the backend.

## Target Files
- `frontend/src/features/roles/components/PermissionMatrix.jsx`
- `frontend/src/features/roles/components/PermissionDiffModal.jsx`
- `frontend/src/features/roles/pages/RoleFormPage.jsx`

## Detailed Implementation Tasks
1. **Automated Dependency Resolution**:
   - When a user grants a mutation or approval capability (e.g. `attendance.approve`, `leave.create`, `employee.edit`), automatically check if the module's corresponding `.view` or `.read` action is missing and auto-grant it.
   - Display a brief toast or notification: *"Automatically granted view permission required for this action."*
2. **Sticky Unsaved Changes Bottom Bar**:
   - Pinned to the bottom of the viewport when form state differs from `originalSnapshot`.
   - Displays real-time delta counter: `X permission changes pending`.
   - "Discard Changes" button with confirmation prompt.
   - "Review & Save Changes" primary button opening the Diff Modal.
3. **Pre-Save Differential Review Modal (`PermissionDiffModal.jsx`)**:
   - Detailed visual breakdown:
     - **Granted Permissions (+)**: Green list of newly enabled actions with initial scopes.
     - **Modified Scopes (~)**: Blue list showing previous scope $\rightarrow$ new scope.
     - **Modified Limits (~)**: Purple list showing old limit $\rightarrow$ new limit.
     - **Revoked Permissions (-)**: Red list of removed actions.
   - System Core Role Alert: Prominent warning when editing system roles like `HR Manager` or `Department Manager`.
   - Direct execution of `updateRole` or `createRole` mutation upon confirmation with loading feedback.

## Verification & Acceptance Criteria
- Dependencies are automatically resolved when selecting higher-privilege actions.
- Unsaved changes bar only appears when true dirty state exists.
- Diff modal accurately reflects 100% of delta items before persistence.
