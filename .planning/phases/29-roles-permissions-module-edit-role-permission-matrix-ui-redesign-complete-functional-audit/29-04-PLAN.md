# Plan 29-04: Action Row Grid, Fine-Grained Data Scopes & Approval Limits

## Goal
Redesign the granular action presentation inside each module card into a high-density, structured action grid. Replace cluttered rows with clean, scannable action cards or rows displaying action name, monospace permission identifier (`module.action`), human-readable duty description, data scope selector dropdown (`All Records`, `Department Scope`, `Direct Team`, `Self Only`), and numerical approval limit input for actions that support financial or duration caps.

## Target Files
- `frontend/src/features/roles/components/PermissionMatrix.jsx`
- `frontend/src/features/roles/components/PermissionActionRow.jsx`

## Detailed Implementation Tasks
1. **Action Row / Card Layout (`PermissionActionRow.jsx`)**:
   - Memoized component with custom equality comparison to guarantee zero unnecessary re-renders.
   - Primary emerald checkbox (`#00C471`) with smooth hover state.
   - Bold action title (e.g. `Approve Leaves`, `Generate Payslips`, `Edit Employee Profile`).
   - Monospace permission key badge (e.g. `leave.approve`, `payroll.process`).
   - Contextual description explaining the security authority granted by this rule.
2. **Data Scope Selector**:
   - Dropdown options: `All Records`, `Department Scope`, `Direct Team`, `Self Only`.
   - Restrict selectable options to `actionItem.allowedScopes` defined in `permissions.js`.
   - Disabled with explanatory tooltip if the action checkbox is unchecked.
3. **Approval Limit Controls (Slice 26.9)**:
   - Present on financial or duration approval actions (e.g. `expense.approve`, `leave.approve`, `loan.approve`).
   - Clean number input with placeholder (e.g. "No cap", "Max Days", "Max PKR").
   - Restricts value to non-negative integers.
4. **Performance Tuning**:
   - Verify input latency is under 16ms when toggling rules or typing limits across 127+ actions.

## Verification & Acceptance Criteria
- Toggling a single permission updates instantly without re-rendering unrelated module rows.
- Data scope dropdown only displays allowed scopes for that specific action.
- Approval limits persist correctly into the role's permissions array.
