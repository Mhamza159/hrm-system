# Plan 29-02: Permission Matrix Category Jump-Nav, Search & Sticky Toolbar

## Goal
Elevate the top navigation and filtering capabilities of `PermissionMatrix.jsx`. Implement a sticky top command bar with real-time debounced permission search, "Show Enabled Only" quick toggle, "Expand All" / "Collapse All" accordion buttons, and global "Grant All" / "Revoke All" actions for custom roles. Implement a category jump-nav ribbon allowing administrators to seamlessly filter or scroll to any of the 5 module categories (`Core HR`, `Time & Attendance`, `Payroll & Finance`, `Talent & Operations`, `Governance & Communication`).

## Target Files
- `frontend/src/features/roles/components/PermissionMatrix.jsx`
- `frontend/src/features/roles/components/MatrixCategoryNav.jsx`

## Detailed Implementation Tasks
1. **Sticky Studio Command Toolbar**:
   - Pinned beneath header with backdrop blur (`backdrop-blur-md bg-white/95 dark:bg-[#111D17]/95`).
   - Debounced Search Input: Filter across action names (e.g. `attendance.approve`), action labels (e.g. "Approve Leaves"), and module names.
   - Live Active Counter Badge: Displays `[Active Count] of 127 Active Permissions` with pulsating emerald indicator.
   - Filter Toggle: "Show Enabled Only" pill button to instantly inspect assigned capabilities.
   - Accordion Bulk Controls: "Expand All" and "Collapse All" buttons.
   - Global Grant / Revoke (Custom roles only): One-click grant all / revoke all actions with warning confirmation.
2. **Category Quick Jump Ribbon (`MatrixCategoryNav.jsx`)**:
   - 5 functional category tabs:
     - `Core HR & Organization` (Auth, Users, Roles, Employees, Departments, Designations, Org Chart)
     - `Time & Leaves` (Attendance, Shifts, WFH, Leaves, Holidays)
     - `Payroll & Loans` (Payroll, Loans, Advances, Expenses)
     - `Talent & Operations` (Recruitment, Candidates, Jobs, Performance, Assets)
     - `Governance & Comms` (Policies, Chat, Announcements, Notifications, Settings, Audit)
   - Selection density pill showing `[Granted in Category] / [Total in Category]` actions.
   - Clicking a category tab filters the displayed module list or scrolls smoothly to the section anchor.

## Verification & Acceptance Criteria
- Search filters 127+ actions instantly without UI lag.
- Category pills accurately calculate granted vs total actions in real time.
- Toolbar remains pinned during long matrix scrolling.
