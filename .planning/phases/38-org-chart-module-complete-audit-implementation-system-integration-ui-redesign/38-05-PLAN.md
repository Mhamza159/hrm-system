# Plan 38-05: Employee Detail Inspection Drawer & Profile Bridge

## Objective
Replace the generic centered modal with a slide-over enterprise inspection drawer (`OrgChartDetailDrawer.jsx`). Display employee organizational metadata, reporting manager coordinates, direct reports roster, department peers, and permission-aware profile navigation without leaking unauthorized personal or financial data.

---

## Technical Context
- **Files Touched**:
  - `frontend/src/features/departments/components/OrgChartDetailDrawer.jsx` (New slide-over drawer)
  - `frontend/src/features/departments/pages/OrgChartPage.jsx` (Wire drawer state & node selection)
- **Dependencies**: React, Lucide Icons, `usePermission`, `useAuth`, React Router `useNavigate`.

---

## Detailed Implementation Steps

1. **Slide-Over Drawer Shell (`OrgChartDetailDrawer.jsx`)**:
   - High-density slide-over sheet docking on the right side of the screen (`w-full sm:w-[480px]`).
   - Dark craft styling: Background `#111D17`, hairline border `#1A3125`, backdrop blur overlay.
   - Smooth slide-in and slide-out animation with ESC key and backdrop click dismissal.

2. **Employee Header & Identity Deck**:
   - Large avatar with active status dot and emerald border.
   - Full Name, Employee Code badge, Grade indicator pill.
   - Designation, Department with icon coordinates.
   - Quick action bar:
     - **Center on Canvas**: Pans the canvas directly to this employee's card.
     - **Make Focus Root**: Re-roots the Org Chart canvas around this employee in Employee-Centered view mode.
     - **View Full Profile**: Navigates to `/employees` or `/profile` with permission check (`can('employee.view')`).

3. **Reporting Structure Section**:
   - **Reporting Manager Card**:
     - Avatar, Name, Title, and Department of the direct manager.
     - Direct click navigates the inspection drawer and canvas directly to the manager!
     - Displays "Executive Leadership / Top Level" if employee has no manager.
   - **Ancestral Chain Breadcrumbs**:
     - Visual vertical breadcrumbs showing the path: `CEO -> VP -> Director -> Manager -> [Employee]`.

4. **Direct Reports & Team Roster**:
   - List of all employees who directly report to this person.
   - Each report row shows: Mini avatar, Name, Designation, and status pill.
   - Clicking any report dynamically switches the drawer inspection to that subordinate!
   - Total count summary: `X Direct Reports · Y Total Indirect Reports`.

5. **Contact Coordinates & PBAC Security**:
   - Email and Phone are displayed ONLY if:
     - Requester has permission `employee.viewSensitive` OR
     - Node represents the logged-in user (`isMe`) OR
     - Requester is Super Admin / HR Manager.
   - Otherwise, displays masked contact or placeholder lock icon to prevent data harvesting.

---

## Verification Criteria
- [ ] Drawer slides out smoothly when any card is clicked on the canvas.
- [ ] Clicking a manager or direct report inside the drawer smoothly updates the drawer and highlights the canvas.
- [ ] Contact details are masked for unauthorized roles (PBAC compliance).
- [ ] "View Full Profile" button only appears when user holds appropriate employee permissions.
