# Plan 38-02: Interactive Canvas & Viewport Navigation Studio

## Objective
Build a professional, interactive canvas navigation studio inside `OrgChartPage.jsx` with butter-smooth custom drag-to-pan, mouse wheel zooming, pinch-to-zoom, fit-to-screen computation, center on root, depth levels limiter, expand/collapse all controls, and visual image export.

---

## Technical Context
- **Files Touched**:
  - `frontend/src/features/departments/pages/OrgChartPage.jsx`
  - `frontend/src/features/departments/components/OrgChartCanvasControls.jsx` (New clean modular canvas HUD)
  - `frontend/src/features/departments/departmentsApi.js` (Support query params)
- **Dependencies**: React Hooks (`useRef`, `useState`, `useCallback`, `useEffect`), Lucide icons, `html-to-image` or native SVG canvas serialization.

---

## Detailed Implementation Steps

1. **Modular Canvas Navigation HUD (`OrgChartCanvasControls.jsx`)**:
   - Create a clean floating control panel that docks in the bottom-right or top-right of the viewport:
     - **Zoom Controls**: Zoom In (+10%), Zoom Out (-10%), Zoom Reset (100%), with live percentage indicator.
     - **Fit to Screen**: Calculates viewport width/height vs tree bounding box and adjusts zoom and translate coordinates so the entire organization fits neatly into view.
     - **Center on Root**: Resets horizontal and vertical panning to center the executive leadership at the top center of the screen.
     - **Find My Position**: Smoothly animates the canvas coordinates to bring the logged-in user's card into the center of the viewport with an emerald pulsing ring.
     - **Depth Level Selector**: Quick buttons to toggle tree visible depth:
       - `Level 1` (Executive / Roots only)
       - `Level 2` (Department Heads & VPs)
       - `Level 3` (Team Leads & Managers)
       - `All Levels` (Full hierarchy expansion)
     - **Expand All / Collapse All**: Bulk toggle across all nodes in the hierarchy tree.
     - **Fullscreen Toggle**: Native browser fullscreen API wrapper with exit fallback.

2. **Custom Drag-to-Pan Implementation (`OrgChartPage.jsx`)**:
   - Replace standard `overflow-auto` scrollbars with interactive pointer-drag pan:
     - Pointer state: `isDragging`, `dragStart: { x, y }`, `panOffset: { x, y }`.
     - `onPointerDown`: Capture start position and enable active dragging cursor (`cursor-grab` $\rightarrow$ `cursor-grabbing`).
     - `onPointerMove`: If dragging, update `panOffset = { x: panOffset.x + dx, y: panOffset.y + dy }`.
     - `onPointerUp` & `onPointerLeave`: End drag smoothly.
   - Mouse wheel zoom:
     - Intercept `onWheel` when holding Ctrl/Meta or zooming on canvas, adjusting `zoom` between `0.2x` and `2.0x`.

3. **Export Canvas Capability**:
   - Add an **Export** dropdown button:
     - Export to PNG image.
     - Export to SVG / Print view.

4. **Blueprint Dot-Grid Background & Responsive Canvas**:
   - Background grid: `radial-gradient(#1A3125 1.5px, transparent 1.5px)` with dynamic scale offset so grid points smoothly shift with pan/zoom.

---

## Verification Criteria
- [ ] Users can click and drag anywhere on the canvas background to pan across the organization.
- [ ] Mouse wheel zooms in and out seamlessly between 20% and 200%.
- [ ] Fit-to-Screen button automatically scales and centers wide organizational structures.
- [ ] Level buttons (L1, L2, L3, All) collapse or expand nodes at corresponding depths.
- [ ] "Find My Position" navigates directly to the user's card with animated focus.
