# Plan 38-04: Multi-Dimensional Filters, Real-Time Search & View Modes

## Objective
Implement multi-dimensional filtering (Department, Designation, Employment Status, Location), high-performance real-time search with ancestral path lighting and auto-focus, and 4 specialized organizational view modes (Company Wide, Department Tree, My Team, Employee Centric).

---

## Technical Context
- **Files Touched**:
  - `frontend/src/features/departments/pages/OrgChartPage.jsx`
  - `frontend/src/features/departments/components/OrgChartFilterBar.jsx` (New comprehensive filter bar)
  - `frontend/src/features/departments/components/OrgChartViewSwitcher.jsx` (New tabbed view mode selector)
  - `frontend/src/features/departments/departmentsApi.js`
- **Dependencies**: React, Lucide Icons, RTK Query caching.

---

## Detailed Implementation Steps

1. **4 Specialized Org Chart View Modes**:
   - **Mode 1: Company Wide (Default)**
     - Full enterprise hierarchy rooted at top executive(s) / CEO downward.
     - Complete organizational view across all departments.
   - **Mode 2: Department Tree View**
     - Groups structure by departments.
     - Displays Department Heads at the top of each department cluster with direct subordinate staff nested beneath.
     - Handles unassigned departments and departments without heads gracefully.
   - **Mode 3: My Team View**
     - Roots the tree at the logged-in user (or their designated manager).
     - Focuses exclusively on their direct reports and subordinate teams.
     - Ideal for managers conducting 1-on-1s, performance reviews, and shift scheduling.
   - **Mode 4: Employee-Centered Focus**
     - Cross-functional 360-degree hierarchy view:
       - Top: Immediate reporting manager.
       - Center: Selected employee (spotlighted).
       - Sideways: Department peers who share the same reporting manager.
       - Bottom: Direct reports (if any).

2. **Multi-Dimensional Filter Bar (`OrgChartFilterBar.jsx`)**:
   - **Department Filter**: Multi-select or single-select dropdown with live headcount pills.
   - **Designation Filter**: Filter by job role / title.
   - **Status Filter**: `Active` (default), `On Probation`, `On Notice`, `All`.
   - **Density Toggle**: `Standard Cards` vs `Compact Chips`.
   - **Active Filter Chips**: Visual pills showing active filters with one-click "Clear All".

3. **Real-Time Search & Ancestral Path Lighting**:
   - Search input matches:
     - Employee Name
     - Employee Code (`EMP-014`)
     - Designation / Job Title
     - Department Name
   - Search results dropdown with instant result count.
   - When a result is selected:
     - Automatically expands all collapsed ancestor branches leading up to the node.
     - Illuminates the vertical connector line from root to the matching employee with an emerald glow.
     - Smoothly centers the canvas on the matching node and pulses an emerald focal indicator.
