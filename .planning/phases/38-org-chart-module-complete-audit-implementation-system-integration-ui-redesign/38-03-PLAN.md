# Plan 38-03: High-Density Enterprise Node & Connector Redesign

## Objective

## Detailed Implementation Steps

1. **Enterprise Node Architecture & Visual Tiers**:
   - Differentiate visual node hierarchy based on role and span:
     - **Executive Tier**: Golden / Amber subtle accent halo, `#00C471` badge, prominent title.
     - **Department Head Tier**: Indigo/Cyan accent, Department unit chip, direct team counter.
     - **People Manager Tier**: Emerald accent with direct report pill (`8 direct reports`).
     - **Individual Contributor Tier**: Clean minimal styling, streamlined footprint.
     - **Logged-in User (`isMe`)**: Distinctive vibrant emerald glow ring, `"You"` shield pill, and highlighted card border.
     - **Ancestral Reporting Path**: Nodes in the user's or searched employee's direct reporting chain display highlighted emerald borders and glowing trunk lines.

2. **Dual-Density Rendering Modes**:
   - **Standard View (Default)**:
     - 280px width card (reduced from bulky 320px for better density).
     - Employee avatar with online/active status dot.
     - Employee Name, Code pill, Designation, Department.
     - Grade badge (`Executive`, `Lead`, `Senior`, `Mid`, `Junior`).
     - Direct reports count badge with collapse/expand toggle button.
     - Hover quick action to view employee inspection drawer.
   - **Compact View (Toggle)**:
     - 170px width horizontal badge with mini avatar, employee name, short title, and expandable counter.
     - Perfect for large organizations (50+ employees) to view the entire structure without scrolling thousands of pixels.

3. **Horizontal Bloat Mitigation (Leaf Grid Stacking)**:
   - When a manager has $> 6$ direct reports who are individual contributors (no subordinates of their own), switch the child layout from an infinite single row into a structured **2-column or 3-column leaf grid** under the manager.
   - This prevents 15 direct reports from expanding the canvas to 5,000+ pixels wide.

4. **Crisp Connector Lines**:
   - Replace brittle pure CSS borders with clean SVG-based or pseudo-element branch lines:
     - Vertical trunk line from manager.
     - Smooth horizontal distribution bar connecting all sibling branches.
     - Drop lines to child nodes.
     - Active emerald illumination when any node in the subtree is highlighted or matches search.
