## Detailed Implementation Steps

1. **Author Vitest Integration Test Suite (`backend/tests/orgchart-overhaul.test.js`)**:
   - Write comprehensive tests covering all 15 audit scenarios:
     1. **Multi-Root Company Hierarchy**: Generates hierarchy with multiple top-level roots (no managers).
     2. **Dynamic Roles & Titles**: Verifies actual designations (`CTO`, `Software Engineer`) are returned without hardcoded fallbacks.
     3. **DAG Cycle Prevention**: Seeds a circular relationship (A reports to B, B reports to A) and verifies cycle is pruned gracefully without infinite recursion or crashes.
     4. **Self-Reporting Prevention**: Seeds an employee reporting to themselves and verifies managerId is neutralized to root.
     5. **Dangling Manager Resolution**: Seeds an employee whose manager is deleted or inactive and verifies employee is retained safely as an unassigned root without losing the subtree.
     6. **Department Filter Query**: `?departmentId=...` correctly returns only members of that department and roots at the department head.
     7. **View Mode: Team**: `?viewMode=team` roots the tree at the requesting manager's employee record.
     8. **View Mode: Employee Centered**: `?viewMode=employee&employeeId=...` returns the 360-degree focal context (manager, employee, peers, reports).
     9. **PBAC Scoping - Department Scope**: Verifies a Department Manager only receives their department tree.
     10. **PBAC Scoping - Team Scope**: Verifies a Team Lead only receives their direct/indirect reports.
     11. **PBAC Sensitivity Masking**: Verifies unprivileged staff receive masked phone and email for peers, but full details for themselves.
     12. **Hierarchy Summary Stats**: Verifies `stats` object accurately counts `totalNodes`, `departmentsCount`, `managersCount`, `maxDepth`, and `spanOfControlAvg`.
     13. **Depth Limiting**: Verifies `?maxDepth=2` prunes branches deeper than 2 levels.
     14. **Terminated / Inactive Filter**: Verifies terminated staff are excluded when `status=active`.
     15. **Ancestral Reporting Chain**: Verifies `reportingChain` contains exact ordered node IDs from requesting user to root.

2. **Frontend Quality Verification**:
   - Run `oxlint -c .oxlintrc.json src` across the entire frontend repository to ensure 0 lint errors.
   - Run `vite build` in `frontend` to verify production bundle generation.

3. **Master Roadmap & Documentation Sync**:
