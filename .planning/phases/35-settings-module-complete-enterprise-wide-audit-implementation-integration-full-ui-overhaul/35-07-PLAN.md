## 1. Goal
Overhaul Section 8 (Templates), Section 9 (Notifications & Alerts), and Section 10 (Backup):
1. **Templates Studio**:
   - Rich email and WhatsApp notification template builder (`welcomeEmail`, `leaveApproval`, `payslipDispatch`, `passwordReset`, `whatsappAlert`, `announcementBroadcast`).
   - Quick placeholder tag injector (`{{name}}`, `{{company}}`, `{{date}}`, `{{otp}}`, `{{designation}}`, `{{amount}}`).
   - Real-time side-by-side template preview rendering with mock employee context.
   - "Reset to Canonical Default" safeguard for each template.
2. **Notifications & Alerts**:
   - Modernize `NotificationSettingsForm.jsx` to integrate seamlessly into the new Elvara Forest UI shell with tab dirty state tracking and quick-save.
3. **Disaster Recovery & Enterprise Database Backup**:
   - Backend snapshot listing endpoint (`GET /api/v1/settings/backups`) returning all stored snapshots with filename, size, creation date, models count, and checksum.
   - Secure authenticated snapshot download endpoint (`GET /api/v1/settings/backups/:filename/download`), strictly restricted to Super Admin role.
   - Non-destructive backup test validator (`POST /api/v1/settings/backups/verify-integrity`) that validates backup JSON integrity without altering the live database.
   - Frontend `BackupTab.jsx` overhaul: Health KPI deck, manual trigger button with confirmation modal, interactive table of preserved snapshots with download buttons, retention horizon settings, and restore safety guidelines.

---

## 2. Requirements & Scope

1. **Backend Endpoints (`backend/src/modules/settings/setting.routes.js`, `setting.controller.js`, `backend/src/jobs/backup.job.js`)**:
   - `GET /api/v1/settings/backups`: Lists existing files in `backups/` directory with metadata (`filename`, `sizeBytes`, `createdAt`). Super Admin only.
   - `GET /api/v1/settings/backups/:filename/download`: Streams backup file to client with `Content-Disposition: attachment`. Super Admin only.
   - `POST /api/v1/settings/backups/verify-integrity`: Checks latest or specified backup archive for valid JSON structure, required models, and records count.

2. **Frontend Components**:
   - `frontend/src/features/settings/components/TemplatesForm.jsx`:
     - Split screen: Template Editor (left) + Realistic Email/WhatsApp Card Preview (right).
     - Placeholder tags clickable chips.
     - Reset template button.
   - `frontend/src/features/settings/components/BackupTab.jsx`:
     - 4-Card Status Deck: Engine Health, Total Snapshots, Storage Used, Retention Policy.
     - "Create Manual Snapshot" primary action.
     - Preserved Snapshots Table: Filename, Created At, Size, Download Action, Integrity Verify Action.
     - Disaster recovery & restore safety disclaimers.
