# Plan 35-06: Multi-Branch Geo-fencing Interactive Map & Spatial Perimeter Management

**Phase**: 35 — Settings Module Complete Overhaul  
**Status**: Planned  
**Layer**: Fullstack (Backend Service & Haversine Validator + Frontend Leaflet Map)  
**Estimated Complexity**: High  

---

## 1. Goal
Overhaul Section 7 (Geo-fencing Map) from a single-fence editor into a full-fledged **Multi-Branch Spatial Perimeter Manager**:
1. Support enterprise multi-location operations: Headquarters (Islamabad), Regional Branches (Lahore, Karachi, Rawalpindi), Client Sites, and Remote Project Hubs.
2. Enable full CRUD on branches: Add new office location, edit coordinates, rename branch, adjust radius (10m to 5,000m), toggle active/inactive per branch, and designate a Primary Headquarters.
3. Leaflet Interactive Map:
   - Branch selector sidebar/dropdown.
   - Draggable pin with instant coordinate updating.
   - Circular radius polygon preview with live resize.
   - Reverse geocoding (OpenStreetMap Nominatim) to automatically populate address from dropped pin.
   - Current location GPS assist button with accuracy indicator.
4. Cross-Module Haversine Distance Enforcement: Ensure `backend/src/modules/attendance/attendance.service.js` checks an employee's punch against ALL active geofences in the company (or branch-assigned fence), accepting the punch if within any authorized perimeter.

---

## 2. Requirements & Scope

1. **Backend Integration (`backend/src/modules/settings/setting.validation.js`, `attendance.service.js`)**:
   - Schema: Each fence has `{ id, name, branchCode, address, latitude, longitude, radiusMeters, isActive, isHeadquarters }`.
   - Update `verifyGeofencePunch` in `attendance.service.js` to iterate over all `isActive: true` fences from `SettingService.getSetting('geoFences')`.

2. **Frontend Component (`frontend/src/features/settings/components/GeoFenceMapEditor.jsx`)**:
   - Master-Detail layout:
     - Left Panel (1/3 width): Branch office list with status chips, radius badges, "Add Office" button, and search.
     - Right Panel (2/3 width): Full Leaflet interactive map with pin, perimeter circle, search geocoding bar, manual latitude/longitude inputs, radius slider (10m - 1000m), and "Locate Me" button.
   - Branch deletion safeguards: Minimum of 1 active office must always exist.
   - Unsaved changes indicator and save action.

---

## 3. Implementation Steps

1. Update `backend/src/modules/settings/setting.validation.js` `geoFenceItemSchema` with unique `id`, `branchCode`, and `isHeadquarters`.
2. Ensure `attendance.service.js` evaluates distance against all active fences using the Haversine formula.
3. Overhaul `frontend/src/features/settings/components/GeoFenceMapEditor.jsx` with the Master-Detail multi-branch manager.
4. Verify creating, modifying, and deleting branches on Leaflet.
