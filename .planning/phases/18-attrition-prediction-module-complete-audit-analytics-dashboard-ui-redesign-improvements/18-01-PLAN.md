# Plan 18-01: Analytics Dashboard Layout, KPI Metric Cards & Global Controls

## 1. Goal
Audit, modernize, and completely redesign the **Attrition Analytics Dashboard Layout** (`AttritionDashboardPage.jsx`). Elevate the dashboard root container with Forest & Emerald Enterprise styling (`#061A14` canvas, `#111D17` surfaces, `#1A3125` borders, `#00C471` emerald accents), implement 4 executive KPI summary cards with tabular numbers and trend indicators, add on-demand recalculation trigger with rate-limit status, and build responsive global filters (search, department picker, risk tier pills).

---

## 2. Target Files & Scope
- `frontend/src/features/attrition/pages/AttritionDashboardPage.jsx`
- `frontend/src/features/attrition/components/RiskTierBadge.jsx`

---

## 3. Detailed Tasks

### Task 1: Dashboard Header & Recalculation Control
- Redesign the dashboard header to fit the enterprise HRMS layout with `#061A14` background.
- Title: "Attrition Risk Intelligence & Retention Hub" with `TrendingDown` badge in `#EF4444` / `#00C471`.
- Subtitle: "Predictive early-warning intelligence synthesizing attendance, compensation, and performance trajectories".
- On-Demand Recalculation Trigger:
  - Button with animated spinner during execution (`isRecalculating`).
  - Gated by `attrition.manage` (Super Admin & HR Manager only).
  - Displays last evaluated timestamp (`Calculated: [Relative / Formatted Time]`).
  - Graceful handling of HTTP 409 (already in progress) with informative toast.

### Task 2: Executive KPI Summary Cards
- Implement 4 high-craft summary cards:
  1. **Total Workforce Evaluated**: Count of active evaluated employees with workforce coverage percentage.
  2. **High Flight Risk**: Red crimson badge (`#EF4444`), employee count, percentage of workforce, and threshold indicator (`Score >= 70`).
  3. **Moderate Risk**: Amber badge (`#F59E0B`), employee count, percentage, and threshold indicator (`Score 40-69`).
  4. **Stable Retention**: Emerald badge (`#00C471`), employee count, percentage, and threshold indicator (`Score < 40`).
- Each card styled with `#111D17` surface, `#1A3125` border, subtle accent glow, and appropriate icon (`Users`, `ShieldAlert`, `AlertTriangle`, `Sparkles`).

### Task 3: Global Filter Toolbar
- **Search Input**: Full-text search by employee name or code with debounce.
- **Department Selector**:
  - Dropdown populated from `/departments`.
  - Available for Super Admin & HR Manager; disabled/locked to the manager's assigned department for Department Managers.
- **Risk Level Segmented Filter**:
  - Segmented pills: `All`, `High Risk`, `Moderate Risk`, `Stable Retention`.
  - Active pill highlighted in corresponding color (`#EF4444`, `#F59E0B`, `#00C471`).
- **Reset Filters**: One-click action to reset all search/filter states to defaults.
