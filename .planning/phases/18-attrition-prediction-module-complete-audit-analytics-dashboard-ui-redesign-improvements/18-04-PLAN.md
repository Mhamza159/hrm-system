## 3. Detailed Tasks

### Task 1: Employee Risk Details Dossier Modal (`EmployeeRiskDetailModal.jsx`)
- Dialog layout styled with `#111D17` surface, `#1A3125` border, and shadow-2xl.
- **Section 1: Employee Profile & Flight-Risk Header**:
  - Employee avatar, name, monospaced employee code, department, and designation.
  - Joining date and calculated tenure.
  - Circular / radial risk score gauge (`0 - 100`) with color interpolation and pulsing risk tier badge (`High`, `Moderate`, `Stable`).
  - Evaluated timestamp.
- **Section 2: 5-Factor Contribution Breakdown**:
  - Horizontal breakdown progress bars with points received vs maximum weight:
    - Attendance & Tardiness: `X / 30 pts`
    - Compensation Stagnation: `X / 25 pts`
    - Performance & Appraisal: `X / 20 pts`
    - Tenure Progression: `X / 15 pts`
    - Engagement Signals: `X / 10 pts`
- **Section 3: Primary Risk Drivers**:
  - List of detected signals from `topFactors` array (e.g., `Unplanned Absences: 4 days in last 90 days (+15)`).
  - Clean card styling with warning icons.
- **Section 4: Contextual Retention Recommendations**:
  - Rule-based suggestions tailored to the active drivers:
    - If compensation stagnation: Recommend market compensation review or off-cycle bonus.
    - If attendance signals: Recommend wellness one-on-one and flexibility/remote work options.
    - If appraisal overdue: Recommend immediate manager performance check-in and career roadmap session.
    - If tenure stagnation: Recommend internal mobility, mentorship, or leadership project delegation.

### Task 2: Retention Intervention Notes Logger & Audit Trail
- Form for adding confidential intervention notes:
  - Action Taken dropdown: `Compensation Review`, `One-on-One Wellness Check`, `Career Pathing / Promotion`, `Workload Rebalancing`, `Performance Counseling`, `Other`.
  - Follow-up date picker (`<input type="date">` with min date set to tomorrow).
  - Note textarea with character count validation (max 1000 chars).
  - Submit button with loading spinner (`addRetentionNoteMutation`).
- **Historical Intervention Timeline**:
  - Vertical timeline of previously logged notes:
    - Author name and role.
    - Timestamp.
    - Action taken badge.
    - Note content.
    - Follow-up date indicator if pending.
