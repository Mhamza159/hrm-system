# Plan 18-03: Employee Risk Analysis Table, Pagination & Export Engine

## 1. Goal
Audit, modernize, and completely redesign the **Employee Attrition Risk Table** (`AttritionDashboardPage.jsx`). Deliver a high-density, accessible enterprise data table presenting employee flight-risk scores, visual risk gauges, pulsing risk tier badges, top contributing driver chips, sorting, responsive pagination, and an authorized CSV export utility.

---

## 2. Target Files & Scope
- `frontend/src/features/attrition/pages/AttritionDashboardPage.jsx` (Table section & export)
- `frontend/src/features/attrition/components/RiskScoreGauge.jsx` (New)

---

## 3. Detailed Tasks

### Task 1: Enterprise Table Architecture & Columns
- Container styled with `#111D17` surface, `#1A3125` border, and subtle table header divider.
- Table Columns:
  1. **Employee Identity**:
     - Circular avatar with initials fallback.
     - Full employee name (`font-bold text-slate-900 dark:text-white`).
     - Monospaced employee code (`font-mono text-[11px] text-[#7E9E8F]`).
     - Email address in secondary text.
  2. **Department & Designation**:
     - Department badge (`Building2` icon).
     - Designation title in muted text.
  3. **Tenure**:
     - Joining date and calculated tenure in years/months.
  4. **Risk Score & Gauge (`RiskScoreGauge.jsx`)**:
     - Numerical score (`0 - 100`) in bold tabular font.
     - Horizontal mini progress bar with gradient interpolation:
       - 0 - 39: `#00C471` (emerald)
       - 40 - 69: `#F59E0B` (amber)
       - 70 - 100: `#EF4444` (crimson)
  5. **Risk Tier**:
     - High (`#EF4444` pill with pulsing indicator).
     - Medium (`#F59E0B` pill with subtle amber ring).
     - Low (`#00C471` pill with emerald check/dot).
  6. **Top Contributing Factors**:
     - Chips showing up to 2 top factors (e.g., `Salary Stagnation (+25)`, `Unplanned Absences (+15)`).
     - `+N more` tooltip if more than 2 factors exist.
  7. **Interventions & Action Triggers**:
     - Count of existing retention notes (`MessageSquare` icon with badge).
     - Primary action button: "View Profile & Notes" (opens `EmployeeRiskDetailModal`).

### Task 2: Responsive Sorting & Pagination
- **Sorting**: Interactive table column headers for `riskScore`, `calculatedAt`, `employeeName` with directional sort arrows (`ArrowUpDown`, `ChevronUp`, `ChevronDown`).
- **Pagination Bar**:
  - Showing `Page X of Y (Total Z employees)`.
  - Rows per page selector (`10`, `25`, `50`).
  - Next / Previous buttons with disabled boundaries.

### Task 3: CSV Export Utility
- "Export Risk Report" action button positioned in the table header.
- Formats currently filtered employee risk data into a downloadable CSV (`attrition-risk-report-[DATE].csv`):
  - Columns: `EmployeeCode`, `Name`, `Department`, `Designation`, `JoiningDate`, `RiskScore`, `RiskLevel`, `AttendanceScore`, `SalaryScore`, `AppraisalScore`, `TenureScore`, `TopFactors`, `NotesCount`, `EvaluatedAt`.
- Gated to authorized users (`attrition.view`).
