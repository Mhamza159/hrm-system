# Deployment & Git Branch Policy

## STRICT USER MANDATE
1. **Never merge into `main` branch or push directly to `origin main` / production without explicit confirmation and permission from the user.**
2. All work, bug fixes, features, and refactoring MUST be done and tested on dedicated feature branches (e.g. `feature/...` or `fix/...`).
3. Only when the user explicitly reviews, approves, and instructs to merge or go live, may changes be merged into `main` and pushed to production.
